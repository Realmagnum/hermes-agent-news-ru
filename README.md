# Новости Hermes Agent

Ежедневные новости Hermes Agent на русском — перевод дайджестов [hermes-agent-news-fr](https://github.com/t1t4nium/hermes-agent-news-fr) (t1t4nium), который собирает и резюмирует анонсы Nous Research и сообщества (X/Twitter: @NousResearch, @Teknium, @witcheer и др.).

Репозиторий синхронизируется автоматически: как только во французском оригинале появляется новый выпуск, он переводится на русский и публикуется здесь (проверка каждые 2 часа).
