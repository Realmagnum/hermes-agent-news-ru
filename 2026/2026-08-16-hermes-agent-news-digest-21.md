# Новости Hermes Agent #21

Панель возможностей desktop получает интерфейс управления по профилям, а witcheer составил список из пяти PR после v0.20.0, заслуживающих внимания.

## Панель возможностей: фильтр по профилям

16 августа Teknium показал обновлённую панель возможностей в Hermes Agent Desktop. Вкладка теперь позволяет ограничивать набор skills, инструментов и MCP конкретным профилем или ботом. Каждый профиль может раскрывать только свои возможности, не смешивая их с глобальной конфигурацией.

Второе дополнение — встроенный браузер навыков. Из панели можно просматривать каталог и устанавливать skill напрямую, без командной строки. Teknium сопроводил анонс скриншотом: вид списка возможностей с переключателями по профилям и кнопкой доступа к skills browser.

> Источник: [@Teknium, 16 августа 2026](https://x.com/Teknium/status/2088874095345856541)

## Пять PR после v0.20.0, которые рекомендует witcheer

16 августа witcheer опубликовал список с комментариями из пяти pull request, смерженных после выхода v0.20.0.

**/heartbeat (#79681): дать сессии пульс.** Команда `/heartbeat every 30m check the deployment` задаёт повторяющуюся инструкцию, которая снова включает сессию в работу как обычный ход, как только сессия становится неактивной и интервал истёк. Агент продолжает продвигать длительную задачу без необходимости её перезапуска.

**Wake word без рук для удалённых агентов (#79491).** Когда агент работает на сервере или в Hermes Cloud, а микрофон находится на ноутбуке, desktop теперь передаёт аудиопоток в backend через существующее аутентифицированное соединение. Детекция wake word работает, даже если у агента нет собственного микрофона.

**read_file понимает настоящие документы (#79781).** PDF, устаревшие форматы Office (.doc, .ppt, .xls), OpenDocument, RTF и EPUB теперь автоматически извлекаются в виде обычного текста. Конвертер устанавливается сам при первом использовании; существующие форматы остаются без изменений.

**/learn может переваривать целые книги (#80804).** Нацеленный на книгу или большой корпус текстов, /learn строит структурированную knowledge-skill: лёгкий индекс и справочные файлы по главам, загружаемые по требованию, вместо того чтобы складывать всё в один файл.

**Обновления desktop становятся незаметными на всех ОС (#83634).** Приложение закрывается, `hermes update` выполняется в фоне, приложение снова открывается. Небольшое окно статуса следит за операцией, а каждое обновление обновляет и сам механизм обновления.

> Источник: [@witcheer, 16 августа 2026](https://x.com/witcheer/status/2089004661386686593)

## witcheer тестирует квантизации Qwen 3.8-27B

16 августа witcheer опубликовал количественный анализ цены квантизации для Qwen 3.8-27B. Семь ступеней GGUF протестированы на RTX 5090: разрыв между Q8_0 и 2-bit составляет 2,9 пункта, без обрыва ни на одном пороге. Q6_K дотягивает до Q8_0 вплоть до второго знака после запятой, что делает самый большой файл шкалы бесполезным.

Самая примечательная величина — UD-IQ3_XXS: 92,7 против 93,7 у Q8_0 при файле 11,1 ГБ и 96 ток/с. Этого достаточно, чтобы разместить плотную 27B в карте на 16 ГБ почти с максимальным качеством. Даже нижний предел — 2-bit на 9 ГБ — держит 90,8, с потерями, сосредоточенными в MMLU и HumanEval.

Его рекомендации: UD-Q4_K_XL для карт на 24 ГБ, UD-IQ3_XXS для карт на 16 ГБ, а Q8_0 игнорировать.

> Источник: [@witcheer, 16 августа 2026](https://x.com/witcheer/status/2088940018144326007) — полная методология в [Grimoire](https://t.me/witcheergrimoire)
