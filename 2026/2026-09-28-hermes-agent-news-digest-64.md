# Новости Hermes Agent #64

В этом выпуске: скорый запуск Hermes Desktop в браузере с помощью команды `hermes webapp`, новая команда `hermes send` из серии Wingtips, инструмент Herald Family для совместного использования одного бота с близкими, 200 пулл-реквестов, объединённых 27 сентября, а также платформа безопасности NVIDIA, добавившая поддержку агентов Hermes в изолированных песочницах.

## Hermes Desktop в браузере с помощью hermes webapp

27 сентября Bear представил обновлённый пулл-реквест: `hermes webapp` запускает полноценное приложение Desktop прямо с хоста Hermes — с чатом, файлами, Git, сохраняющим состояние после перезагрузки терминалом и авторизацией для удалённых подключений. 28 сентября Teknium ответил: «Coming soon to all!», а Luke The Dev в тот же день подтвердил, что выход в браузере подтверждён официально.

Пулл-реквест 93508 от BearHuddleston добавляет команду `hermes webapp` — защищённый аутентификацией браузерный режим для оригинального движка рендеринга Hermes Desktop. Это не веб-панель управления: команда запускает рабочее пространство Desktop с фокусом на чате и развёртывает браузерную реализацию `window.hermesDesktop`, привязанную к хосту с запущенным Hermes. Существующие границы полномочий сохраняются без дублирования интерфейса и создания параллельного бэкенда. Рендерер компилируется отдельно в `apps/desktop/dist-webapp`, а аутентификация FastAPI по сессионным токенам и одноразовые тикеты WebSocket защищают поверхность атаки. Нативные возможности Electron либо отключены, либо возвращают явную ошибку вместо имитации, а внешние подключения по умолчанию закрыты настроенной аутентификацией.

## Wingtips #86: hermes send

witcheer посвятил 86-й выпуск Wingtips команде `hermes send`. Она позволяет отправлять сообщения из любого скрипта на платформы, где уже настроен Hermes Agent. Команда использует учётные данные бота со шлюза и не делает никаких обращений к модели. Например, `hermes send --to telegram "deploy finished"` отправляет сообщение напрямую, а входные данные также можно передавать через пайп (pipe).

> Источник: [@witcheer, Hermes Wingtips #86: hermes send, 28 сентября 2026](https://x.com/witcheer/status/2104531742686093765)

## Herald Family: совместный доступ к боту для близких

28 сентября Luke The Dev представил Herald Family — инструмент, созданный для простой задачи: поделиться ботом Hermes с женой, не открывая ей доступ ко всей своей конфигурации. Вы выбираете бота, настраиваете доступные функции и приглашаете человека по QR-коду или одноразовой ссылке. Всего одна команда запускает компактный прокси для совместного доступа прямо на машине, где работает Hermes. Демонстрация доступна на видео.

> Источник: [@iamlukethedev, I wanted to share a Hermes Bot with my wife... So I built Herald Family, 28 сентября 2026](https://x.com/iamlukethedev/status/2104550126983282710)

## 200 пулл-реквестов, объединённых 27 сентября

28 сентября iamlukethedev подвёл итоги: 27 сентября в репозиторий Hermes было смерджено ровно 200 пулл-реквестов. Среди наиболее заметных изменений:

- Интерфейс больше не использует буферную зону (staging area) при перетаскивании файлов из локальной системы и сохраняет встроенные @-упоминания файлов.
- Канбан-доска теперь отображает причину блокировки задачи и позволяет её разблокировать.
- Комбинации Cmd/Ctrl + от 1 до 9 переключают на вкладку, находящуюся под курсором.

> Источник: [@iamlukethedev, Hermes merged 200 PRs on September 27, 28 сентября 2026](https://x.com/iamlukethedev/status/2104384576890212482)

## Платформа NVIDIA Open Agent Safety и агенты Hermes

28 сентября Jensen Huang представил платформу NVIDIA Open Agent Safety совместно с более чем сотней индустриальных партнёров. Платформа объединяет OpenShell и Sentry. OpenShell переносит принципы изоляции веб-браузеров на работу агентов: каждая сессия изолируется в песочнице, потребление ресурсов отслеживается, а каждое разрешение верифицируется средой исполнения перед выполнением действия. Sentry представляет собой эталонную архитектуру внеполосного мониторинга (out-of-band monitoring), работающую на DPU BlueField-4, которая способна за считанные миллисекунды изолировать агента при попытке выйти за установленные рамки.

Связующим звеном с экосистемой Hermes выступает NemoClaw — открытый референсный стек NVIDIA для запуска агентов в песочницах OpenShell. Он позволяет запускать агентов Hermes, объединяя цикл навыков и памяти от Nous Research с контролем исполнения OpenShell. Это обеспечивает постоянную работу агентов, позволяя им обучаться на собственном опыте и повторно использовать успешные рабочие процессы. Утилита инициализации `nemohermes onboard` выбирает Hermes по умолчанию, а слой интеграции записывает конфигурацию среды выполнения в `/sandbox/.hermes`.
