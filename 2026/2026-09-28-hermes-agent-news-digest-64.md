## Hermes Desktop в браузере с помощью hermes webapp

Bear представил обновленный пулл-реквест: команда `hermes webapp` позволяет хостить полноценное приложение Desktop прямо из инстанса Hermes. Пользователю становятся доступны чат, работа с файлами, Git, терминал, сохраняющий сессию даже при перезагрузке страницы, и аутентификация для удаленных подключений. @Teknium прокомментировал новость обещанием «Coming soon to all!», а @iamlukethedev подтвердил официальный скорый релиз браузерной версии.

Пулл-реквест [#93508](https://github.com/NousResearch/hermes-agent/pull/93508) от BearHuddleston внедряет команду `hermes webapp` — защищенный режим запуска оригинального рендерера Hermes Desktop в браузере. Это не урезанный веб-дашборд: система разворачивает полноценное рабочее окружение с чатом и реализует браузерный полифил для `window.hermesDesktop`, взаимодействующий с хостом Hermes. Архитектура сохраняет разграничение прав доступа без необходимости клонировать UI или поднимать параллельный бэкенд.

Технические детали:
- Сборка рендерера компилируется изолированно в директорию `apps/desktop/dist-webapp`.
- Поверхность атаки защищена токенами сессий FastAPI и одноразовыми тикетами WebSocket.
- Нативные API Electron не эмулируются: они либо отсутствуют, либо явно возвращают ошибку.
- Удаленные сетевые привязки по умолчанию закрыты и требуют настроенной авторизации.

## Wingtips #86: hermes send

@witcheer посвятил 86-й выпуск серии Wingtips утилите `hermes send`. Команда позволяет отправлять сообщения из любых bash-скриптов во внешние платформы, уже подключенные к Hermes Agent.

Ключевая особенность — использование кредов бота через существующий шлюз без единого вызова LLM, что исключает лишний расход токенов.

```bash
hermes send --to telegram "deploy finished"
```

Команда также бесшовно поддерживает передачу данных через пайплайны (`stdout` в `stdin`).

## Herald Family: совместный доступ к боту для близких

@iamlukethedev представил инструмент Herald Family, созданный для решения бытовой задачи: поделиться ботом Hermes с семьей, не предоставляя доступ ко всей рабочей конфигурации и окружению.

Схема работы предельно проста:
- Пользователь выбирает бота и отмечает функции, к которым нужно открыть доступ.
- Приглашение отправляется через QR-код или одноразовую ссылку.
- Вся сессия обслуживается легковесным прокси-сервером, запускаемым на хосте с Hermes одной командой.

В оригинальном посте доступна видеодемонстрация работы утилиты.

## 200 пулл-реквестов смерджено за 27 сентября

@iamlukethedev подвел итоги рекордной продуктивности команды: за 27 сентября в репозитории Hermes было смерджено ровно 200 пулл-реквестов. Среди наиболее заметных улучшений:

- **Работа с файлами:** интерфейс больше не использует промежуточную зону (staging) при перетаскивании локальных файлов и корректно сохраняет инлайн-ссылки через `@`.
- **Канбан-доска:** теперь визуализирует причину блокировки задачи и позволяет разблокировать ее в один клик.
- **Навигация:** комбинации `Cmd/Ctrl + 1...9` теперь переключают фокус на вкладку, находящуюся непосредственно под курсором мыши.

## Платформа NVIDIA Open Agent Safety и агенты Hermes

Дженсен Хуанг представил платформу NVIDIA Open Agent Safety, созданную совместно с более чем сотней индустриальных партнеров. Решение объединяет две ключевые технологии:

- **OpenShell:** переносит принципы песочницы современных веб-браузеров на жизненный цикл агентов. Каждая сессия изолируется, потребление ресурсов лимитируется, а разрешения валидируются рантаймом перед выполнением каждого действия.
- **Sentry:** референсная архитектура внеполосного мониторинга (out-of-band), работающая на DPU BlueField-4. Система способна за миллисекунды отправить в карантин агента, пытающегося выйти за пределы изоляции.

Интеграция с экосистемой Hermes реализована через **NemoClaw** — открытый референсный стек NVIDIA для запуска агентов внутри песочниц OpenShell. Стек объединяет циклы памяти и скиллов от Nous Research с политиками безопасности OpenShell. Это открывает дорогу к созданию надежных «always-on» агентов, способных непрерывно учиться на собственном опыте. 

Мастер настройки `nemohermes onboard` по умолчанию выбирает Hermes в качестве целевого агента, а слой интеграции автоматически сохраняет конфигурацию рантайма по пути `/sandbox/.hermes`.
