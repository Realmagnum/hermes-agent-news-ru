# Новости Hermes Agent #3

Ускоренный стриминговый TTS, Hermes лидирует в бенчмарке Composio и −50 % на GPT Terra/Luna в Nous Portal.

## Стриминговый TTS приходит в Hermes Agent

Teknium анонсировал 29 июля, что голосовые вызовы в Hermes Agent стали заметно быстрее. Большинство поддерживаемых TTS-бэкендов теперь отдают синтез речи в стриминге (чанк за чанком) вместо ожидания полного аудиофайла.

Результат: гораздо меньшее время голосового ответа, приближающееся к разговору в реальном времени. В анонсе не уточняется, доступна ли функция уже в стабильной ветке или требует ветку main, но механизм, судя по всему, работает на стороне API.

> Источник: [@Teknium, 29 июля 2026](https://x.com/Teknium/status/2082339029375426914)

## Hermes Agent — самый быстрый harness по бенчмарку Composio

Composio опубликовал 29 июля результаты бенчмарка, сравнивающего три harness'а автономных агентов: Hermes Agent, Kimi Code и Claude Code. Цифры:

- **Доля успешных задач**: 22/28 у Kimi Code, 21/28 у Hermes, 20/28 у Claude Code
- **Медианное время на задачу**: 179 с у Hermes, 297 с у Kimi Code, 348 с у Claude Code

Hermes — самый быстрый harness (медиана 179 с, почти вдвое быстрее Claude Code). Kimi Code показывает лучшую долю успеха и лучшую токен-эффективность. По сырым баллам все трое близки, но разрыв во времени значителен.

Teknium перепостил результаты, отметив, что самый быстрый harness (Hermes) и самый экономный по токенам (Kimi Code) — разные, что говорит о различных архитектурных компромиссах между подходами.

> Источник: [@Composio, перепост @Teknium, 29 июля 2026](https://x.com/composio/status/2082452274140311565)

## GPT Terra и Luna со скидкой −50 % в Nous Portal

Nous Research анонсировал 28 июля партнёрство с OpenRouter: GPT-5.6 Terra и Luna доступны со скидкой 50 % в течение ограниченного времени в Nous Portal.

Предложение доступно на portal.nousresearch.com. Teknium подтвердил акцию, поделившись визуалом анонса. Явная дата окончания не сообщалась.

> Источник: [@NousResearch, перепост @Teknium, 28 июля 2026](https://x.com/Teknium/status/2082138543204528518)
