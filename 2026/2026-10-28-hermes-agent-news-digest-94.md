## Новые подписки: облачный агент включён в тариф

27 октября Nous Research объявила о масштабном обновлении тарифных планов подписки на Hermes Agent:
- **Облачный агент в коробке:** каждый новый платный тариф теперь по умолчанию включает облачного агента, работающего круглосуточно (always-on) на выделенной инфраструктуре — держать ноутбук открытым больше не требуется.
- **Новая модель лимитов:** расход ресурсов больше не списывается из единого ежемесячного пула кредитов. Теперь действуют сбалансированные дневные и недельные лимиты, дополняемые ежемесячной квотой.
- **Бесшовный переход:** пользователи текущих планов могут переключиться на новую линейку в любой момент на странице биллинга в Nous Portal.

Как уточнил @Teknium, подписчики всех платных уровней Nous Portal получают полноценный инстанс Hermes Agent вместе с выделенной виртуальной машиной («компьютером»), к которому можно подключиться в один клик как из приложения Desktop, так и через мессенджеры.

@witcheer поделился впечатлениями прямо с борта самолёта: его агент на Hermes Cloud автономно выполнял задачи, несмотря на ужасный бортовой Wi-Fi, подчеркнув, что облачный агент доступен «из коробки» во всех новых планах. В свою очередь, @iamlukethedev резюмировал суть апдейта: включённый хостинг облачного агента, суточные и недельные лимиты и скорректированные цены.

## 61 пулл-реквест, влитый 27 октября

В changelog за 27 октября зафиксирован 61 смердженный пулл-реквест. Ключевые нововведения:

- **Синхронизация настроек:** параметры интерфейса Desktop и Webapp (тема оформления, режим) теперь синхронизируются между всеми открытыми окнами на одной машине.
- **Умное создание сессий:** кнопка создания новой сессии теперь переиспользует пустую вкладку-черновик вместо пложения лишних вкладок.
- **Разработка плагинов в браузере:** Desktop-плагины теперь можно открывать и отлаживать прямо во вкладке браузера без необходимости держать отдельное приложение.
- **Восстановление после рестарта:** после перезапуска CLI сообщает, если последнее сообщение не успело отправиться, и выводит точную команду для возобновления сессии.

### Безопасность и стабильность
В релиз также вошла серия важных патчей безопасности и багфиксов:
- **Защита в режиме без токена:** запросы из браузера или от сторонних хостов теперь строго отклоняются при отключённой авторизации по токену.
- **Валидация URL:** проверка URL теперь блокирует адреса, авторитет (authority) которых парсится разными HTTP-клиентами неоднозначно (защита от URL parsing confusion).
- **Сохранение сообщений при выходе:** сообщения, отправленные перед самым закрытием приложения Desktop, больше не теряются.
- **Надёжность апдейтов Desktop:** обновления Desktop больше не сбоят из-за объёмной базы `state.db`, региональных настроек с запятой в качестве десятичного разделителя или особенностей утилиты GNU `date`.

## ElevenLabs SFX: генерация звуковых эффектов из Desktop

27 октября @Teknium представил официальный плагин **ElevenLabs SFX**, развивающий направление Game Dev Studio в экосистеме Hermes Agent.

Плагин даёт возможность генерировать звуковые эффекты (SFX) прямо из интерфейса Hermes Desktop с поддержкой зацикливания (looping), вариаций в один клик и удобной библиотекой всех сгенерированных ассетов. @witcheer, который на прошлой неделе сгенерировал 3D-модель рыцаря-утки через плагин Meshy, отметил, что теперь агент может озвучивать созданные объекты.

### Как устроен плагин
- **Инструмент `elevenlabs_sound_effect`:** превращает текстовое описание в аудиофайл длительностью от 0,5 до 30 секунд (с опцией бесшовной петли).
- **Требования:** переменная окружения `ELEVENLABS_API_KEY` (тот же API-ключ, что используется для генерации голоса ElevenLabs).
- **Постобработка и упаковка:** плагин включает скилл саунд-дизайна и локальный пайплайн на базе `ffmpeg`, который нормализует громкость, обрезает тишину и упаковывает результат в архив с `manifest.json`.
- **UI в Desktop:** сгенерированные звуки отображаются интерактивными карточками с графиком волны (waveform), кнопкой зацикленного воспроизведения и генерацией вариаций. По горячей клавише доступна общая библиотека звуков профиля.
- **Тарификация:** генерация рассчитывается по тарифам ElevenLabs (около 10 кредитов за секунду аудио при фиксированной длине, либо фикс).

### Установка

```bash
hermes plugins install elevenlabs-sound-effects
```

## Собственный аккаунт GitHub для агента

## Wingtips #112: однократные запланированные задачи

28 октября @witcheer опубликовал очередную подсказку из серии Wingtips (#112), посвящённую однократному запуску отложенных задач.

Чтобы задача выполнилась ровно один раз без необходимости вручную удалять её из расписания, при создании используется ключевое слово `in`:

```bash
hermes cron create "in 2h" "Напомни позвонить стоматологу до закрытия клиники."
```

Шлюз выполнит команду спустя 2 часа, после чего задание автоматически удалится из планировщика.

## Ornith 1.5 122B: запуск локально на одной видеокарте

27 октября @witcheer протестировал и сравнил локальную работу двух версий модели **Ornith 1.5**:

- **Ornith 1.5 122B:** квантованная 3-битная версия (размер файла 46,1 ГиБ) выдаёт **47,6 токенов/с** на одной видеокарте RTX 5090 (32 ГБ VRAM) при частичной выгрузке экспертов (MoE) в системную RAM.
- **Ornith 1.5 35B:** версия в квантовании `Q4_K_M` (20,2 ГиБ) целиком помещается в видеопамять карты и работает примерно в шесть раз быстрее. При этом качество ответов 35B укладывается в статистическую погрешность старшей 122B-модели практически на всех бенчмарках, за исключением MMLU.

### Семейство Ornith 1.5
Ornith 1.5 — семейство открытых моделей под лицензией MIT, разработанное лабораторией Ornith. Изначально линейка включала версии 397B, 35B и 9B, а размерность 122B была добавлена позже как сбалансированное промежуточное решение для энтузиастов локального инференса. Веса опубликованы на Hugging Face; модели поддерживаются в Ollama и нативно работают в связке с Hermes Agent.
