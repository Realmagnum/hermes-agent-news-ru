## /export и /import: портативные профили Hermes

Команда Nous Research представила механизм полного экспорта и импорта профилей в Hermes Agent, сделав их легко переносимыми между машинами.

Команда `/export` упаковывает профиль в единый архив без конфиденциальных данных и секретов. В экспорт включаются:
- установленные скиллы и модули памяти;
- персона (persona) агента и cron-задачи;
- плагины, настройки, темы оформления и кастомные раскладки десктопного интерфейса.

Команда `/import` восстанавливает окружение из файла в один шаг, сразу приводя агента в полностью рабочее состояние.

Студия @tonbistudio показала практический сценарий: дефолтный агент был экспортирован с локального ПК и развернут под новым именем на кластере DGX Spark, сохранив весь накопленный опыт и контекст. Как подчеркнул @witcheer, агент больше не привязан жестко к хосту, на котором настраивался и эволюционировал, при этом учетные данные пользователя гарантированно остаются в безопасности.

## Официальный скилл для превращения любого сайта в API-клиент

@Teknium представил новый официальный скилл — `har-derived-api-client`. 

Он позволяет агенту выполнить сценарий на веб-странице, отследить сетевые запросы браузера и автоматически сгенерировать статический API-клиент. В дальнейшем агент и сторонние скрипты могут обращаться к сайту напрямую через полученный клиент, минуя тяжелый рендеринг в браузере.

Установка выполняется одной командой:
```bash
hermes skills install official/web-development/har-derived-api-client
```

По замечанию @witcheer, лучшие инструменты агента — это те, которые он создал сам под конкретный контекст. Hermes один раз проходит пользовательский путь в браузере, разбирает сетевой трафик под капотом и собирает компактный HTTP-клиент. Все последующие вызовы выполняются как легковесные и быстрые сетевые запросы вместо дорогостоящей загрузки страниц в браузере.

## Hermes Wingtips #45: миграция с OpenClaw через команду hermes claw migrate

В 45-м выпуске серии Hermes Wingtips @witcheer разобрал сценарий переноса конфигураций из OpenClaw в Hermes Agent с помощью встроенной утилиты миграции:

```bash
hermes claw migrate
```

Команда импортирует пользовательские настройки, базы памяти и скиллы. Особенности работы утилиты:
- **Безопасность токенов:** ключи API и секреты не затрагиваются, пока явно не передан флаг `--migrate-secrets`.
- **Автоматический бэкап:** перед внесением любых изменений утилита упаковывает рабочую директорию Hermes home в ZIP-архив, делая процесс полностью обратимым.
- **Предварительный просмотр:** флаг `--dry-run` отображает список изменений без модификации файлов на диске.
