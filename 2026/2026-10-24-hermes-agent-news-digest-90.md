## 122 пулл-реквеста, влитых 23 октября

iamlukethedev подсчитал: 23 октября в Hermes влили 122 пулл-реквеста. Среди заметных изменений:

- Автоматизация браузера теперь работает только через `browser_exec`: `agent-browser` и встроенные инструменты браузера удалены, а Camofox переносится в плагин.
- Подтверждения для доверенных MCP-инструментов запоминают выбор: варианты «Allow for this session» и «Always» сохраняются отдельно для каждого инструмента. Если разрешение нужно только для одного вызова, доступны лишь Once и Deny.

В changelog за 23 октября также отмечены:

- Режим YOLO и отключение `approvals.mode`: они больше не запрашивают подтверждение для недоверенных MCP-вызовов записи, кроме случаев превышения лимита расходов.
- Карточки плагинов, которые отвечают в собственном диалоге.
- Отдельный каталог для плагинов Desktop и каталоги, доступ к которым предоставил пользователь.
- Если установку нельзя выполнить, сообщение теперь указывает, какого приложения не хватает.

## Curator поддерживает скиллы агента в порядке

23 октября NetworkChuck рассказал о Curator в Hermes: функция дорабатывает скиллы, удаляет неработающие и автоматически создаёт новые. Документация описывает Curator как фоновое обслуживание скиллов, созданных агентом. Он отслеживает, как часто каждый скилл просматривают, используют и изменяют, а долго не востребованные постепенно переводит из активных в устаревшие, а затем в архив.

Дополнительно можно включить консолидацию с помощью вспомогательной модели. По умолчанию она отключена; при запуске может предложить объединить похожие скиллы или исправить их отклонения.

Curator не удаляет скиллы безвозвратно: в худшем случае он архивирует их в `~/.hermes/skills/.archive/`, откуда их можно восстановить. По умолчанию он обслуживает только созданные агентом скиллы, пропускает закреплённые и используемые в cron-задачах. Проверка запускается после периода бездействия не менее двух часов и с интервалом в семь дней.

## Kimi K3.1 Pro появился на Nous Portal

## draft-cards превращает черновики в карточки

23 октября tonbistudio рекомендовал draft-cards — community-плагин, который показывает черновики писем и сообщений в виде редактируемых карточек, а не сплошного текста.

Когда вы просите Hermes написать письмо, появляется карточка с адресатами, темой и текстом — всё можно проверить перед отправкой. Запрос на правку создаёт новую карточку и подсвечивает конкретные изменённые слова. Текст можно редактировать прямо в карточке; отправка происходит только после нажатия кнопки «Отправить».

Плагин не требует настройки почты, не обращается к сетевым сервисам и не читает токены или учётные записи. Для Hermes 0.22.2 и новее:

```bash
hermes plugins install arsiktech/hermes-draft-cards --enable
```

## Wingtips #109: поиск плагинов

24 октября witcheer опубликовал совет Wingtips #109. Каталог плагинов Hermes — это проверенный список, где плагины можно находить по названию. Искать их можно прямо из терминала:

```bash
hermes plugins search <термин>
```

Введите, например, `weather`, `rss` или `telegram` — Hermes найдёт плагины с подходящими названиями.
