# Новости Hermes Agent #70

В этом выпуске: 91-й выпуск серии советов Wingtips об отправке файлов в Telegram, релиз SDK Hermes Gadget для компактных голосовых устройств на ESP32, 144 pull request, смердженных 3 октября, упрощение настройки Discord и плагин для Stream Deck от сообщества.

## Wingtips #91: отправка файлов в Telegram

witcheer посвятил 91-й выпуск Wingtips отправке файлов в Telegram. Агент больше не ограничен простым текстом: достаточно указать желаемый формат прямо в сообщении — например, «send me that as a PDF», — и Hermes сгенерирует файл и отправит его. Сценарий рассчитан на то, чтобы сохранить документ и прочитать его позже на телефоне или переслать кому-то еще.

В документации Telegram раскрывается техническая часть: шлюз извлекает теги `MEDIA:/chemin/vers/fichier` из ответов агента и пересылает указанный файл в качестве нативного вложения платформы. Поддерживаются изображения, аудио, видео, документы (pdf, txt, md, csv, json и др.), архивы и книги. Публичный Bot API Telegram ограничивает размер загружаемых файлов до 20 МБ; локальный демон telegram-bot-api поднимает этот лимит до 2 ГБ, а Hermes автоматически адаптирует внутренний лимит, как только настроен параметр `base_url`.

## Hermes Gadget: открытый SDK для голосовых устройств на ESP32

4 октября adolandev представил Hermes Gadget — открытый SDK для компактных устройств, взаимодействующих с персональным экземпляром Hermes. Суть концепции передает ее слоган: зажать кнопку, задать вопрос, выслушать ответ. Пользователь говорит, Hermes слушает, размышляет и отвечает голосом, пока дисплей отображает текущее действие; если требуется разрешение, агент запрашивает его прямо на экране устройства. Teknium лаконично оценил релиз фразой «We got ESP32 at home».

В репозитории hermes-gadget-sdk, опубликованном 4 октября в версии v0.1.0, детально описан состав проекта: портативное ядро на C++17 с портом прошивки под ESP32 и десктопным эмулятором, плагин для платформы Hermes (концентратор устройств, адаптер шлюза, инструменты агента), протокол взаимодействия, инструментарий и документация. Устройство привязывается аналогично телефону: оно выводит код, который подтверждается на хосте Hermes, после чего проходит аутентификацию по собственному ключу. Гаджет сообщает о поддерживаемых действиях (светодиоды, реле, зуммер), которыми может управлять Hermes, а также умеет выводить карточки и считывать данные датчиков. Плагин устанавливается через `hermes plugins install` и интегрируется в `hermes gateway setup`; браузерный установщик, развернутый на GitHub Pages, прошивает устройство по протоколу Web Serial с помощью esptool-js. Проект позиционируется как неофициальный и не связан с Nous Research.

> Источники: [@adolandev, Hermes Gadget is an open SDK for a small device..., 4 октября 2026](https://x.com/adolandev/status/2106624035090059630), [@Teknium, We got ESP32 at home, 4 октября 2026](https://x.com/Teknium/status/2106632146484162773) и [Adolanium/hermes-gadget-sdk, репозиторий GitHub](https://github.com/Adolanium/hermes-gadget-sdk)

## 144 pull request, смердженных 3 октября

4 октября iamlukethedev подвел статистику: 3 октября в Hermes было смерджено 144 pull request. В тексте публикации упоминаются два изменения, остальные представлены на прикрепленном скриншоте:

- Desktop считает Ultrafast отдельным полноценным уровнем скорости, а функция keep-awake теперь может предотвращать уход компьютера в спящий режим только во время активной работы агента.
- Боты в Desktop сохраняют идентичность каждого бэкенда при холодных запусках, переподключениях и общих профилях.

> Источник: [@iamlukethedev, Hermes merged 144 PRs on October 3, 4 октября 2026](https://x.com/iamlukethedev/status/2106621938118578278)

## Настройка Discord стала проще

4 октября Teknium объявил, что процесс интеграции Hermes с Discord теперь станет менее запутанным и неприятным. witcheer, активный пользователь Discord, назвал это отличным апдейтом для работы своего агента.

В документации Discord описан ускоренный процесс: после создания приложения и копирования токена бота команда `hermes gateway setup` проверяет токен на стороне Discord, сообщает, если отключен интент Message Content Intent (приводя прямую ссылку на нужный раздел настроек), генерирует готовую инвайт-ссылку для сервера и добавляет пользователя в список разрешенных без необходимости включать Developer Mode. Неактивный интент — главная причина, по которой боты не запускаются: без него Discord отклоняет соединение.

> Источники: [@Teknium, Setting up your Hermes with Discord should now be a little less confusing or painful, 4 октября 2026](https://x.com/Teknium/status/2106563883058274541), [@witcheer, as a Discord heavy user, this is a wonderful update, 4 октября 2026](https://x.com/witcheer/status/2106615308781797813) и [Discord, документация Hermes Agent](https://hermes-agent.nousresearch.com/docs/user-guide/messaging/discord)

## Плагин для Stream Deck от сообщества

3 октября witcheer показал плагин для Stream Deck под Hermes Agent, созданный сообществом. В сообщении описаны три действия: Start Run отправляет агенту заранее сохраненный промпт и показывает статус выполнения в реальном времени прямо на кнопке, Steer Run передает дополнительную инструкцию во время работы агента, а Stop Run прерывает выполнение. Сами промпты можно вставлять из буфера обмена или вводить через компактное поле ввода.

> Источник: [@witcheer, a Stream Deck plugin for Hermes Agent, made by the community, 3 октября 2026](https://x.com/witcheer/status/2106477981400957422)
