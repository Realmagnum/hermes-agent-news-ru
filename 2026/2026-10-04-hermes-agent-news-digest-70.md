## Wingtips #91: отправка файлов в Telegram

@witcheer посвятил 91-й выпуск серии Wingtips передаче файлов через Telegram. Теперь агент не ограничивается текстовыми ответами: достаточно явно указать нужный формат прямо в сообщении (например, «send me that as a PDF»), и Hermes сформирует файл, после чего отправит его в диалог. Это позволяет сгенерировать документ на лету, чтобы прочитать его позже на телефоне или переслать другим пользователям.

В официальной документации описан механизм взаимодействия: шлюз считывает теги вида `MEDIA:/путь/к/файлу` из ответов агента и пересылает указанный файл как нативное вложение платформы. 

Поддерживается широкий спектр форматов:
- Изображения, аудио и видео.
- Документы (`.pdf`, `.txt`, `.md`, `.csv`, `.json` и др.).
- Архивы и электронные книги.

Стандартный публичный Telegram Bot API ограничивает размер загружаемых файлов до 20 МБ. Использование локального демона `telegram-bot-api` поднимает этот лимит до 2 ГБ, при этом Hermes автоматически масштабирует свои внутренние ограничения, как только в конфигурации определяется параметр `base_url`.

## Hermes Gadget: открытый SDK для голосовых устройств на ESP32

Разработчик @adolandev представил **Hermes Gadget** — открытый SDK для создания компактных аппаратных терминалов, взаимодействующих с персональным экземпляром Hermes. Концепция выражена в лаконичном принципе: зажать кнопку, задать вопрос и слушать ответ. Пользователь говорит — Hermes слушает, рассуждает и отвечает голосом, транслируя ход выполнения задачи на экран. Если агенту требуется подтверждение операции, он запрашивает аппрув непосредственно на экране гаджета. @Teknium иронично прокомментировал релиз фразой: «We got ESP32 at home».

Репозиторий `hermes-gadget-sdk`, выпущенный в версии `v0.1.0`, содержит:
- Портативное ядро на C++17 с портами прошивки для микроконтроллеров ESP32 и десктопным симулятором.
- Плагин для платформы Hermes (концентратор устройств, адаптер шлюза, наборы инструментов для агента).
- Протокол коммуникации, сопутствующий тулинг и документацию.

Гаджет сопрягается по принципу мобильного клиента: он выводит код, подтверждаемый на хосте Hermes, после чего проходит аутентификацию по собственному ключу. Устройство умеет регистрировать периферийные действия (управление светодиодами, реле, зуммером), доступные для вызова агентом, а также отображать карточки и опрашивать сенсоры.

Плагин ставится через команду `hermes plugins install` и подключается к мастеру `hermes gateway setup`. Для быстрой прошивки доступен веб-инсталлятор на GitHub Pages, прошивающий устройство через Web Serial с помощью `esptool-js`. Проект является полностью независимой разработкой сообщества и не аффилирован с Nous Research.

## 144 пулл-реквеста за 3 октября

@iamlukethedev подвел итоги рекордного дня разработки: 3 октября кодовая база Hermes приняла 144 пулл-реквеста. 

Среди ключевых изменений:
- **Desktop-клиент:** режим **Ultrafast** теперь обрабатывается как полноценный уровень скорости инференса, а системная функция **keep-awake** получила опцию удержания хоста в активном состоянии только на время выполнения задач агента.
- **Идентичность ботов:** клиенты в Desktop теперь корректно сохраняют привязку к бэкендам при «холодных» перезапусках, реконнектах и использовании общих профилей.

## Упрощение настройки шлюза Discord

По словам @Teknium, процесс интеграции Hermes с Discord избавился от лишних сложностей. @witcheer, активно использующий Discord для рабочих процессов, также высоко оценил обновление.

Обновленный интерактивный мастер `hermes gateway setup` взял на себя рутинную валидацию:
- После создания приложения и ввода токена утилита сама проверяет его валидность через API Discord.
- Детектирует отсутствие флага **Message Content Intent** (главная причина, почему боты не могут подключиться к серверам) и сразу выдает прямую ссылку на нужный тумблер в консоли Discord Developer Portal.
- Генерирует готовую ссылку с корректными скоупами для добавления бота на сервер.
- Автоматически прописывает пользователя в whitelist без необходимости вручную включать Developer Mode в Discord и копировать ID учетной записи.

## Плагин для Stream Deck от сообщества

@witcheer поделился плагином для **Stream Deck**, созданным энтузиастами экосистемы Hermes Agent. Модуль добавляет три аппаратных действия для управления агентом:
- **Start Run** — отправляет заранее сохраненный промпт агенту и выводит динамический статус выполнения прямо на клавишу.
- **Steer Run** — отправляет дополнительную инструкцию для корректировки контекста прямо во время работы агента.
- **Stop Run** — принудительно прерывает выполнение текущей сессии.

Промпты для запуска можно передавать как через буфер обмена, так и из компактного поля ввода на деке.
