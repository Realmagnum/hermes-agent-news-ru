# Новости Hermes Agent #32

Этот выпуск посвящён стабильному релизу v0.20.6, смене модели из любого чата, настольному клиенту, управляющему всеми удалёнными машинами, переработанному каталогу моделей Nous Portal и закрытию инстанций Nitter под давлением X Corp.

## Hermes Agent v0.20.6 (v2026.8.27)

Nous Research выпустила патч-версию v0.20.6, включающую около 525 слитых pull requests с v0.20.5 — примерно 1 313 коммитов по 1 557 файлам.

Ключевые изменения:
- Консенсусная навигация с реальным профилем: используется профиль Chromium по умолчанию для локальной навигации, со штатным механизмом закрытия по подтверждению на Windows.
- В настольном приложении браузер получил собственное окно ОС, SSH-движок удалённого обновления и канал профилей флота.
- Расширение каталога удалённых MCP-серверов: более 50 серверов от вендоров, протестированных в реальных условиях (Cloudflare, Grafana Cloud, Better Stack, Railway).
- Кеширование результатов с ограничением срока жизни (TTL) для web_search и web_extract.
- Сжатие lean-tail по умолчанию.
- tool_search с поддержкой множественных запросов и стемминга.
- Опциональное шифрование secrets, хранящихся через системный менеджер паролей, избавляет от необходимости каждый раз вводить пароль Keychain на macOS.
- Модули обновления приостанавливают gateway через control socket вместо принудительного завершения всего дерева процессов.
- Инсталляции на базе образов и пакетов не принимают небезопасные обновления на месте (фаза 3 issue #91277).
- Cron: долговременные подтверждения приёма инцидентов и более понятные сообщения об ошибках рассинхронизации кода.
- Контроль раскрытия ссылок Slack.
- Общие идентификаторы докер-контейнеров.
- Встраиваемые бэкенды терминальных окружений.
- Новые модели в селекторах: GLM-5.3 Flash, MiniMax M3 (бесплатно) и MiniMax H3 Max (видео).

Полные release notes и список контрибьюторов появятся в v0.21.0.

## Hermes Wingtips #56: смена модели из любого места

Пятьдесят шестой номер серии от witcheer посвящён изменению модели «на лету» вне зависимости от клиента. Команда `hermes model` открывает интерактивный селектор, что исключает использование через пайплайн, скрипт или терминал другого агента. Обходное решение — вообще не пользоваться селектором: в любом чате и на любой платформе достаточно выполнить `/model grok-4 --provider` вместе с адресом провайдера — и модель переключится напрямую.

> Источник: [@witcheer — Hermes Wingtips #56: смена модели из любого места, 27 августа 2026](https://x.com/witcheer/status/2092941623961190832)

## Единое окно настольного приложения для управления всеми машинами

Witcheer показал, как десктопный клиент Hermes управляет всеми машинами, где живут его агенты: облачный VPS, сервер через SSH или локальная gateway — все они подключаются, и переключение между ними происходит через нижнюю панель состояния. Все профили подключенных gateway отображаются единым списком в один клик. Демонстрация показывает SSH-движок удалённого обновления и канал профилей флота, появившиеся в v0.20.6.

> Источник: [@witcheer — Единый интерфейс десктопа для всех машин, 27 августа 2026](https://x.com/witcheer/status/2092861480098058328)

## Nous Portal: полностью переработанная страница каталога моделей

Nous Research полностью переработала страницу каталога моделей Nous Portal: теперь всё собрано в одном месте — активные бесплатные модели, акции и сортируемый список остальных доступных моделей.

> Источник: [@NousResearch — Новый каталог моделей Nous Portal, 27 августа 2026](https://x.com/NousResearch/status/2092776270333395353)

## Инстанции Nitter останавливаются под давлением X Corp

24 августа 2026 г. X Corp выслала письма о прекращении деятельности, требуя безвозвратного удаления инстанций Nitter и соответствующего репозитория. Общедоступные зеркала закрываются одно за другим: nitter.net объявляет об уходе оффлайн и остановке разработки, инстанция tiekoetter указывает на бессрочное закрытие без сроков возвращения, а XCancel прекратил работу после получения собственного письма от X Corp. Сообщение инстанция tiekoetter ведёт на предыдущий коммит с юридическим уведомлением и общественную дискуссию в репозитории Nitter. Остановка этих зеркал сокращает свободный доступ к X для мониторинга экосистемы.
