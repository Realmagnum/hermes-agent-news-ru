## Релиз Hermes Agent v0.20.6 (v2026.8.27)

Команда Nous Research представила патч-релиз **v0.20.6**. Обновление вобрало в себя 525 пулл-реквестов, смердженных с момента выхода v0.20.5 — это суммарно около 1 313 коммитов, затронувших 1 557 файлов.

**Ключевые изменения:**
- **Полноценный браузинг с подтверждением (consented real navigation):** агент теперь умеет задействовать дефолтный профиль Chromium для локальной веб-навигации с запросом на подтверждение закрытия окон в Windows.
- **Десктопный браузер:** компонент получил отдельное нативное окно ОС, механизм удаленного обновления по SSH и боковую панель управления профилями парка инстансов (fleet profiles rail).
- **Расширение каталога удаленных MCP-серверов:** добавлено свыше 50 проверенных на практике вендорских серверов, среди которых Cloudflare, Grafana Cloud, Better Stack и Railway.
- **TTL-кэширование** для результатов инструментов `web_search` и `web_extract`.
- **Сжатие lean-tail** теперь включено по умолчанию.
- Мультизапросный поиск инструментов `tool_search` со стеммингом (stemming).
- Опциональное шифрование локальных секретов через системный keychain — устраняет навязчивые системные диалоги macOS при каждом запуске агента.
- **Безопасные обновления:** апдейтеры теперь приостанавливают шлюзы через контрольный сокет вместо принудительного убийства дерева процессов.
- Установки на базе образов и пакетных менеджеров теперь блокируют небезопасные in-place обновления (3-я фаза решения issue #91277).
- **Cron:** внедрены долговечные подтверждения инцидентов (durable acknowledgments) и более наглядные отчеты об ошибках при рассинхронизации кода.
- Контроль разворачивания превью ссылок (unfurling) в Slack.
- Общие идентификаторы контейнеров в Docker.
- Подключаемые бэкенды для терминальных сред.
- **Новые модели в селекторах:** GLM-5.3 Flash, бесплатная MiniMax M3 и видеомодель MiniMax H3 Max.

Полный чейнджлог и список контрибьюторов разработчики опубликуют вместе с мажорным релизом v0.21.0.

## Hermes Wingtips #56: переключение модели на лету

В пятьдесят шестом выпуске серии заметок @witcheer разобрал удобный способ смены активной LLM из любого интерфейса. 

Обычная команда `hermes model` открывает интерактивный терминальный селектор, что делает невозможным ее вызов через пайпы (`|`), bash-скрипты или терминальные тулы других агентов. Решение заключается в обходе интерактивного меню: прямо в чате на любой платформе можно выполнить команду в одну строку:

```bash
/model grok-4 --provider <адрес_провайдера>
```

Команда переключает используемую модель мгновенно и без лишних подтверждений.

## Единое десктопное окно для управления всеми машинами

@witcheer показал возможности нового десктопного интерфейса Hermes: теперь из единого окна можно централизованно администрировать все хосты, на которых запущены агенты.

Облачные VPS, удаленные серверы, подключенные по SSH, и локальные шлюзы объединяются в одном месте, а переключение между ними происходит в один клик через нижний статус-бар. Все профили со всех активных шлюзов отображаются единым списком. Демонстрация отлично иллюстрирует работу движка SSH-обновлений и панели профилей флота, представленных в свежем релизе v0.20.6.

> **Источники:**
> - [@witcheer — Одно десктопное окно для контроля всей инфраструктуры (27 августа 2026)](https://x.com/witcheer/status/2092861480098058328)
