## Hermes Agent v0.22.5: исправления и настраиваемая делегация

22 октября Teknium выпустил **v0.22.5** — обновление с исправлениями и 81 пулл-реквестом, смерженным со времени v0.22.4. Версия доступна как стабильный релиз на GitHub (CLI и установщики), в Microsoft Store, Docker и Hermes Cloud. Полные отредактированные заметки за этот период появятся в v0.23.0.

Между v0.22.4 и коммитом `bf0203a794a` вошло 231 коммит без мержа: изменено 804 файла (+35 212 / −17 885 строк), смержен 81 пулл-реквест и закрыто 30 задач.

Главные изменения:
- **Переработан вход через Nous:** авторизация выполняется через простой device login; гостевой режим бесплатного тарифа предлагает войти в аккаунт, а интерфейс показывает, кто подключён. Коннекторы предлагают авторизацию вместо перехода в гостевой режим.
- `hermes update` теперь удерживает стабильный релиз, если тот не проходит проверку.
- В Windows исправлено зависание `hermes update` на старом лаунчере после смены закреплённой версии Python.
- Добавлена поддержка тарифов с лимитом на временное окно: индикаторы плана, карточки ограничений и восстановление после смены модели.
- **Бэкенды делегации стали подключаемыми:** подагенты маршрутизируются по карте моделей или профилю; профиль можно менять для каждой сессии.
- Slash-команды плагинов могут предлагать выбрать вариант.
- Добавлена команда `hermes import-agent` и миграция из OpenClaw.
- `hermes mcp serve` и бэкенд Singularity вынесены из ядра в плагины. Установщик предлагает импортёр, если обнаруживает другого агента.
- В Desktop сессии можно закреплять перетаскиванием в сайдбар, а плагины устанавливать в один клик; отображаются значки тарифных уровней.
- Обновлены Electron до 44 и Pillow до 13, а также ряд зависимостей безопасности.
- Если рабочая папка разговора удалена, пользователь увидит понятное сообщение.
- `hermes update` восстанавливает приостановленные шлюзы после повреждения `.git`.
- Длинные ответы Claude DirectSDK больше не обрезаются таймером блокировки.
- В групповых разговорах Desktop снова видно, какой бот работает.
- Добавлен экспериментальный клиент событий MCP в режиме webhook.

> - [Репозиторий GitHub Hermes Agent — Hermes Agent v0.22.5 (22 октября 2026)](https://github.com/NousResearch/hermes-agent/releases/tag/v0.22.5)

## 48 пулл-реквестов смержено за 22 октября

23 октября iamlukethedev подвёл итоги: за 22 октября в Hermes смержили **48 пулл-реквестов**. Среди заметных изменений — подключаемые бэкенды делегации: можно выбрать режим по умолчанию, карту моделей или профили. В Desktop появились настройки делегации с выбором режима, редактором маршрутов моделей и маршрутами профилей. Расширенная делегация добавлена в официальный каталог.

В журнале изменений за 22 октября также отмечены:
- поддержка тарифов с лимитами на временное окно;
- исправление разрешения зависимостей через `uv` с последней версией инструмента;
- исправление лаунчера Windows после смены закреплённой версии Python;
- обновление `edge-tts`, устраняющее ошибку 403 в Edge TTS;
- закрепление сессий в сайдбаре перетаскиванием;
- перенос `hermes mcp serve` в плагин `mcp-serve`.

## Cua Spaces: изолированный компьютер для Hermes

22 октября Nous Research представила плагин **Cua Spaces**. Он предоставляет Hermes отдельную Linux-, macOS- или Windows-среду на уже имеющемся оборудовании. Команда может открыть её, наблюдать за работой в реальном времени, вмешаться и передать управление обратно, пока Hermes продолжает работу.

Плагин переносит терминал, файлы и выполнение кода Hermes на изолированную машину, а сам Hermes остаётся на компьютере пользователя. Можно следить за ходом работы, щёлкнуть, чтобы перехватить управление, а затем снова позволить агенту продолжить. Для настройки достаточно одной команды:

```bash
hermes config set terminal.backend cua
```

По завершении задачи изолированная среда удаляется.

## Herald выходит на Android

23 октября iamlukethedev сообщил, что **Herald**, приложение Hermes Bots, теперь доступно на Android — на следующий день после начала публичного бета-тестирования через TestFlight.

Настройка прежняя: запустите команду на компьютере, отсканируйте QR-код — и боты Hermes появятся в телефоне. Можно подтвердить рискованный шаг прямо из уведомления, отправить ссылку из Chrome боту и создать групповые разговоры, где боты отвечают по очереди.

> **Источники:**
> - [@iamlukethedev — Herald теперь на Android (23 октября 2026)](https://x.com/iamlukethedev/status/2113434773901472088)

## Meshy предлагает месяц Pro за один доллар

22 октября Nous Research объявила акцию для пользователей Hermes: месяц тарифа **Meshy Pro** за один доллар. В тариф входят доступ к API и 1 000 кредитов. После оформления подписки и установки плагина нужно создать ключ на meshy.ai и вставить его в Hermes Desktop: «Настройки» → «Плагины» → «Meshy».

По словам Teknium, Meshy связалась с командой при запуске плагина и предоставила купоны. Через плагин можно из разговора превратить текстовый запрос или фотографию в 3D-модель, наложить текстуры, добавить скелет и анимацию, а также подготовить модель к 3D-печати. Обычно Meshy Pro стоит 20 долларов в месяц.

## Uncommon Web: каталог веб-библиотек, созданный Hermes

22 октября Teknium рассказал, как ему показали JavaScript-библиотеку для дизеринга. Он передал её Hermes Agent и попросил сделать веб-страницу с демонстрациями малоизвестных библиотек стилей и компонентов. Через двадцать минут сайт был готов. В течение дня Teknium продолжал добавлять находки: каталог вырос примерно с 75 до **462 демонстраций**, охватывающих **425 библиотек в 23 разделах**.

Сайт **Uncommon Web** — практический справочник необычных по стилю веб-библиотек. Каждая демонстрация запускается прямо на странице и сопровождается командой установки, фрагментом кода и лицензией. Темы — от дизеринга, пиксельной графики и ASCII до брайлевской графики и игровых движков.
