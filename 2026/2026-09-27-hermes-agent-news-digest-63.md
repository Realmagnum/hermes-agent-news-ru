## Простой режим в Hermes Desktop

Разработчик @witcheer представил упрощенный режим (**Simple mode**) для Hermes Desktop. Интерфейс переключается исключительно на чат, а все технические и служебные панели автоматически сворачиваются.

Включить простой режим можно тремя способами:
- Через командную палитру: нажать `Cmd+K` (`Ctrl+K` в Windows/Linux) и ввести команду `simple`;
- Через настройки: **Settings → Appearance → Window and layout → UI Mode**;
- Горячими клавишами `Cmd+Shift+\` (`Ctrl+Shift+\`), открывающими редактор раскладки интерфейса, где достаточно выбрать пресет **Simple**.

## Wingtips #85: команды hermes pause и hermes resume

В 85-м выпуске серии заметок Wingtips автор @witcheer разобрал работу команды `hermes pause`. Она позволяет моментально заблокировать запуск новых задач агентом.

Пока действует пауза:
- Не срабатывают cron-задачи;
- Не берутся в работу карточки из канбана;
- Боты на шлюзах (gateway) не начинают новые циклы генерации ответов.

Снять блокировку можно обратной командой:

```bash
hermes resume
```

Фича особенно удобна в случаях, когда фоновая задача ведет себя нештатно, и выполнение процессов требуется экстренно приостановить без полного отключения окружения.

## Инструкция от Twilio: подключение агента по SMS

В блоге для разработчиков Twilio вышло практическое руководство по привязке агента Hermes к выделенному телефонному номеру для общения по SMS (автор — Amanda Lange). 

**Архитектура решения:**
- Hermes Agent запущен на выделенном Mac mini;
- В качестве LLM-бэкенда используется бесплатная модель через аккаунт Nous Research;
- Учетные данные Twilio (`AccountSID` и `Auth Token`), а также настроенный на отправку SMS номер вносятся в дашборд агента.

Интересная деталь: автор попросила агента самостоятельно настроить вебхук. Hermes Agent без посторонней помощи поднял туннель через `ngrok`, ссылаясь на собственную встроенную документацию по интеграции с SMS. На следующее утро агент в полностью автономном режиме отправил SMS-оповещение владельцу о том, что у него заканчиваются бесплатные токены.

## Нативный терминальный режим hermes --native

Разработчик @tonbistudio показал режим работы интерфейса в основном буфере терминала:

```bash
hermes --native
```

В отличие от стандартного TUI-интерфейса, который разворачивается в альтернативном буфере экрана (alternate screen), нативный режим рендерится напрямую в текущем окне консоли. Это убирает экран загрузки и, главное, сохраняет всю историю скроллбэка терминала после завершения работы с агентом.

> **Источники:**
> - [@tonbistudio — Have you tried the new native terminal mode for Hermes Agent? hermes --native (27 сентября 2026)](https://x.com/tonbistudio/status/2104079178845032667)

## Дайджест релизов: 161 пулл-реквест за 26 сентября

По подсчетам @iamlukethedev, за одни сутки 26 сентября в кодовую базу Hermes Agent было смерджено 161 пулл-реквест. Распределение по категориям:
- Интерфейс: 26
- Голосовые функции и Realtime: 1
- Инструменты разработчика и плагины: 79
- Безопасность и управление секретами: 8
- Интеграции и чат: 14
- Стабильность и оптимизация: 33

**Главные изменения:**
- **Поддержка скриптовых cron-задач в UI:** исправлена давняя проблема отображения. Задачи работали штатно, но в интерфейсе показывались с пустыми описаниями, без бейджа *Script* и со статусом «нет запусков». Теперь задачи и история их исполнения отображаются корректно.
- **Claude Opus 5.5:** модель добавлена в селекторы провайдеров Anthropic и Bedrock. Для Bedrock Opus 5 и 5.5 поддержано контекстное окно в 1 млн токенов.
- **Стриминг ответов:** устранено дублирование слов при переключении превью на новое сообщение.
- **Безопасность API-ключей:** прямой ключ `OPENAI_API_KEY` гарантированно изолирован и ни при каких условиях не перенаправляется на шлюзы OpenRouter.
- **Голосовой стек:** заработал TTS-стриминг для xAI, исключена утечка API-ключей Gemini в URL-параметрах, а служебные токены завершения цепочки рассуждений (reasoning end-tokens) больше не озвучиваются голосом.
- **Отказоустойчивость cron:** планировщик продолжает работу даже при наличии поврежденных записей в `jobs.json` или некорректных счетчиков повторов.
- **Обработка прерываний:** по нажатию `Ctrl+C` выводится ровно тот фрагмент частичного ответа, который был сохранен в сессии (как в вебе, так и в десктопном приложении).
- **Кастомизация UI:** в настройках оформления появилась опция *File Browser*, а пользовательские CSS-стили больше не сбрасываются при обновлении приложения.
- **Сетевой стек:** облачный портал корректно удерживает сессию при сбоях редиректов, а версия для macOS использует системные сертификаты из Keychain для подключения к удаленным шлюзам.
