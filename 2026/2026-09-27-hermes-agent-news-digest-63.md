# Новости Hermes Agent #63

В этом выпуске: простой режим в Hermes Desktop, команда `hermes pause` из серии Wingtips, руководство по Twilio для подключения агента к телефонному номеру по SMS, первое официальное мероприятие Hermes в Малайзии, нативный режим терминала `hermes --native` и обзор 161 пулл-реквеста, принятого 26 сентября.

## Простой режим в Hermes Desktop

27 сентября witcheer объявил о появлении простого режима в Hermes Desktop: остается только окно диалога, а технические панели сворачиваются. Включить его можно тремя способами: нажать Cmd+K (Ctrl+K в Windows и Linux) и ввести «simple»; перейти в Настройки → Внешний вид → Окно и разметка → Режим интерфейса; либо нажать Cmd+Shift+\ (Ctrl+Shift+\), чтобы открыть редактор разметки и выбрать Simple.

> Источник: [@witcheer, Simple mode in Hermes Desktop: chat only, the technical panes fold away, 27 сентября 2026](https://x.com/witcheer/status/2104254609661309025)

## Wingtips #85: hermes pause и hermes resume

85-й выпуск Wingtips witcheer посвятил команде `hermes pause`, которая запрещает Hermes Agent запускать новые задачи. Пока она активна, cron-задачи не срабатывают, задачи из канбана не отправляются, а боты шлюза не начинают новые циклы обработки. Команда `hermes resume` снимает паузу. Это особенно полезно, когда запланированная задача выполняет действия, которые в данный момент лучше приостановить.

> Источник: [@witcheer, Hermes Wingtips #85: hermes pause, 27 сентября 2026](https://x.com/witcheer/status/2104227606614757460)

## Руководство по Twilio для связи с агентом по SMS

27 сентября witcheer поделился руководством из блога для разработчиков Twilio, в котором агент Hermes получает собственный телефонный номер для общения по SMS. В статье Аманды Ланге (Amanda Lange) от 21 сентября подробно описан процесс настройки: Hermes Agent разворачивается на выделенном Mac Mini, через аккаунт Nous Research выбирается бесплатная модель, после чего учетные данные Twilio (AccountSID и Auth Token) и номер с поддержкой SMS указываются в панели управления.

Автор попросила агента напрямую настроить вебхук, с чем он справился самостоятельно, а затем поднял туннель ngrok; при этом Hermes даже сослался на собственную документацию по SMS. После настройки номера ответное сообщение на отправленное SMS приходит напрямую от агента. Утром агент сам прислал ей SMS, предупредив, что бесплатные токены подходят к концу.

> Источники: [@witcheer, Twilio's developer blog has a Hermes Agent tutorial: your agent on its own phone number, over SMS, 27 сентября 2026](https://x.com/witcheer/status/2104206409881526365) и [Sending SMS with an Agentic AI using Twilio and Hermes Agent, Amanda Lange, 21 сентября 2026](https://www.twilio.com/en-us/blog/developers/tutorials/integrations/sending-sms-agentic-ai-using-twilio-hermes-agent)

## Нативный режим терминала hermes --native

27 сентября tonbistudio представил новый нативный режим терминала для Hermes Agent, запускаемый командой `hermes --native`. Интерфейс отображается прямо в терминале без переключения на альтернативный экран: нет заставки при запуске, а терминал сохраняет историю прокрутки после выхода из интерфейса. Разница наглядно продемонстрирована на видео.

> Источник: [@tonbistudio, Have you tried the new native terminal mode for Hermes Agent? hermes --native, 27 сентября 2026](https://x.com/tonbistudio/status/2104079178845032667)

## 161 пулл-реквест слит 26 сентября

27 сентября iamlukethedev подвел итоги: 26 сентября в Hermes Agent был слит 161 пулл-реквест. Они распределились по следующим категориям: интерфейс (26), голос и работа в реальном времени (1), инструменты и плагины для разработчиков (79), безопасность и секреты (8), интеграции и чат (14), а также стабильность (33). Среди наиболее заметных изменений:

- В интерфейсе наконец-то отображаются скриптовые cron-задачи и история их выполнения.
- Claude Opus 5.5 добавлен в селекторы Anthropic и Bedrock; для Bedrock Opus 5 и 5.5 доступен контекст в 1 миллион токенов.
- Потоковые ответы больше не повторяют слово при переключении предпросмотра на новое сообщение.
- Настоящий ключ `OPENAI_API_KEY` ни при каких условиях не маршрутизируется и не отправляется на OpenRouter.
- В голосовом модуле: заработал потоковый TTS от xAI, ключи Gemini больше не остаются в URL, а рассуждения модели (reasoning) больше не озвучиваются вслух.
- Cron-задачи продолжают срабатывать, даже если в jobs.json есть поврежденные записи либо бесконечные или отрицательные счетчики повторов.
- Сочетание Ctrl+C отображает тот же частичный ответ, что сохраняется в сессии, как в консольном интерфейсе, так и в десктопном приложении.
- В интерфейс добавлена настройка File Browser в разделе «Внешний вид», а пользовательские стили CSS сохраняются при обновлениях.
- Портал Cloud сохраняет сессию при сбое редиректа, а macOS теперь доверяет центрам сертификации из связки ключей при подключении к удаленным шлюзам.

Накануне iamlukethedev подробно описал проблему со скриптовыми cron-задачами: они действительно работали, но интерфейс не мог их отобразить, из-за чего описание оставалось пустым, бейдж Script отсутствовал, а статус ошибочно показывал «нет запусков».

Desktop just couldn't see it, 26 сентября 2026](https://x.com/iamlukethedev/status/2103993691816018264)
