# Новости Hermes Agent #67

В этом выпуске: совместный туториал NVIDIA и Nous по трассировке запусков Hermes Agent с помощью NeMo Relay, поддержка языковых пакетов в системном плагине, 133 пулл-реквеста, влитых 30 сентября, команда `/context` в выпуске Wingtips, быстрый способ прикреплять веб-страницы, файлы и папки к сообщениям, а также карта памяти в Hermes Desktop.

## NVIDIA и Nous опубликовали руководство по трассировке запусков Hermes Agent

30 сентября NVIDIA и Nous Research выпустили совместное руководство, демонстрирующее, как трассировать и оценивать выполнение задач Hermes Agent с помощью NeMo Relay. Авторы публикации (William Markito Oliveira, Maryam Najafian, Moon Chung и Teknium) исходят из того, что агент может решить задачу неоптимальным путем, а простой проверки статуса успешности недостаточно: она не объясняет, почему агент восстановился после ошибки вызова инструмента, завершил работу раньше времени или совершил цепочку лишних обращений к модели.

Hermes Agent нативно поддерживает NeMo Relay, сопоставляя сессии, шаги (turns), вызовы моделей и вызовы инструментов с иерархией областей видимости (scopes) NeMo Relay. Каждый запуск формирует три представления данных: поток ATOF (JSONL-лог начала и завершения областей видимости с идентификаторами и таймстемпами), траекторию ATIF (пошаговую JSON-запись взаимодействий, вызовов инструментов и наблюдений) и спаны OpenTelemetry с разметкой OpenInference, которые можно визуализировать в совместимых инструментах вроде Arize Phoenix.

В руководстве разбираются два примера. Первый — демонстрационный: в изолированном Docker-контейнере запускается скрипт, выводящий `VALUE=42`, что позволяет убедиться в корректности всей связки. Второй — комплексная исследовательская задача с несколькими инструментами: Hermes изучает папку с документами о поездке, ищет информацию в интернете, проверяет данные конференции на официальном сайте, пишет отчет и должен вернуть `COLT 2026`, при этом все спаны обращений к модели и вызовам инструментов отправляются в Phoenix.

Далее авторы приводят кейс-стади Hermes ToolPerf, где на выборке из 108 прогонов сравниваются базовая и исправленная версии: Qwen Coder 30B успешно справляется с большим числом задач, но при этом возрастает количество вызовов, объем передаваемых данных и задержка. @witcheer наглядно резюмирует пользу: благодаря NeMo Relay запуск Hermes Agent оставляет полный след — каждый вызов модели, обращение к инструменту, повторная попытка и ошибка снабжены временной меткой. @Teknium добавил, что чем больше данных для анализа доступно разработчикам, тем эффективнее можно оптимизировать тестовую обвязку (harness).

## Системный плагин теперь поддерживает языковые пакеты

1 октября @Teknium объявил, что теперь через плагины можно добавлять полноценную поддержку новых языков для всех интерфейсов Hermes в дополнение к шестнадцати уже доступным. @witcheer емко подытожил анонс: теперь агент говорит на любом языке.

Механизм опирается на параметр `provides_locales` в файле `plugin.yaml`. Языковой пакет может добавить новый язык интерфейса или переопределить формулировки существующего сразу на всех уровнях: в ядре Python (запросы подтверждения, ответы шлюзов, глаголы действий инструментов), в TUI-интерфейсе и в приложении Desktop. Писать код на Python не требуется — достаточно объявить локаль и добавить соответствующие YAML-файлы в директорию `locales/` плагина.

Каталоги переводов поддерживают наложение и частичную локализацию: пакет переводит только то, что в нем определено, а недостающие строки берутся из базового каталога или английской версии — сырые ключи пользователю никогда не показываются. При этом добавление языкового пакета не меняет язык автоматически: выбор пользователя по-прежнему задается через параметр `display.language`.

> Источники: [@Teknium, You can now add full new languages across all of Hermes' surfaces via Plugin, 1 октября 2026](https://x.com/Teknium/status/2105520243481411791), [@witcheer, your Hermes Agent now speaks any language, 1 октября 2026](https://x.com/witcheer/status/2105525651729940685) и [Build a Hermes Plugin, Ship a language pack, документация Hermes Agent](https://hermes-agent.nousresearch.com/docs/developer-guide/plugins)

## Wingtips #88: /context

Восемьдесят восьмой выпуск Wingtips @witcheer посвятил команде `/context`. Контекстное окно Hermes Agent содержит намного больше, чем просто сообщения: системный промпт, описания инструментов, память, правила проекта и текущий диалог. Команда наглядно показывает, какую долю занимает каждый из элементов.

В документации подробно описан вывод команды. В CLI и TUI команда `/context` отображает сетку из ста ячеек, где каждая ячейка соответствует примерно одному проценту контекстного окна модели, а затем сводную таблицу по категориям: системный промпт, определения инструментов, правила, индекс скиллов, MCP, субагенты, память и переписка — наряду со свободным пространством. В мессенджерах аналогичная разбивка выводится простым текстом со шкалой заполнения. Команда работает в режиме «только чтение» и рассчитывается локально: без обращений к модели и влияния на кэш промптов. Доступен алиас `/ctx`, а вызов `/context all` выводит детализацию затрат по каждому скиллу и набору инструментов.

> Источники: [@witcheer, Hermes Wingtips #88: /context, 1 октября 2026](https://x.com/witcheer/status/2105552884670550343) и [Slash Commands Reference, /context, документация Hermes Agent](https://hermes-agent.nousresearch.com/docs/reference/slash-commands)

## Прикрепление веб-страниц, файлов и папок к сообщениям

30 сентября @witcheer показал, как передать агенту веб-страницу прямо внутри любого сообщения. В поле ввода достаточно ввести `@`, выбрать `@ url:`, вставить ссылку и задать свой вопрос. Страница будет скачана и прикреплена к сообщению еще до того, как агент начнет его читать.

Через то же меню можно прикрепить файл или папку, а подробный синтаксис описан в руководстве по контекстным ссылкам (context references). Конструкция `@file:путь/к/файлу.py` внедряет содержимое файла с возможностью указать диапазон строк; `@folder:путь/к/папке` передает дерево каталога с метаданными; `@url:` выгружает содержимое веб-страницы. Ссылки разворачиваются до того, как сообщение попадает в модель, а контент добавляется в специальный блок прикрепленного контекста. В одном сообщении можно использовать несколько ссылок, а в интерактивном CLI ввод `@` вызывает автодополнение.

> Источники: [@witcheer, you can hand your Hermes Agent a web page inside any message, 30 сентября 2026](https://x.com/witcheer/status/2105300357421179009) и [Context References, документация Hermes Agent](https://hermes-agent.nousresearch.com/docs/user-guide/features/context-references)

## Карта памяти в Hermes Desktop

1 октября @witcheer опубликовал видео с демонстрацией карты, на которой собрано всё, чему агент научился с момента создания. Золотистыми точками обозначены скиллы, синими ромбами — воспоминания, причем самые старые расположены в центре. При наведении курсора отображается название скилла или суть воспоминания, а правый клик позволяет отредактировать или удалить запись (удаленные скиллы отправляются в архив).

В документации десктопного приложения эта функция называется Memory Graph. Это интерактивная карта изученного материала: скиллы и воспоминания представлены в виде масштабируемого графа узлов с таймлайном и фильтрами («Все», «Используется», «Изучено»). Карту можно открыть из командной палитры или с помощью `/journey` (алиасы: `/learning` и `/memory-graph`). Функция экспорта позволяет поделиться структурой графа в виде компактного кода для вставки без передачи текста самих воспоминаний и скиллов; этот же код можно импортировать обратно.

> Источники: [@witcheer, everything my Hermes Agent has learned for me since I created it is here, 1 октября 2026](https://x.com/witcheer/status/2105636918046183541) и [Hermes Desktop, Memory Graph, документация Hermes Agent](https://hermes-agent.nousresearch.com/docs/user-guide/desktop)
