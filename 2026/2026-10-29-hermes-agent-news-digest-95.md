## 55 пулл-реквестов, влитых 28 октября

В changelog за 28 октября зафиксировано 55 смердженных пулл-реквестов. Разработчик @iamlukethedev подвёл итоги и особо выделил улучшения Webapp: теперь веб-интерфейс ощущается так, словно вы работаете на своей локальной машине.

### Главные изменения:
- **Общая идентичность Webapp и Desktop:** веб-интерфейс теперь использует ту же аутентификацию и профиль, что и Desktop — сессии и групповые чаты бесшовно синхронизируются между ними.
- **Интеграция с автономным бэкендом:** Webapp и автономный бэкенд теперь делят общий список групповых чатов, а прикрепление файлов корректно работает на локальном бэкенде.
- **Возобновление групповых бесед:** чаты, возобновлённые из автономного бэкенда, снова корректно доставляют сообщения и активируют («будят») участников группы.
- **Токен сессии деплоя:** токен сессии деплоя теперь открывает доступ к закрытому дашборду, а бэкенд может считывать его напрямую из файла.
- **Корректная обработка ошибок в `web_extract`:** инструмент теперь честно возвращает ошибку при HTTP-кодах 4xx и 5xx вместо того, чтобы считать такой ответ успешным извлечением контента.
- **Безопасность Firecrawl:** сервис теперь повторно проверяет политики сайта для целевого URL после прохождения всех HTTP-редиректов.
- **Быстрый `capture_screenshot`:** инструмент больше не зависает на 60 секунд при попытке сделать снимок скрытой вкладки браузера.
- **Оптимизация Docker-образов:** новые агенты, развёрнутые в Docker, больше не пересобирают виртуальное окружение при первом запуске ради пакета `fal`.

Дополнительно в changelog отмечен плагин удалённой конфигурации **Hermes Cloud** — опциональный (opt-in) режим, позволяющий администраторам централизованно управлять настройками агентов через облачный сервис вместо локальных файлов конфигурации.

## Herald готовит десктопное приложение для всех ботов

29 октября @iamlukethedev анонсировал появление **Herald** на десктопе. Herald автоматически обнаруживает существующий инстанс Hermes Agent на Mac и в один клик объединяет всех ботов в едином окне.

### Ключевые возможности Herald:
- **Групповые чаты агентов:** боты могут работать сообща в одном контексте — например, один агент перепроверяет расчёты или код другого.
- **Раздельный экран (Split View):** одновременный запуск и просмотр двух чатов бок о бок.
- **Встроенные изображения:** медиафайлы отображаются прямо в переписке, а не в виде путей к файлам.

### Экстремальная производительность:
Разработчик делает упор на ультралёгкость и плавность интерфейса:
- **0,7% CPU** в режиме простоя;
- скроллинг истории из 2 000 сообщений на стабильных **120 FPS**;
- отрисовка ответов на экране за **32 миллисекунды**.

Релиз десктопного Herald ожидается в ближайшее время. Herald — это независимый сторонний проект от Luke The Dev, построенный поверх Hermes Agent (не связанный напрямую с Nous Research). Разработка ведётся в открытом репозитории Herald-OS.

## Tracekit: верификация каждого вызова инструмента перед выполнением

29 октября @witcheer представил **Tracekit** — комьюнити-плагин от Cygnux Labs для превентивной верификации действий агента. Каждый вызов инструмента (tool call) проверяется *до* фактического выполнения: он может быть разрешён, заблокирован или приостановлен до ручного подтверждения человеком.

В опубликованной демонстрации показан сценарий из трёх запланированных вызовов: команда `ls` была автоматически одобрена, загрузка файла с передачей в shell заблокирована политикой безопасности, а операция с удалённой веткой отправлена на подтверждение.

### Архитектура и принципы работы:
- **Криптографический аудит:** Tracekit фиксирует каждый вызов как подписанное событие в цепочке хешей (hash-chained audit log). Подпись формируется внешним подписантом (signer), неподконтрольным самому агенту.
- **Политика безопасности:** при отказе вызов блокируется, при требовании согласования (review) выполнение замирает до явного одобрения оператором.
- **Автономный жизненный цикл (Run):** каждая сессия Hermes оформляется как изолированный запуск (run), который закрывается при выходе агента, экспортируется и может быть независимо проверен оффлайн.
- **Минимальный футпринт:** плагин регистрирует ровно два хука — `pre_tool_call` и `post_tool_call` — без лишних сайд-эффектов.
- **Требования:** библиотека `tracekit-ai` версии 1.4.2 или новее и переменная окружения `TRACEKIT_SIGNER_TOKEN`.
- **Локальный fallback:** если внешний подписант не настроен, первый вызов автоматически запускает локальный dev-сервис подписи от текущего пользователя. Любой сбой или отказ надёжно блокирует вызов (fail-closed).

## Wingtips #113: переключение проекта прямо из чата

29 октября @witcheer опубликовал очередную подсказку из серии Wingtips (#113).

Проект в Hermes Agent — это именованный рабочий контекст (workspace), который может объединять несколько папок (например, репозиторий API и репозиторий фронтенда в рамках одного приложения). В приложении Hermes Desktop переключить текущую сессию в нужный проект можно естественной командой прямо в чате:
```text
switch this chat to my Recipe Box project
```
Hermes находит проект по имени и переносит рабочее пространство текущего диалога в корневой каталог этого проекта. Запрос списка проектов выведет все доступные проекты с отметкой активного.

В документации подчёркивается механика работы: встроенное действие `desktop_project` поддерживает три операции — `create`, `list` и `switch`. Смена проекта всегда выполняется через явный вызов инструмента `desktop_project`, а не как побочный эффект от команды смены директории `cd`.
