# Новости Hermes Agent #40

Этот выпуск посвящён установке локальных моделей в Hermes Desktop в один клик, на которую обратили внимание в связи с оборудованием NVIDIA, шестьдесят второму выпуску Wingtips о выделенной модели для задач cron, а также проекту сообщества: cron Hermes Agent, который каждую ночь пишет настоящую газету.

## Hermes Desktop устанавливает локальные модели в один клик

Nous Research объявила 3 сентября, что Hermes Desktop теперь умеет разворачивать локальные модели в один клик. Приложение считывает аппаратное обеспечение машины, выбирает наиболее подходящую модель, затем скачивает её и настраивает среду выполнения (runtime). Ещё одно сообщение Nous Research уточняет, что такая установка особенно подходит для оборудования NVIDIA, а аккаунт NVIDIA RTX Spark добавляет, что она появится на системах NVIDIA под Windows и Linux.

witcheer, который активно использует локальные модели, называет новшество падением главного барьера на пути их внедрения. Выбор правильной модели до сих пор требовал специальных знаний: что помещается в память, какая квантизация, какие настройки среды выполнения. Hermes Desktop теперь управляет всем этим одним кликом.

В документации подробно описан механизм работы. Hermes скачивает и поддерживает механизм инференса llama.cpp и выбирает его компиляцию, подходящую под оборудование, а также управляет памятью: больше не нужно настраивать ни размер контекста, ни GPU-слои, ни квантизацию. Каждая модель каталога оценивается применительно к машине (помещается целиком в GPU, использует системную RAM или слишком велика), и Hermes выбирает компиляцию наивысшего качества, которая полностью работает на GPU, никогда не предлагая сборку ниже 4 бит. Под Windows и Linux нужен GPU NVIDIA (CUDA) или процессор; на macOS — чип Apple Silicon; GPU AMD работают через Vulkan.

## Wingtips #62: выделить задачам cron отдельную модель

В шестьдесят втором выпуске своей серии Wingtips witcheer объясняет, что задачам cron и чат-сессиям не обязательно делить одну и ту же модель. Без отдельной настройки для cron новая задача работает на глобальной модели по умолчанию — той, с которой ведётся общение, — даже если речь идёт о небольшом ежедневном резюме. Он показывает два способа управлять расходами плановых задач.

В документации указан порядок разрешения модели в момент запуска: сначала привязка (pin) самой задачи, затем настройка `cron.model` в файле `config.yaml`, затем глобальное значение по умолчанию. `cron.model` задаёт модель по умолчанию для всей флотилии cron независимо от чат-модели: его устанавливают один раз через `hermes config set cron.model <name>`, и смена модели для общения больше не затрагивает плановые задачи. Отдельная задача также может закрепить собственную модель и собственного провайдера. Когда ничего из этого не задано, Hermes фиксирует провайдера и модель в момент создания: если глобальное значение по умолчанию затем изменится, задача выходит из строя, завершаясь. Она пропускает выполнение, не запускает ни одного вызова инференса и предупреждает только один раз, если только не отключить защиту от дрейфа настройкой `cron.model_drift_guard false`.

## Cron Hermes Agent, который каждую ночь пишет настоящую газету

witcheer 4 сентября привлёк внимание к проекту сообщества: cron Hermes Agent, который ночью составляет настоящую газету — с первой полосой, рубриками и нумерацией страниц. Он подчёркивает первую идею репозитория: цифры никогда не берутся от модели. Погода, рынки и семейная бухгалтерия генерируются на Python.

Репозиторий vaelkeep/hermes-paper-agent позиционируется как газета, которая пишет сама себя: агент ведёт рубрики, иллюстрации создаются кодом, и он отказывается публиковать выпуск, содержащий ошибки. Рубрики с данными (погода через Open-Meteo, финансы через Yahoo, счета, этапы) — это код; редакционный контент остаётся за агентом. Каждый выпуск проходит проверку, и если она возвращается красной, агент исправляет указанную строку, прежде чем второй прогон пройдёт чисто: репозиторий иллюстрирует случай ячейки таблицы из 27 символов при лимите в 26, исправленной до публикации. Архитектура опирается на файл AGENTS.md, задающий постоянные распоряжения ночного главного редактора, и на скилл (skill), установленный в Hermes. Проект опубликован под лицензией MIT.
