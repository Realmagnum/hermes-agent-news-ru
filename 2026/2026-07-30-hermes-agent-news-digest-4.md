## Hermes Agent v0.19.1 (v2026.7.30): консолидация месяца работы

30 июля команда Nous Research выпустила патч-релиз **Hermes Agent v0.19.1**, объединивший в единой стабильной сборке более 1 000 пулл-реквестов, смердженных со времени выхода v0.19.0 (20 июля). Главная цель релиза — предоставить надежную кодовую базу для downstream-потребителей: официальных Docker-образов, развертываний на хостингах и чистых установок.

Масштаб изменений в ветке `main` впечатляет:
- около **2 789 коммитов** и **4 748 измененных файлов** (+442 000 / −392 000 строк);
- критические фиксы и стабилизация шлюза (**gateway**), голосовой подсистемы, десктопного приложения и скрипта установки;
- платформенная разработка: интеграция каналов Buzz/Nostr, генерация и доставка видео через **FLUX 3**, повышение надежности передачи медиафайлов в Telegram и устранение регрессий в голосовом режиме.

Полные курируемые ноуты этого окна изменений выйдут вместе с мажорным апдейтом **v0.20.0**. Обновиться до v0.19.1 можно уже сейчас:

```bash
hermes update
```

*(для чистой установки используйте стандартный установочный скрипт).*

## FLUX 3 Preview доступен в Hermes Agent

Nous Research объявила об открытии публичного доступа к **FLUX 3 Preview** — новой модели генерации видео от Black Forest Labs. Функция запущена эксклюзивно внутри Hermes Agent и доступна бесплатно на всех платных тарифах **Nous Portal** в течение первых 48 часов.

В честь релиза стартовал конкурс короткометражного кино:
- **Условия:** создать ролик с помощью FLUX 3 и выложить его с отметками @NousResearch и @bfl_ai до 1 августа (19:00 PT).
- **Призовые места:**
  - **1-е место:** год бесплатной генерации во FLUX 3 (20 генераций в день), $2 000 кредитов на Nous Portal и фирменный худи.
  - **2-е место:** $1 000 кредитов на Nous Portal.
  - **3-е место:** $500 кредитов на Nous Portal.

**Специальные предложения для пользователей:**
- первые 100 зарегистрировавшихся с кодом `L1YSMYDB` получат бесплатный месяц подписки **Nous Portal Plus** с полным доступом к видеогенерации;
- первые 25 апгрейдов с промокодом `KEQHYO3X` получат скидку $20.

Обновить окружение для доступа к фиче можно командой:

```bash
hermes update
```

## Официальная интеграция с Buzz

Ранее сообщество использовало неофициальный форк для интеграции Hermes Agent в Buzz. Теперь представлена полноценная нативная поддержка: Hermes Agent «runs Buzz». Self-hosted рабочее пространство от Block (бывший Square) объединяет разработчиков и агентов в общих чатах и едином кодбейзе.

Интеграция предлагает три сценария развертывания:
- **Buzz Desktop:** автоматически определяет установленный локально Hermes и запускает агента из коробки;
- **Релейный мост (relay bridge):** наделяет агента постоянной hosted-идентичностью внутри каналов;
- **Подключение через Hermes Gateway:** превращает Buzz в полноценную внешнюю платформу агента с поддержкой каналов, личных сообщений (DM), тредов, реакций и cron-задач.

По словам @Teknium, протестировать интеграцию можно не дожидаясь следующего релиза через команду `hermes update`. Документация доступна на `hermes-agent.nousresearch.com/docs/integrations/buzz`.

**Вклад сообщества:**  
Разработчик @tonbistudio опубликовал репозиторий `buzz-skills` с двумя готовыми скиллами:
- `hermes-in-buzz` — для настройки подключения удаленного инстанса Hermes к локальному приложению Buzz через gateway;
- `buzz-media-attachments` — для корректного форматирования и прикрепления видео- и медиафайлов под стандарты Buzz.

## Голосовая активация: «Hey Hermes»

В Hermes Agent появилась нативная голосовая активация. При произнесении кодового слова (**wake word**) агент мгновенно открывает новую сессию и переходит в режим ожидания команды в формате hands-free — это работает в CLI, TUI и десктопном интерфейсе.

Особенности реализации:
- **Полная локальность:** распознавание фразы происходит локально на устройстве без отправки аудиопотока во внешние API.
- **Безопасность:** по умолчанию прослушивание выключено. Активировать режим можно кликом по иконке уха в строке ввода GUI.
- **Поддержка профилей:** система распознает имена сконфигурированных профилей, позволяя вызывать нужный контекст напрямую голосом.

Руководство по настройке опубликовано на `hermes-agent.nousresearch.com/docs/user-guide/features/wake-word`.
