# Новости Hermes Agent #26

Стабильный выпуск объединяет около 330 merge-запросов с прошлого релиза, десктоп ускоряется на 20% благодаря коллаборации с xAI и открывает доступ к Grok и Imagine, Ox Alpha появляется в Hermes через opencode и OpenRouter, а Nous Research запускает детальный набор на странице карьеры.

## Hermes Agent v0.20.5 (v2026.8.19)

Nous Research выпустила патчную версию v0.20.5, которая объединяет примерно 323 merge-запроса с v0.20.4, около 746 коммитов, затронувших 1 250 файлов.

Ключевые изменения:
- Bot Mode: ветки обсуждений для групп, сворачиваемые конспекты чатов, аватары blob-face.
- Прикрепление PDF и файлов перетаскиванием.
- Веб-поиск без ключа: бесплатная ротация между пятью провайдерами с переключением в кольцо, веб-поиск на чистой установке без каких-либо ключей.
- Полировка CLI: размытый селектор моделей, палитра команд Ctrl+P, расширенная команда /status.
- Защитные механизмы выполнения на основе выводов оценки Composio.
- Подсказки hermes update и проверка --plan для кластеров.
- Команды hermes worktree list/prune.
- Провайдер без аутентификации.
- Множественные уточняющие вопросы.
- Cron-задачи с сохраняемой памятью и уровнем рассуждений на задачу.

Полные заметки к выпуску и список контрибьюторов будут подготовлены вместе с v0.21.0.

> Источник: [Hermes Agent v0.20.5 (v2026.8.19), GitHub Releases, 19 августа 2026](https://github.com/NousResearch/hermes-agent/releases/tag/v2026.8.19)

## Десктоп Hermes стал работать на 20% быстрее благодаря xAI

Teknium сообщил, что десктоп Hermes Desktop теперь обрабатывается на 20% быстрее, поблагодарив xAI и особенно Jaaneek за сотрудничество. Производительность рендеринга сопоставима с уже проведённой работой по hydration Bot Mode и спиннерам композера.

> Источник: [@Teknium, десктоп стал на 20% быстрее благодаря xAI, 21 августа 2026](https://x.com/Teknium/status/2090648797844210019)

## Grok и Imagine доступны в Hermes с подпиской X

Jaaneek, инженер из xAI, активно участвующий в основных harness'ах агентов, напомнил, что модели Grok и Imagine можно использовать в Hermes Agent при наличии подписки X Premium или SuperGrok. Он также спросил у сообщества, какую фичу для Hermes стоит выпустить следующей.

> Источник: [@Jaaneek, Grok и Imagine в Hermes, 21 августа 2026](https://x.com/Jaaneek/status/2090770966359970105)

## Ox Alpha доступен через opencode и OpenRouter

Teknium объявил, что Ox Alpha теперь доступен в Hermes Agent через провайдера opencode и OpenRouter. Модель добавляется к числу уже подключаемых к агенту провайдеров.

> Источник: [@Teknium, Ox Alpha в Hermes, 21 августа 2026](https://x.com/Teknium/status/2090674052058984513)

## Nous Research набирает восемь специалистов

Nous Research запустила кампанию по найму, анонсированную на X и подробно описанную на странице карьеры. Компания позиционирует себя как open-source AI research company на переднем крае исследований, полностью удалённая и с высокой степенью автономии.

Открыты восемь fulltime-позиций: generalist software engineer, product software engineer, software engineer для Hermes Cloud, machine learning engineer по оценкам, product analysis engineer, security engineer, deployment engineer (адптирование Hermes Agent Enterprise для клиентов) и UI/UX дизайнер. Отклик отправляется на recruiting@nousresearch.com с указанием вакансии в теме письма, резюме, мотивационного письма и портфолио (например, GitHub). Возможна и свободная заявка, если не найдена подходящая позиция.

> Источник: [@NousResearch, кампания по найму, 20 августа 2026](https://x.com/NousResearch/status/2090580123795787792)
