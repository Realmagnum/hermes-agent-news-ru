## Hermes Wingtips #44: у куратора появилась кнопка отмены

12 августа @witcheer опубликовал сорок четвертый выпуск серии Hermes Wingtips, посвященный автоматическим снапшотам куратора и командам отката изменений.

Куратор (`curator`) — это фоновый процесс, который наводит порядок в созданных агентом скиллах: он отправляет устаревшие навыки в архив и объединяет дублирующиеся. Перед каждым прогоном оптимизации куратор автоматически делает полный снапшот всей директории со скиллами. 

Для навигации по истории изменений и управления восстановлением достаточно трех шагов:

- Просмотр всех доступных точек восстановления:
  ```bash
  hermes curator rollback --list
  ```
- Откат к самому свежему снапшоту:
  ```bash
  hermes curator rollback
  ```
- Даже сама операция восстановления предварительно создает резервный снимок, поэтому данные не потеряются ни при каких обстоятельствах.

## Hermes Agent запускается на Raspberry Pi 4 с 2 ГБ RAM

Сообщество нашло эффективный сценарий для микрокомпьютеров: пользователь запустил полноценного Hermes Agent на плате Raspberry Pi 4 (~$50) всего с 2 ГБ оперативной памяти.

Секрет кроется в архитектурном разделении нагрузки:
- **Локальный агентный цикл:** Pi берет на себя выполнение цикла агента (agent loop), менеджмент памяти и работу с локальными инструментами.
- **Удаленный инференс:** тяжелая языковая модель опрашивается удаленно через API на внешнем сервере.

В результате получается полноценный автономный always-on агент, работающий без затрат на аренду VPS и потребляющий минимум электроэнергии. Как отметил @witcheer, 2 ГБ RAM — это даже меньше, чем установлено в большинстве современных смартфонов.

> **Источники:**
> - [@witcheer — Запуск Hermes на Raspberry Pi 4 (12 августа 2026)](https://x.com/witcheer/status/2087509716746326124)

## Centaur интегрирует Hermes Agent как первоклассный харнесс

11 августа Георгиос Константопулос (@gakonst) сообщил о мердже пулл-реквеста от @Teknium, добавляющего поддержку Hermes Agent в платформу Centaur. Centaur от Paradigm предназначен для запуска автономных кодинг-агентов в изолированных песочницах (sandboxes) и уже поддерживает Codex, Claude Code, Amp и Nanocodex.

Интеграция сохраняет ключевые преимущества экосистемы Hermes:

- **Непрерывность сессий (Session continuity):** постоянный шлюз на уровне песочницы сохраняет контекст сессии Hermes между обращениями, даже если сам sandbox был перезагружен.
- **Цикл непрерывного обучения (Learning loop):** ревизии памяти и скиллов после каждого шага фиксируются в каталоге `HERMES_HOME` и могут накапливаться между разными песочницами через смонтированный volume.
- **Встроенные Cron jobs:** фоновый процесс выполняет команду `hermes cron tick`, обеспечивая работу запланированных в диалоге фоновых задач на протяжении всей жизни песочницы.

Активировать харнесс можно флагом `--hermes` в Slack, указанием `harness: hermes` в конфигурации каналов или глобальной переменной окружения `CENTAUR_DEFAULT_HARNESS=hermes`. Пулл-реквест успешно прошел юнит-тесты (10/10), двухэтапную проверку непрерывности контекста и полный набор интеграционных тестов Slack (45/45).

## CopilotKit: интеграция Hermes в любые приложения через AG-UI

10 августа команда CopilotKit объявила об интеграции Hermes Agent в любые пользовательские приложения с помощью открытого протокола **AG-UI**. Агента можно бесшовно встроить в стэки на базе React, React Native, Next.js, Angular, а также в корпоративные клиенты Slack и Microsoft Teams.

В опубликованной демонстрации показано, как Hermes Agent напрямую взаимодействует с компонентами интерфейса хост-приложения, генерирует элементы UI в реальном времени и поддерживает режим human-in-the-loop (подтверждение критических действий пользователем).
