## Hermes Agent v0.21.4 (v2026.9.21)

21 сентября команда Nous Research представила корректирующий релиз **Hermes Agent v0.21.4** (с тегом `v2026.9.21`). С момента выхода v0.21.3 в кодовую базу вошло порядка 1 800 пулл-реквестов, объединённых в стабильный релиз для downstream-потребителей, Docker-образов, Hermes Cloud и развёртываний на хостингах. Полный чейнджлог за этот период выйдет вместе с версией v0.22.0. По состоянию на коммит `4b8a813` окно изменений включает 5 071 коммит без учёта мерджей, 5 169 изменённых файлов, 1 812 принятых пулл-реквестов и 2 116 закрытых issue.

**Ключевые изменения релиза:**

- **Синглтон-блокировка шлюза** на уровне хоста с регистрацией точек встречи (rendezvous): десктопное приложение теперь корректно подключается к уже активному бэкенду на хосте вместо запуска дублирующего процесса.
- **Управление коннекторами на стороне бэкенда** с общей картой конфигурации для десктопа, TUI и CLI.
- **Структурированный вывод в JSONL** с флагом `--format stream-json` для командной строки.
- **Параметр `skills.auto_load`**, позволяющий закреплять скиллы в системном промпте каждой новой сессии.
- **Улучшения интерфейса:** селектор шрифтов для чата и десктопного GUI, локальные обновления движка в один клик и возможность удаления плагинов прямо из хаба плагинов.
- **Политика `decline`** для отклонения неавторизованных личных сообщений на шлюзе.
- **Лимит параллелизма** для обнаружения MCP-серверов (`mcp.discovery_concurrency`).
- **Временные границы (before/after)** для команды `session_search` с ослабленным fallback-условием поиска по «ИЛИ».
- **Новая команда** `hermes sessions set-journal-mode`.
- **Поддержка видеомоделей:** LTX 2.5 и Kling O3 в каталогах.
- **Веб-страницы для каталога плагинов:** персональные страницы авторов и расширений с readme-файлами, привязанными к коммитам, и сортировкой по дате добавления или обновления.
- **Дюжина новых плагинов от сообщества:** tailscale, ssh, shodan, terminal, rss, resetwatch, done-bell, kiwi, cognee, Octen.
- **Крупный пакет исправлений:** изоляция профилей и мультиплексирование, cron, kanban, десктопное окружение и стабильность `state.db`.

Полные примечания к выпуску войдут в релиз v0.22.0, где будут подробно описаны все изменения начиная с v0.21.0, ключевые функциональные блоки и списки авторов изменений.

## Возвращение Claude Code через плагин Direct SDK

21 сентября @Teknium сообщил о возвращении моделей Claude в Hermes Agent благодаря новому официальному плагину, который напрямую задействует Claude SDK без лишних компромиссов. Это позволяет снова использовать подписки Claude Code внутри Hermes Agent. В тот же день @tonbistudio опубликовал видеоролик с демонстрацией установки плагина Direct SDK и обзором Fable 5.1.

В каталоге плагин доступен под именем `claude-subscription-directsdk` со статусом **Claude Subscription DirectSDK (Experimental)** (мейнтейнер — NousResearch). Плагин запускает оригинальный бинарник Claude Code как локальный модельный клиент, отправляющий запросы в рамках подписки Claude Pro или Max. При этом Hermes сохраняет собственный агентный цикл, стек инструментов, систему подтверждений и механизм компактификации контекста. 

Несмотря на название, реализация работает нативно по протоколу stream-json и не требует установки Python-пакета Agent SDK.

**Системные требования:**
- Hermes Agent 0.21.4 или новее;
- Python 3.10+;
- Установленный и авторизованный официальный CLI Claude Code.

Плагин не хранит учётные данные — вся авторизация делегируется бинарнику `claude`.

```bash
# Установка плагина
hermes plugins install claude-subscription-directsdk

# Авторизация в Claude CLI
claude auth login
```

После этого остаётся лишь выбрать соответствующего провайдера в конфигурации. Архитектурная основа решения заложена в пулл-реквесте #105863 авторов @teknium1 и @unsupportedpastels: общие компоненты (профили внешних провайдеров, нативные ретрансляторы, управление потоками конфигурации и селекторы) были перенесены в ядро через PR #117451. Плагин помечен как экспериментальный и предназначен для тестирования — паритет функций и готовность к продакшену пока не гарантируются.

## Wingtips #80: skills.auto_load

В юбилейном 80-м выпуске заметок Wingtips разработчик @witcheer разобрал работу директивы `skills.auto_load`. 

По умолчанию Hermes Agent подгружает скиллы динамически, когда этого требует текущая задача. Однако некоторые скиллы необходимы в каждой сессии независимо от контекста: например, корпоративный стайлгайд, чек-лист для код-ревью или правила оформления коммитов. Ключ `skills.auto_load` закрепляет такие скиллы, принудительно инициализируя их на старте каждого нового диалога.

Механизм работает одинаково во всех окружениях: CLI, TUI, шлюзе, cron и API. Список скиллов объявляется в `config.yaml`:

```yaml
skills:
  auto_load:
    - code-style
    - git-conventions
```

Список резолвится один раз — при первой сборке системного промпта сессии. Сгенерированные байты промпта кэшируются и повторно используются на протяжении всей беседы, включая смену моделей и сжатие контекста, благодаря чему сохраняется кэш промпта (prompt cache). Изменения в конфиге вступают в силу со следующей сессии.

Если указанный скилл отсутствует или отключён, агент выведет предупреждение в лог и продолжит работу. Флаг `--ignore-rules` (или переменная `HERMES_IGNORE_RULES=1`) отключает автоматическую загрузку скиллов вместе с файлами `AGENTS.md`, `SOUL.md`, `.cursorrules` и инъекцией памяти (при этом явно переданные флаги `-s` продолжают работать). Настройка изолирована на уровне профиля.

## Xiaomi MiMo-V2.6: две омнимодальные open-source модели

21 сентября Xiaomi представила семейство **MiMo-V2.6**, включающее две нативно омнимодальные модели: **Pro** и **Flash**. Обе модели обучены с использованием масштабированного обучения с подкреплением (RL). 

Флагманская версия Pro демонстрирует паритет с Claude Opus 5 и GPT-5.6 Sol на большинстве агентных бенчмарков, а также набрала **46 баллов** в рейтинге Artificial Analysis Intelligence — наивысший показатель среди открытых моделей на сегодняшний день.

**Результаты тестов и позиционирование:**
- **MiMo-V2.6 Pro:** 71,9 балла на DeepSWE v1.1, 89,9 на Terminal Bench 2.1 и 82,0 на OSWorld-Verified.
- **MiMo-V2.6 Flash:** сбалансированное решение с акцентом на скорость, низкую задержку и экономичность.

**Цены за токены (API):**
- **Flash:** $0,14 за 1 млн входных токенов (без кэша) / $0,28 за 1 млн выходных токенов;
- **Pro:** $0,435 за 1 млн входных токенов / $0,87 за 1 млн выходных токенов.

Веса моделей опубликованы под открытой лицензией и доступны на Hugging Face. В документации провайдеров Hermes Agent уже присутствует интеграция с Xiaomi MiMo:

```bash
hermes chat --provider xiaomi --model mimo-v2-pro
```

Полноценная поддержка новых моделей появится в каталоге по мере развёртывания инфраструктуры.
