# Новости Hermes Agent #58

В этом выпуске: корректирующий релиз v0.21.4 после недельного перерыва, возвращение Claude Code в Hermes Agent через официальный плагин Direct SDK, 80-й выпуск Wingtips о закреплении навыков (skills), Grok 4.7 за полцены на Nous Portal и выход омнимодальных моделей Xiaomi MiMo-V2.6.

## Hermes Agent v0.21.4 (v2026.9.21)

21 сентября Nous Research выпустила Hermes Agent v0.21.4 с тегом v2026.9.21. Этот корректирующий релиз объединяет около 1800 пулреквестов, смердженных со времён v0.21.3, в стабильный тег для нижестоящих потребителей, Docker-образов, Hermes Cloud и хостинг-развёртываний. Полный список изменений за этот период отложен до версии v0.22.0. На момент коммита 4b8a813 окно разработки насчитывает 5071 коммит (без учёта мерджей), 5169 изменённых файлов, 1812 принятых пулреквестов и 2116 закрытых issue.

Основные изменения:

- Блокировка шлюза-синглтона на уровне хоста с регистрацией точки рандеву, благодаря чему десктопное приложение подключается к уже активному бэкенду хоста вместо запуска второго экземпляра.
- Управление коннекторами на стороне бэкенда с картой конфигурации в десктопном приложении, TUI и CLI.
- Структурированный вывод `--format stream-json` в формате JSONL для CLI.
- `skills.auto_load` для закрепления навыков в системном промпте каждой новой сессии.
- Выбор шрифта для чата и десктопного интерфейса, обновление локального движка в один клик и удаление плагинов прямо из хаба плагинов.
- Поведение `decline` для неавторизованных личных сообщений на шлюзе.
- Настраиваемый лимит параллельных подключений для обнаружения MCP (`mcp.discovery_concurrency`).
- Границы «до» и «после» для `session_search` с ослабленным повторным поиском через логическое ИЛИ.
- Команда `hermes sessions set-journal-mode`.
- LTX 2.5 и Kling O3 в видеокаталогах.
- Веб-страницы для каждого плагина и автора в каталоге, с файлами README, привязанными к коммитам, и сортировкой по дате добавления или обновления.
- Около десятка новых плагинов от сообщества в каталоге: tailscale, ssh, shodan, terminal, rss, resetwatch, done-bell, kiwi, cognee, Octen.
- Масштабная серия исправлений для изоляции профилей и мультиплексирования, cron, канбана, десктопного интерфейса и state.db.

Полные примечания к релизу за этот период выйдут вместе с v0.22.0: в них будет подробно задокументировано всё, начиная с v0.21.0, включая ключевые моменты, функциональные области и полные благодарности контрибьюторам. Ни одно изменение не будет упущено.

> Источник: [Hermes Agent v0.21.4 (v2026.9.21), примечания к релизу, 21 сентября 2026](https://github.com/NousResearch/hermes-agent/releases/tag/v2026.9.21)

## Возвращение Claude Code через плагин Direct SDK

21 сентября Teknium объявил о возвращении Claude в Hermes Agent благодаря новому официальному плагину, использующему SDK Claude без компромиссов. Это позволяет снова запускать подписки Claude Code внутри Hermes Agent. В тот же день tonbistudio опубликовал видеоролик с демонстрацией установки плагина Direct SDK и первого знакомства с Fable 5.1.

На странице каталога описан плагин `claude-subscription-directsdk` (отображается как Claude Subscription DirectSDK (Experimental)), поддерживаемый NousResearch. Он управляет оригинальным немодифицированным бинарником Claude Code в режиме клиента модели с тарификацией по запросам по подписке Claude Pro или Max. При этом Hermes сохраняет свой агентский цикл, инструменты, подтверждения и компакцию контекста. Несмотря на название, реализация нативно работает по stream-json и не требует Python-пакета Agent SDK. Для работы необходимы Hermes Agent 0.21.4 или новее, Python 3.10+ и официально установленный и авторизованный CLI Claude Code. Плагин не хранит учётные данные — всё проходит через `claude`. Установка сводится к паре команд: `hermes plugins install claude-subscription-directsdk`, затем `claude auth login` и выбор провайдера.

Текущая квалификация основана на пулреквесте #105863 от @teknium1 и @unsupportedpastels, чьи общие компоненты — профили внешних процессов для провайдеров, нативные транспорты воспроизведения, контроль потока конфигурации и инфраструктура селектора — вошли в ядро через PR #117451. Плагин помечен как экспериментальный: это ознакомительная сборка, не претендующая на полную функциональную паритетность или готовность к продакшену.

> Источники: [@Teknium, Welcome back to Hermes Agent, Claude, 21 сентября 2026](https://x.com/Teknium/status/2102093483788107792), [@tonbistudio, Huge news for Claude subscribers!, 21 сентября 2026](https://x.com/tonbistudio/status/2102112767654441132) и [Claude Subscription DirectSDK (Experimental), каталог плагинов Hermes Agent](https://hermes-agent.nousresearch.com/docs/plugins/claude-subscription-directsdk)

## Wingtips #80: skills.auto_load

witcheer посвятил 80-й выпуск Wingtips параметру `skills.auto_load`. Обычно Hermes Agent подгружает навык, когда этого требует задача, однако некоторые навыки полезны абсолютно в каждой сессии: внутренний кодстайл, чек-лист для код-ревью или правила оформления коммитов. Этот ключ закрепляет их, загружая каждый навык из списка в каждую новую сессию.

Документация по CLI подробно описывает этот механизм. Чтобы одни и те же навыки были активны на старте любой сессии во всех интерфейсах — CLI, TUI, шлюзе, cron и API, — их достаточно перечислить в `skills.auto_load` файла config.yaml. Список разрешается единожды, при первой сборке системного промпта сессии, а отрендеренные байты переиспользуются на протяжении всего диалога, включая смену моделей и компакцию, благодаря чему кеш промпта остаётся нетронутым. Изменения в конфигурации вступают в силу со следующей сессии. Если навык отсутствует или отключён, в лог записывается предупреждение, а сам он игнорируется. Флаг `--ignore-rules` (или `HERMES_IGNORE_RULES=1`) отключает автозагрузку вместе с AGENTS.md, SOUL.md, .cursorrules и внедрением памяти, при этом навыки, явно переданные через `-s`, продолжают загружаться. Настройка задаётся индивидуально для каждого профиля.

> Источники: [@witcheer, Hermes Wingtips #80: skills.auto_load, 22 сентября 2026](https://x.com/witcheer/status/2102275176138178793) и [CLI Interface, Preloading Skills at Launch, документация Hermes Agent](https://hermes-agent.nousresearch.com/docs/user-guide/cli#preloading-skills-at-launch)

## Grok 4.7 за полцены на Nous Portal

21 сентября SpaceXAI анонсировала Grok 4.7, охарактеризовав её как заметное улучшение по сравнению с Grok 4.6 при сохранении той же цены и скорости. В тот же день NousResearch объявила, что Grok 4.7 доступна в Hermes Agent через Nous Portal со скидкой 50% в течение недели.

witcheer уточнил подробности: Grok 4.7 доступна на Nous Portal со скидкой 50% на неделю, и для агента, работающего через аккаунт Portal, переключение выполняется буквально одной командой в любом чате: `/model`, выбрать Grok 4.7 и продолжить. Позже в тот же день он напомнил, что многие передовые frontier-модели сейчас предлагаются за половину каталожной цены на портале — Grok 4.7, GPT-5.6 Sol и Sol Pro, Gemini 3.8 Flash и 3.7 Flash, Kimi K3, — а целый ряд моделей доступен бесплатно: Ling 3.0 Flash, LongCat 2.0, Laguna S и XS, Step 3.7 Flash, Solar.

## Xiaomi MiMo-V2.6: две омнимодальные модели в open source

21 сентября Xiaomi анонсировала MiMo-V2.6 в версиях Pro и Flash. Это две нативно омнимодальные модели, улучшенные за счёт масштабированного обучения с подкреплением. Версия Pro находится на одном уровне с Claude Opus 5 и GPT-5.6 Sol в большинстве агентских бенчмарков и набирает 46 баллов в индексе Artificial Analysis Intelligence — наивысший результат среди открытых моделей на сегодняшний день, по оценкам сообщества.

На официальной странице представлены подробные результаты. Например, Pro набирает 71,9 балла на DeepSWE v1.1, 89,9 на Terminal Bench 2.1 и 82,0 на OSWorld-Verified; версия Flash ориентирована на оптимальный баланс между интеллектом, эффективностью и стоимостью. Что касается тарифов, Flash стоит 0,14 доллара за входные токены (без учёта кеша) и 0,28 доллара за выходные, а Pro — 0,435 доллара за вход и 0,87 доллара за выход. Веса выпущены под открытой лицензией и уже доступны на Hugging Face. В документации по провайдерам Hermes Agent уже есть раздел для Xiaomi MiMo (`hermes chat --provider xiaomi --model mimo-v2-pro`), поэтому добавление новой модели в каталог ожидается по мере её развёртывания.
