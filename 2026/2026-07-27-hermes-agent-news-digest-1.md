# Новости Hermes Agent #1

Два крупных анонса от Nous Research за выходные: без новой релизной версии, но с заметным движением в ветке main.

Progressive disclosure для инструментов MCP, 51 PR за выходные и интеграция Buzz.

## Progressive disclosure для инструментов MCP и плагинов

Teknium анонсировал в воскресенье 26 июля переработку управления инструментами MCP и плагинами в Hermes Agent. Проблема: чем больше инструментов MCP вы добавляете, тем больше токенов контекста съедают их описания — вплоть до переполнения окна и деградации качества ответов.

Реализованное решение — механизм **progressive disclosure**. Конкретно:

- Пока описания инструментов MCP укладываются в менее 5 % доступного контекста, агент видит все их имена и описания целиком, как раньше.
- За этим порогом агент уведомляется, что в его распоряжении N инструментов MCP, доступных через единую функцию поиска-и-выполнения. Он знает, что они существуют, но должен находить их динамически, а не держать постоянно перед глазами.

Заявленный результат: значительное снижение затрат входных токенов без измеримой потери точности во внутренних тестах Nous Research.

## 51 PR смержено в субботу

Luke The Dev (@iamlukethedev) собрал итоги дня разработки субботы 26 июля: **51 pull request смержено**, из них 15 фич и 36 исправлений стабильности. Teknium перепостил сводку. Вот заметные изменения:

**Производительность**
- Запуск worktree в 8,7× быстрее: `hermes -w` ускорился с 14 с до 1,8 с благодаря параллелизованному кэшу.
- Адаптивные таймауты сжатия: медленные модели больше не штрафуются одинаково.

**Стабильность и восстановление**
- Восстановление сессии офлайн: повреждённая база `state.db` чинится без разрушительного сброса.
- Автоматическая защита SQLite: уязвимые сборки SQLite патчатся при обновлении.

**Интерфейс и команды**
- Очередь для `/goal`: команды накапливаются, если агент занят, вместо того чтобы исчезать.
- Исправлена маршрутизация slash-команд: команды теперь нацеливаются на активную сессию, а не на случайную.
- Кликабельные ссылки `@session`: прямой переход к сессии из чата.

**Интеграции**
- Восстановлена генерация изображений Codex.
- Поддержка stream-only провайдеров: вспомогательные модели, выдающие только стриминг, теперь работают без сбоев.
- Фаза 3 интерактивности relay: нативные валидации и запросы уточнений Telegram/Discord с циклом подтверждения получения.

> Источник: [Luke The Dev, перепост @Teknium, 26 июля 2026](https://x.com/Teknium/status/2081525680156955111)

## Интеграция сообщества Hermes + Buzz

Интеграция сообщества позволяет использовать Hermes Agent в [Buzz](https://github.com/amanning3390/buzz) — agent builder от Block (бывш. Square). Официальная интеграция анонсирована как «скоро», но этот форк сообщества работает уже сейчас.
