## Wingtips #90: /blueprint

witcheer посвятил девяностый выпуск Wingtips команде `/blueprint`. Она позволяет настраивать автоматизацию «из коробки»: Hermes последовательно задаёт уточняющие вопросы, а затем формирует cron-задачу без необходимости вручную писать синтаксис cron. Пример из публикации — короткий ежедневный урок по выбранной теме по будням — основан на шаблоне Daily learning drip из каталога.

В документации детально описана механика работы. Полный формат команды: `/blueprint [name] [slot=value ...]`, также доступен алиас `/bp`. При запуске без аргументов она выводит каталог доступных шаблонов; с указанием имени запускает пошаговое заполнение параметров на следующем шаге диалога; а при передаче параметров прямо в строке (например, `/blueprint morning-brief time=08:00`) сразу создаёт задачу. Blueprint никогда не запускает планирование втихую: создание задачи всегда требует явного подтверждения, а дальнейшее управление расписанием происходит через команду `/cron`. Технически blueprint представляет собой обычный skill, содержащий блок `metadata.hermes.blueprint` в заголовке файла `SKILL.md`.

## Неделя улучшений Hermes Desktop

2 октября tonbistudio опубликовал видео с обзором небольших улучшений приложения Hermes Desktop за прошедшую неделю, которым тем же вечером поделился witcheer. Среди новинок: перетаскивание сессий между проектами (drag-and-drop), новые темы оформления, независимая регулировка размера шрифта в чате отдельно от масштаба интерфейса, а также панель ревью с отображением незакоммиченных изменений и текущей ветки. Селектор моделей с разделом избранного, о котором говорилось в выпуске #67, также вошёл в обновление. witcheer особо подчеркнул этот пункт: закрепление двух-трёх моделей, между которыми приходится часто переключаться, помещает их в самый верх списка.

## Установка MCP-сервера в один клик из Desktop

witcheer показал 2 октября, как подключить MCP-сервер к Hermes Agent буквально в один клик прямо из интерфейса Hermes Desktop. Весь процесс проходит в разделе Capabilities на вкладке Connectors: достаточно найти нужный сервис в каталоге (в примере используется DeepWiki, способный работать с любым публичным репозиторием GitHub), нажать Install — и карточка сразу же отобразит доступные инструменты. Четвёртый шаг настройки, не вошедший в текст из-за лимита символов, продемонстрирован в прикреплённом видео.

В документации по интеграциям напоминают о назначении MCP: протокол Model Context Protocol обеспечивает подключение Hermes к внешним серверам инструментов с поддержкой транспортов stdio и SSE, фильтрацией инструментов по серверам, а также регистрацией ресурсов и промптов.

> Источники: [@witcheer, how to add an MCP server to Hermes Agent in one click, 2 октября 2026](https://x.com/witcheer/status/2106036133666619806) и [Integrations, MCP Servers, документация Hermes Agent](https://hermes-agent.nousresearch.com/docs/integrations/)
