## v0.22.2 — релиз, которым должен был стать v0.22.1

Nous Research выпустила v0.22.2 15 октября 2026 года. v0.22.1 был собран не из того коммита: в релиз попала неготовая работа над шлюзом, а приложение из Microsoft Store могло зависать на `Connecting.`. Поэтому v0.22.2 — это релиз, которым должен был стать v0.22.1. Известная проблема пока остаётся: сессии, запущенные через шлюз 0.22.1, нельзя удалить в 0.22.2.

Выделяются два исправления:

- **Шлюз запускается после перезагрузки.** При старте Linux может назначить ранний PID постороннему процессу. Шлюз принимал его за уже работающий экземпляр, из-за чего не запускался под управлением systemd, launchd или Docker. Теперь Hermes учитывает, при какой загрузке он стартовал, а если определить это не удаётся — проверяет блокировку хоста, которой владеет только активный шлюз. (#138594, исправляет #133744)
- **Длинные запросы к локальной модели надёжнее работают на ноутбуках.** Локальные запросы показывают ход чтения промпта в строке состояния; таймеры зависания не учитывают время сна компьютера; после восстановления локального сервера выполняется новая попытка вместо постоянного отказа автоматического предохранителя. Сжатие контекста больше не превышает тайм-аут, пока сервер читает длинную беседу. На Windows-компьютерах с унифицированной памятью запуск модели и размер кэша промпта теперь рассчитываются с учётом свободной памяти. (#138560)

В релиз также вошли изменения, появившиеся начиная с v0.22.0:

- Сборка пакета Microsoft Store вынесена в отдельный процесс `windows-store`.
- Nemotron 3.5 Super VL получил настройки по умолчанию и добавлен в список моделей NVIDIA NIM; избранные модели теперь отображаются в начале селектора.
- В каталог добавлены корейский (`hermes-lang-ko`) и бразильский португальский (`hermes-lang-pt-br`) языковые пакеты.
- В каталог плагинов добавлены teamorouter, author-feed, wait-ledger, lightningai, openinvest, hermes-agent-mixer и Hermes AAC. Kumiho Memory появился в разделе памяти.

## phone-harness: управление настоящим телефоном

15 октября witcheer представил phone-harness — плагин из каталога, который позволяет Hermes Agent управлять настоящим телефоном после одной установки. Агент видит экран, нажимает, проводит пальцем и вводит текст — это работает и в приложениях без API или собственного плагина.

В карточке каталога описан механизм: плагин поддерживает ShawnPana, он закреплён за коммитом `7e3ea6c` и предоставляет единственный инструмент — `phone_exec`. Модель пишет короткий скрипт Python с уже импортированными помощниками; плагин выполняет его на телефоне и возвращает результат.

- Перед каждым вызовом `phone_exec` требуется подтверждение через хук `pre_tool_call`. Автозапуск по классификатору по умолчанию отключён: эвристику можно обойти.
- Подагенты используют телефон по очереди через внутреннюю блокировку; если он занят дольше 120 секунд, инструмент сообщает об этом.
- Интеграции с хранилищами паролей нет: агент не вводит пароли, PIN-коды и коды 2FA.
- Установка: `hermes plugins install ShawnPana/phone-harness/integrations/hermes`.
- Для iPhone нужны разрешения на доступность и запись экрана, для Android — adb, для облачного телефона — `phone-harness cloud login`.

## Pet Room в Herald OS

15 октября iamlukethedev анонсировал Pet Room в Herald OS: каждый активный агент Hermes появляется там в виде собственного питомца, а пользователь может буквально наблюдать за его действиями. Если агент работает в терминале, он направляется к терминалу; если открывает браузер — идёт к браузеру.

Herald OS — открытая операционная система вокруг агента от Luke The Dev, не связанная с Nous Research. Pet Room развивает интеграцию с Petdex, о которой объявили накануне: маскот Teknium живёт на рабочем столе, а теперь у каждого активного агента есть своё место в комнате.
