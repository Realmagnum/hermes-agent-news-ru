## Paper Agent: управление Hermes Agent с E-Ink ридера

Марко Франзон (@mfranz_on) представил проект **Paper Agent** — связку, позволяющую отслеживать и подтверждать действия Hermes Agent прямо с электронной книги на базе E-Ink.

Архитектура сценария предельно проста:
- Пока вы спокойно читаете книгу, автономные агенты выполняют задачи в фоновом режиме на хосте.
- Как только агенту требуется вмешательство человека (**human-in-the-loop**) — например, для подтверждения push в репозиторий, деплоя или выполнения потенциально опасных команд вроде `rm -rf` — на E-Ink экране появляется карточка с запросом аппрува.
- Никаких смартфонов, открытых ноутбуков и отвлекающих факторов.

> «Это не просто очередное всплывающее уведомление. Ощущается скорее как подписание и утверждение боевых задач», — комментируют подход в сообществе.

@Teknium поддержал инициативу, отметив разнообразие сценариев сообщества: *> "love seeing the community run Hermes Agent on all kinds of different hardware"* и *> "very cool and unusual setups"*. Разработка также поддерживает работу в связке с Claude Code.

> - [@witcheer / @Teknium — обсуждение сетапа Paper Agent (2 августа 2026)](https://x.com/witcheer/status/2083727374919872945)

## Локальная компиляция Hermes Desktop на любых платформах

@Teknium поделился полезным лайфхаком: клиент **Hermes Desktop** можно беспрепятственно собрать на Intel Mac, а также на любых других платформах, для которых отсутствуют официальные готовые сборки.

Схема не требует ожидания прекомпилированных бинарников под редкие архитектуры: достаточно установить CLI и вызвать команду запуска десктоп-версии:

```bash
hermes desktop
```

При первом вызове утилита автоматически компилирует десктопное приложение локально под текущую систему. 

> *> "Same applies on any other surface we dont have an official installer for"*, — подчеркнул @Teknium.

В первую очередь этот метод решает проблему владельцев компьютеров Mac на процессорах Intel (так как официальные релизы собираются под Apple Silicon), но трюк применим к любому окружению без предсобранного дистрибутива.

> **Источники:**
> - [@Teknium — совет по локальной сборке Hermes Desktop на Intel Mac (1 августа 2026)](https://x.com/Teknium/status/2083556018072817681)
