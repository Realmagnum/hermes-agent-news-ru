# Новости Hermes Agent #22

Версия v0.20.2 объединяет около 397 PR, Bots Mode входит в фазу упаковки для desktop, проект перешагнул отметку в 2 500 контрибьюторов, а лимит контекста подписок ChatGPT и Codex вырастает до 900K токенов.

## v0.20.2: тег, объединяющий 397 PR

16 августа Hermes Agent выпустил v0.20.2 (v2026.8.16). Это patch-релиз: тег собирает около 397 pull request, смерженных после v0.20.1, в стабильную версию для нижестоящих потребителей (Docker-образы, размещённые деплойменты, новые установки).

За окно набежало около 967 коммитов в 1 279 файлах (+128 522 / −7 622). Изменения затрагивают несколько поверхностей:

- Desktop: реестр подключений с несколькими gateway, обновления, ограниченные профилем, проверки состояния MCP и deep links.
- CLI: пробы обновлений Windows, клавиатурный протокол Kitty, ужесточение чата опцией `-c`.
- Gateway: сохраняемые маршруты моделей, автодополнение `/loop`, темы Telegram в личных сообщениях.
- Кэш промптов для LiteLLM Claude на потоке OpenAI, ужесточение cron, разрешение аутентификации через scopes профиля и более надёжный установщик на Linux и Windows.

Подробные notes de release и полный список контрибьюторов появятся вместе с v0.21.0, который задокументирует всё, начиная с v0.20.0.

> Источник: [Release Hermes Agent v0.20.2](https://github.com/NousResearch/hermes-agent/releases/tag/v2026.8.16)

## Bots Mode входит в фазу упаковки

Вечером 16 августа Teknium объявил, что упаковывает Bots Mode для Hermes Agent Desktop в преддверии релиза: «Packaging up Bots Mode for Hermes Agent Desktop for release right now, stay tuned». Выпуск #20 анонсировал эту версию примерно на 17 августа; фаза упаковки сейчас в разгаре.

В ответах Teknium уточнил охват. Bots Mode — это лишь UX-слой поверх профилей агентов, не более. У каждого бота собственный gateway, что позволяет ему быть независимым ботом в Telegram или Discord. Возможность заставить несколько ботов общаться между собой также входит в обновление.

> Источники: [@Teknium, упаковка Bots Mode, 16 августа 2026](https://x.com/Teknium/status/2089098159217918249) - [@Teknium, Bots Mode = UX для профилей, 16 августа 2026](https://x.com/Teknium/status/2089131479561601296) - [@Teknium, gateway на каждого бота, 16 августа 2026](https://x.com/Teknium/status/2089111859903471667)

## Hermes Agent перешагнул 2 500 контрибьюторов

17 августа Teknium сообщил, что на этих выходных Hermes Agent преодолел отметку в 2 500 контрибьюторов. Он подчеркнул, что команда пока интегрировала лишь часть работы каждого: «мы едва затронули поверхность рецензирования и интеграции работы всех, кто внёс вклад».

> Источник: [@Teknium, 17 августа 2026](https://x.com/Teknium/status/2089186056973562102)

## Подписки ChatGPT и Codex: лимит 900K токенов

17 августа Teknium объявил, что лимит контекста для пользователей подписок ChatGPT и Codex в Hermes Agent вырастает до 900K токенов. Чтобы воспользоваться этим, нужно обновить Hermes. В треде — полезное уточнение: модель GPT-5.6 Sol с контекстом в 1M теперь работает и при использовании через аккаунты ChatGPT, тогда как раньше это было доступно только для API-ключей.

> Источник: [@Teknium, 17 августа 2026](https://x.com/Teknium/status/2089163355261214830)

## Laguna S 2.1 бесплатно ещё две недели на Nous Portal

Laguna S 2.1, модель от poolside, остаётся бесплатной ещё две недели на Nous Portal. Чтобы использовать её в своём агенте, достаточно выбрать `poolside/laguna-s-2.1:free` в `/model`.

> Источники: [@witcheer, 17 августа 2026](https://x.com/witcheer/status/2089361292549108152) - [@yeahfortommy, 17 августа 2026](https://x.com/yeahfortommy/status/2089359131933061161)
