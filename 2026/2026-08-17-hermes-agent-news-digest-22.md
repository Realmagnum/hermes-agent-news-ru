## v0.20.2: консолидация 397 пулл-реквестов

16 августа состоялся релиз Hermes Agent **v0.20.2** (тег `v2026.8.16`). Это накопительный патч-релиз: он объединил порядка 397 пулл-реквестов, влитых со времени выхода v0.20.1, предоставив стабильную кодовую базу для конечных потребителей (Docker-образы, облачные развертывания, свежие установки).

Окно изменений охватывает 967 коммитов в 1 279 файлах (+128 522 / −7 622 строк кода). Обновления затронули практически все компоненты:

- **Desktop:** реестр мульти-gateway подключений, изолированное обновление данных по профилям, валидация состояния MCP-серверов и поддержка диплинков.
- **CLI:** опрос наличия обновлений под Windows, поддержка протокола клавиатуры Kitty, повышение надежности и защищенности сессий чата при запуске с флагом `-c`.
- **Gateway:** персистентная маршрутизация моделей, автодополнение команды `/loop`, поддержка топиков Telegram для прямого общения (DM).
- **Инфраструктура и рантайм:** кэширование промптов для LiteLLM Claude поверх стрима OpenAI, стабилизация планировщика cron, сквозная аутентификация между скоупами профилей, а также доработанные и более надежные инсталляторы для Linux и Windows.

Развернутые release notes и полный список благодарностей контрибьюторам будут опубликованы с выходом v0.21.0, где подведут итоги всех изменений с момента релиза v0.20.0.

> **Источники:**
> - [Release Hermes Agent v0.20.2 (16 августа 2026)](https://github.com/NousResearch/hermes-agent/releases/tag/v2026.8.16)

## Bots Mode переходит на стадию сборки

Вечером 16 августа @Teknium объявил о начале финальной сборки и упаковки режима **Bots Mode** для Hermes Agent Desktop:  
> *"Packaging up Bots Mode for Hermes Agent Desktop for release right now, stay tuned"*.

В комментариях к анонсу разработчик подробно объяснил архитектуру фичи. **Bots Mode** представляет собой удобную UX-надстройку над профилями агентов:
- За каждым ботом закреплен собственный gateway, что позволяет запускать его в качестве полностью независимого агента в Telegram или Discord.
- Прямо «из коробки» поддерживается сценарий, при котором несколько ботов могут общаться и взаимодействовать между собой в общем контексте.

> **Источники:**

> - [@Teknium — Bots Mode = UX для профилей (16 августа 2026)](https://x.com/Teknium/status/2089131479561601296)

## Подписки ChatGPT и Codex: лимит контекста вырос до 900K токенов

17 августа объявлено об увеличении лимита контекста для пользователей подписок ChatGPT и Codex в Hermes Agent до **900K токенов**. Чтобы применить новые квоты, пользователям достаточно обновить агент до актуальной версии.

Также в треде уточнили важную деталь: модель **GPT-5.6 Sol** с контекстным окном в 1M токенов теперь полностью доступна при авторизации через аккаунты ChatGPT (ранее запуск этой модели требовал прямого подключения через API-ключ).

> **Источники:**
> - [@Teknium — Лимиты ChatGPT/Codex до 900K (17 августа 2026)](https://x.com/Teknium/status/2089163355261214830)

## Laguna S 2.1 бесплатен еще две недели на Nous Portal

Модель **Laguna S 2.1** от poolside остается бесплатной на Nous Portal еще на две недели. 

Чтобы подключить ее к своему агенту, выберите модель через интерфейс команд:
```bash
/model poolside/laguna-s-2.1:free
```
