## Fast Search от Perplexity становится поиском по умолчанию в Hermes Agent

24 сентября команда Nous Research объявила, что веб-поиск в Hermes Agent стал быстрым и полностью бесплатным: Perplexity разработала специализированный движок **Fast Search** для агентов и открыла к нему доступ на всех уровнях подписки Nous Portal. В Perplexity подтвердили, что Fast Search теперь назначен поисковым сервисом по умолчанию для пользователей Nous Portal. Решение оптимизировано под агентные сценарии: задержка одного поискового вызова составляет всего **160 мс (p50)** и **230 мс (p95)**.

Под капотом Fast Search работает **Photon** — движок извлечения и ранжирования (retrieval & ranking), написанный инженерами Perplexity на Rust с привлечением кодинг-агентов взамен прежнего open-source решения. 

Ключевые показатели нового поискового пресета:
- **Снижение затрат:** совокупная стоимость связки «модель + поиск» на одну задачу сократилась на **68%** (по результатам шести бенчмарков при сопоставимом качестве выдачи).
- **Экстремальная скорость:** внутренняя задержка ранжирования p99 упала с ~800 мс до **65 мс**.
- **Эффективность инфраструктуры:** система потребляет на 20% меньше серверов, сохраняя при этом в 2,5 раза больше данных на каждый документ.
- **Сценарии применения:** пресет Fast Search рекомендован для типовых агентных пайплайнов, тогда как стандартный режим лучше справляется со сложными и неоднозначными запросами.

Как переключиться:
По словам разработчика @witcheer, если поиск уже настроен через подписку Nous Portal, переход произойдет автоматически сразу после обновления при первом же ответе. В остальных случаях достаточно переключить маршрут поиска через CLI:
```bash
hermes tools
```
Инструмент по-прежнему вызывается через стандартный вызов `web_search`.

## Стабильный релиз Cua Driver для Omarchy: нативный синтетический курсор

25 сентября проект Cua представил стабильную версию **Cua Driver** для дистрибутива Omarchy — архитектурную основу для **Computer Use**, интегрированную непосредственно в ядро и оконную подсистему ОС. В течение месяца разработчики Cua вели совместную работу с @dhh, @SpencerGBull и @vaxryy, чтобы внедрить нативную поддержку виртуального (синтетического) курсора прямо в композитор **Hyprland**. Кодовая база драйвера полностью открыта.

Принципиальное отличие от macOS и Windows:
- На коммерческих платформах фоновый Computer Use до сих пор опирается на компромиссы, костыли и обходные пути оконных серверов при попытке эмулировать несколько указателей мыши одновременно.
- В Omarchy композер изначально управляет двумя независимыми курсорами (пользовательским и агентным) и изолированно маршрутизирует их события в нужные окна. Действия агента больше не перехватывают фокус экрана и не мешают параллельной работе человека за компьютером.

Сборка доступна в ветке **Edge** дистрибутива Omarchy; разработчики Cua Driver также подготовили официальные бинарные артефакты для архитектуры Linux ARM64. Как подчеркнул @witcheer, подсистема Computer Use в Hermes Agent функционирует именно поверх Cua Driver, поэтому нативный уровень абстракции существенно повышает стабильность всего стека.

## Стелс-модель Space Bunny Alpha стала бесплатной на Nous Portal

@witcheer опубликовал первые отзывы о стелс-модели **Space Bunny Alpha**, которая теперь доступна без дополнительной платы всем пользователям Nous Portal. 

Среди ключевых преимуществ модели:
- **Высокая скорость и лаконичность:** модель генерирует короткие и точные цепочки рассуждений без лишней «воды», что критически важно в агентных контурах, где каждый вызов внешнего инструмента вынужден ждать генерации токенов.
- **Огромный контекст:** контекстное окно составляет **1 миллион токенов**.
- **Мультимодальность:** нативная поддержка обработки изображений и видео.

Для подключения модели в консоли Hermes Agent достаточно выполнить команду:
```bash
/model stealth/space-bunny-alpha
```
Ранее о запуске модели также сообщил @yeahfortommy, подтвердив ее полную готовность к работе внутри экосистемы Hermes.

## Hermes Desktop переведен на девять языков

@witcheer сообщил, что интерфейс **Hermes Desktop** получил масштабное обновление локализации и теперь поддерживает девять языков:
- Русский
- Английский
- Упрощенный китайский
- Традиционный китайский
- Японский
- Арабский
- Французский
- Немецкий
- Испанский

Переключить язык интерфейса можно в меню: `Настройки` → `Внешний вид` → `Язык` (`Settings` → `Appearance` → `Language`).

## Bot Screen теперь доступен со смартфона через Herald

Разработчик @iamlukethedev продемонстрировал работу режима **Bot Screen** на мобильных устройствах после добавления соответствующей интеграции в утилиту Herald.

Теперь пользователи могут открыть смартфон и в режиме реального времени наблюдать за тем, как агент Hermes взаимодействует с рабочим столом компьютера. Если агент сталкивается с задачей, требующей ручного вмешательства человека (например, прохождение капчи или авторизация), пользователь может перехватить управление прямо с экрана телефона, выполнить действие и вернуть управление агенту.

> **Источник:**
> - [@iamlukethedev — Hermes Bot Screen is now on my phone (24 сентября 2026)](https://x.com/iamlukethedev/status/2103002905959936334)
