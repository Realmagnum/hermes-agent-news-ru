# Новости Hermes Agent #8

Массовые оптимизации (Nemo Relay), Qwen 3.8 Max интегрирует Hermes Agent, DeepSeek V4 Flash −90 % и туториал по Buzz.

## Оптимизации Hermes Agent: −90 % токенов, новая модель не за горами

Teknium анонсировал 2 августа, что Hermes Agent только что получил глубокие оптимизации, выявленные с помощью инструмента Nemo Relay от NVIDIA и ряда других стратегий.

Выигрыш цифрами:

- **На 36 % меньше раундов** на задачу (с 6,9 до 4,4)
- **На 46 % меньше ошибок инструментов** на задачу (с 3,3 до 1,8)
- **На 87 % меньше растраченных токенов** на полную задачу (с 1,2M до 159K)
- **На 91 % меньше входных токенов** на задачу (с 5,7K до 488)

Эти результаты получены из анализа 250 000 разговоров Teknium со своим Hermes: трассировались лишние раунды, ошибки и расход схемы, чтобы понять, где можно сэкономить каждый байт.

Оптимизации уже доступны в Hermes Agent через `hermes update`. Teknium уточняет, что полная версия релиза (v0.19.2 или v0.20.0) будет опубликована на следующий день (3 августа).

> Источник: [@Teknium, 2 августа 2026](https://x.com/Teknium/status/2084065915004747888) — [@Teknium, 2 августа 2026](https://x.com/Teknium/status/2084066111625318789)

## DeepSeek V4 Flash 0731 со скидкой −90 % в Nous Portal

Nous Research анонсировал 2 августа скидку 90 % на DeepSeek V4 Flash 0731 через Nous Portal в партнёрстве с Novita Labs — на ближайшие 7 дней.

По сниженным ценам модель более чем в 1000 раз дешевле Fable 5 на сопоставимых задачах, при этом превосходя её на Terminal-Bench 2.1.

Комментарий Teknium: «Интеллект настолько дёшев, что хочется измерять его, чтобы показать: нескольких центов достаточно, чтобы построить империю».

> Источник: [@NousResearch, перепост @Teknium, 2 августа 2026](https://x.com/NousResearch/status/2083953441571742191) — [@Teknium, 2 августа 2026](https://x.com/Teknium/status/2083956677947383927)

## Qwen 3.8 Max интегрирует Hermes Agent в своё видео запуска

3 августа Qwen (Alibaba) анонсировал Qwen 3.8 Max — новую модель для кодинга, а также локальную модель 27B. В своём видео запуска Alibaba_Qwen выделил Hermes Agent.

«Спасибо @Alibaba_Qwen за то, что показали Hermes Agent в видео запуска!» — ответил Teknium.

Это заметное признание для проекта: Qwen, один из ведущих игроков домена, выбрал Hermes Agent в качестве демонстрационной платформы для своей новой модели.

> Источник: [@Teknium, 3 августа 2026](https://x.com/Teknium/status/2084140512777560537) — [@Alibaba_Qwen, 3 августа 2026](https://x.com/Alibaba_Qwen/status/2084093402967396594)
