## Оптимизация Hermes Agent: минус 90% токенов и скорый релиз новой модели

2 августа @Teknium объявил о масштабной внутренней оптимизации **Hermes Agent**. Узкие места удалось выявить благодаря профилированию с помощью инструмента **Nemo Relay** от NVIDIA, а также ряду сопутствующих архитектурных улучшений.

Результаты в цифрах впечатляют:
- **На 36% меньше раундов (turns)** на выполнение задачи (снижение с 6,9 до 4,4);
- **На 46% меньше ошибок вызова инструментов** на задачу (падение с 3,3 до 1,8);
- **На 87% меньше неэффективно израсходованных токенов** на полный цикл задачи (падение с 1,2 млн до 159 тыс.);
- **На 91% меньше входных токенов (input tokens)** на задачу (сокращение с 5,7 тыс. до 488).

Эти показатели получены на основе анализа 250 000 диалогов @Teknium с Hermes. Разработчики детально отследили лишние шаги, сбои выполнения и накладные расходы на схемы данных, выжав экономию буквально из каждого байта.

Улучшения уже доступны пользователям. Чтобы применить их, достаточно выполнить команду обновления:

```bash
hermes update
```

Полноценный мажорный релиз с новым функционалом (`v0.19.2` или `v0.20.0`) ожидается 3 августа.

## Скидка 90% на DeepSeek V4 Flash 0731 в Nous Portal

Команда **Nous Research** совместно с **Novita Labs** запустила недельную промо-кампанию: стоимость доступа к **DeepSeek V4 Flash 0731** через **Nous Portal** снижена на 90%.

С учетом дисконта инференс модели обходится более чем в 1000 раз дешевле Fable 5 при решении сопоставимых задач, при этом DeepSeek обходит конкурента в бенчмарке **Terminal-Bench 2.1**.

@Teknium прокомментировал это событие:  
> «Интеллект стал настолько дешевым, что его хочется измерять лишь затем, чтобы доказать: для постройки империи хватит нескольких центов».

## Qwen 3.8 Max продемонстрировал Hermes Agent в релизном ролике

3 августа команда Qwen (Alibaba) представила новую модель для кодинга **Qwen 3.8 Max**, а также локальную версию на 27B параметров. Примечательно, что в официальном демонстрационном видео Alibaba_Qwen показала связку модели именно с **Hermes Agent**.

@Teknium поблагодарил разработчиков:  
> «Спасибо @Alibaba_Qwen за то, что показали Hermes Agent в промо-ролике запуска!»

Для open-source проекта это серьезное признание: один из ключевых игроков мирового AI-рынка выбрал Hermes Agent в качестве эталонной платформы для демонстрации возможностей своей флагманской кодинг-модели.

> - [@Alibaba_Qwen — Официальный анонс Qwen 3.8 Max (3 августа 2026)](https://x.com/Alibaba_Qwen/status/2084093402967396594)
