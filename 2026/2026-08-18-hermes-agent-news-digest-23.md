# Новости Hermes Agent #23

Bot Mode официально выходит в Hermes Desktop, релиз v0.20.4 объединяет 74 PR, а функция нативных виджетов позволяет отображать графики в реальном времени прямо в чате.

## Bot Mode официально выходит в Hermes Desktop

17 августа Nous Research анонсировал выход Bot Mode для Hermes Agent Desktop: «Introducing Bot Mode for Hermes Desktop. Your agent profiles become a series of named Bots. Each Bot has its own role, model, memory, skills and profile picture; Bots can use any model and even communicate with each other. Build a specialist Bot once to use it forever.»

Teknium уточнил позиционирование: Bot Mode — это альтернатива режиму сессий, где на каждый профиль агента приходится один разговор, или «бот». Каждый бот получает задачи, описание, фото профиля и общается с другими ботами. Боты сохраняют собственную память, скиллы, инструменты и внешние подключения.

Этот релиз продолжает публичную бету от 13 августа (выпуск #19) и фазу упаковки, анонсированную 16 августа (выпуск #22). Функция теперь встроена в основное desktop-приложение.

Tonbi сопроводил запуск демо групповых чатов: несколько специализированных ботов совместно ведут крупный игровой проект, опираясь на свой опыт. Один сообщает о завершении своего проекта и предлагает помощь, другой считает, что это подходит под front-end-работу следующего этапа, третий предлагает взять конкретный тикет, а выбранный бот читает связанные документы, прежде чем запросить одобрение на выполнение задачи.

## v0.20.4: тег, объединяющий 74 PR

18 августа Hermes Agent выпустил v0.20.4 (v2026.8.18). Это patch-релиз, объединяющий около 74 pull request, смерженных после v0.20.3 (тег от 17 августа), — примерно 146 коммитов в 265 файлах (+21 697 / −2 217).

Изменения затрагивают несколько поверхностей:

- Desktop: работа над стеклянной/полупрозрачной поверхностью (матовое стекло, селектор эффекта матирования, предварительный выбор macOS).
- Desktop: вкладчатая боковая панель SESSIONS|BOTS со скрытием/отображением по каждому боту.
- Bot Mode: исправления групповых чатов (длинные ходы участников, рендеринг Markdown, маршрутизация между машинами).
- Skills: скан отзывов NVIDIA SkillEvaluator Tier 1 при установке (проверки лицензии и безопасности).
- Cron: ужесточение отправки медиа (настраиваемая задержка, вложения при ручном запуске, сигнализация о пропущенных запусках).
- База данных: исправления event-loop и конфликтов доступа к SessionDB.
- CLI: `hermes update` теперь честно сообщает об ожидающих ветках.
- Kanban: нативные уведомления операционной системы.

Подробные примечания к релизу и полный список контрибьюторов появятся вместе с v0.21.0, который задокументирует всё, начиная с v0.20.0.

> Источник: [Release Hermes Agent v0.20.4](https://github.com/NousResearch/hermes-agent/releases/tag/v2026.8.18)

## Нативные виджеты, отображаемые в чате

17 августа imbabybrooklyn показал функцию нативных виджетов, генерируемых в Hermes Agent. Принцип: скилл может рендерить компонент интерфейса прямо в разговоре. В примере скилл `/get-price btc` отображает в чате график цены в реальном времени вместо текста.

Демонстрация иллюстрирует границу между командой и интерфейсом: вывод скилла не ограничен текстом — он может создавать встроенный интерактивный виджет.
