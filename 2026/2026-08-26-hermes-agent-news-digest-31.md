# Новости Hermes Agent #31

Этот выпуск об расширении каталога MCP-коннекторов Hermes, о связывании cron-задач, объяснённом witcheer в пятидесятом пятом выпуске его серии, о решающем критерии для выбора локальной модели и о доступности GLM-5.3 Flash в Nous Portal после окончания бесплатности Ox Alpha.

## Каталог коннекторов MCP получает 44 новых подключения

Nous Research объявил о расширении встроенного каталога MCP-коннекторов Hermes, который теперь предлагает 44 новых подключения к распространённым приложениям, устанавливаемым одним кликом из десктопного приложения. Анонс выделяет доступ к Cloudflare, Datadog, Metabase, GitLab, Railway и DeepWiki, а также другим сервисам и источникам данных.

Документация Hermes описывает этот каталог как набор MCP-серверов, проверенных и объединённых командой Nous, отключённых по умолчанию: вы устанавливаете только то, что нужно. При установке Hermes опрашивает сервер для перечисления экспортируемых инструментов и показывает чекбокс-лист. Из терминала команды `hermes mcp` (интерактивный селектор), `hermes mcp catalog` (текстовый список) и `hermes mcp install <name>` управляют установкой. Записи хранятся в директории `optional-mcps/` репозитория hermes-agent, их наличие означает одобрение Nous; этапа community-субмиссии не существует, записи добавляются через merge-запрос.

> Источники: [@NousResearch, 44 новых подключения в каталоге, 25 августа 2026](https://x.com/NousResearch/status/2092326815193055681), [@NousResearch, сервисы теперь доступны, 25 августа 2026](https://x.com/NousResearch/status/2092321384085299665) и [Hermes Agent, страница MCP документации](https://hermes-agent.nousresearch.com/docs/user-guide/features/mcp)

## Wingtips #55: связывание cron-задач

Пятидесятый пятый номер серии witcheer посвящён связыванию cron-задач. Каждая cron-задача запускается в новой сессии, так что пайплайн в два шага, например сборка затем суммирование, по умолчанию не видит, что произвёл первый шаг. Связывание осуществляется через `context_from`: создавая вторую задачу, указываем её на идентификатор первой, которая передаст ей свой вывод.

> Источник: [@witcheer, Hermes Wingtips #55, связывание cron-задач, 26 августа 2026](https://x.com/witcheer/status/2092527968140632114)

## Выбор локальной модели: ability tool calling прежде всего

witcheer напоминает критерий, имеющий наибольшее значение в спецификации локальной модели для Hermes: строка, которая важна — обучена ли модель вызывать инструменты. Ниже этого порога вы получаете модель, которая повествует: она пишет вызов инструмента явно текстом, и ничего больше не выполняется.

## GLM-5.3 Flash заменяет Ox Alpha в Nous Portal

Teknium указывает, что бесплатный период Ox Alpha через Nous Portal завершён, и GLM-5.3 Flash теперь доступен тем, кто хочет продолжить использование.
