## Каталог MCP-коннекторов пополнился 44 новыми интеграциями

Команда Nous Research объявила о масштабном расширении встроенного каталога MCP-коннекторов (Model Context Protocol) в Hermes Agent. В каталог добавили 44 новые интеграции с популярными сервисами, доступные для установки в один клик прямо из десктопного приложения. 

Среди добавленных платформ — **Cloudflare**, **Datadog**, **Metabase**, **GitLab**, **Railway**, **DeepWiki** и многие другие источники данных.

Особенности работы с каталогом:
- **Безопасность и оптимизация ресурсов:** каталог представляет собой подборку проверенных серверов MCP, которые по умолчанию отключены — вы подключаете только те инструменты, которые действительно нужны в работе.
- **Интерактивная настройка:** при установке Hermes опрашивает выбранный сервер, получает список доступных инструментов и выводит удобный список с чекбоксами для выборочной активации.
- **Управление через CLI:**
  - `hermes mcp` — запуск интерактивного меню выбора;
  - `hermes mcp catalog` — вывод текстового списка всех доступных коннекторов;
  - `hermes mcp install <name>` — быстрая установка конкретного коннектора по имени.
- **Модель поставки:** манифесты интеграций хранятся в каталоге `optional-mcps/` репозитория hermes-agent. Наличие коннектора в этой директории подтверждает проверку со стороны команды Nous Research. Отдельного маркетплейса нет — новые коннекторы попадают в релиз напрямую через мердж пулл-реквестов.

## Wingtips #55: связывание cron-задач в цепочки

В 55-м выпуске обучающей серии инженер @witcheer разобрал организацию пайплайнов из cron-задач.

Каждая cron-задача в Hermes запускается в абсолютно чистой изолированной сессии. Из-за этого двухэтапный сценарий (например, «собрать метрики», а затем «сформировать саммари») по умолчанию не видит артефакты выполнения первого шага. 

Связать их между собой позволяет параметр `context_from`: при создании второй задачи достаточно указать идентификатор (ID) первой — и Hermes автоматически пробросит её выходные данные в контекст следующего шага.

> **Источник:**
> - [@witcheer — Hermes Wingtips #55: чейнинг cron-задач (26 августа 2026)](https://x.com/witcheer/status/2092527968140632114)

## Выбор локальной модели: поддержка tool calling превыше всего

@witcheer напомнил о главном техническом критерии при подборе локальной LLM для Hermes: критически важно наличие полноценного обучения механизму вызова инструментов (**tool calling**).

Если модель не натренирована на вызов функций, агент скатывается в обычное «повествование»: LLM просто генерирует в чат текст о том, какую команду или инструмент она вызвала бы, но фактически вызов не инициируется и сценарий не выполняется.

> **Источник:**
> - [@witcheer — Критерии выбора локальной модели для Hermes (26 августа 2026)](https://x.com/witcheer/status/2092589072480919837)
