## Официальный плагин REA для обратного инжиниринга

15 октября Teknium представил официальный плагин REA (Reverse Engineer Anything) для Hermes Agent. Установка выполняется двумя командами:

```bash
hermes plugins install rea
hermes plugins enable rea
```

Плагин добавляет MCP-сервер REA и скилл с инструкциями по его использованию. Он умеет исследовать:

- Нативные исполняемые файлы и библиотеки, .NET-сборки, приложения Electron и JavaScript;
- Android-пакеты и образы прошивок;
- сетевые и браузерные HAR-захваты;
- поведение программ во время выполнения.

REA выдаёт структурированные результаты — декомпилированный код, графы вызовов и приложения, а также захваты. Hermes может объяснить эти данные или использовать их как основу для дальнейшей работы.

В каталоге указано, что пакет поддерживает morluto (`morluto/rea`) и распространяется по лицензии MIT. Он фиксирует версию `rea-agents@6.4.0` и запускает её через `npx -y rea-agents@6.4.0 mcp` по протоколу stdio при каждой сессии, пока плагин включён. Примерно 170 инструментов доступны под именами `mcp__rea__<инструмент>` и вызываются через механизм Hermes для поиска инструментов по запросу.

Для статического анализа, JavaScript, Electron, архивов, метаданных .NET, PE-ресурсов и HAR-захватов достаточно Node.js 22.19 или новее. Для декомпиляции нативного кода нужно отдельно установить движок: Ghidra с JDK, Hopper или IDA; для Android — JADX, для прошивок — Binwalk или Unblob. REA не устанавливает эти зависимости, а скилл отдельно предписывает агенту не делать этого. Отдельный для каждого сервера лимит вызовов появится в Hermes v0.23.0.

## Nemotron 3.5 Super VL набрал 63,44 балла в Hermes Bench

15 октября Nous Research заявила, что Hermes Agent — лучшее место для работы с новыми моделями NVIDIA Nemotron 3.5 Super VL и Bolt. По данным Nous Research, NVIDIA оценила Super VL в Hermes Bench на **63,44 балла**. По сравнению с сопоставимыми локальными моделями его скорость генерации может быть до **5 раз выше**.

NVIDIA описывает Super VL как открытую модель, объединяющую рассуждения и использование инструментов с пониманием текста, изображений, документов и видео. Она предназначена для длительных агентных задач и насчитывает **120 млрд параметров**, из которых **12 млрд активны**.

## 15 октября смержили 50 пулл-реквестов

16 октября iamlukethedev сообщил, что за предыдущий день в Hermes смержили **50 пулл-реквестов**. Среди отмеченных изменений:

- Новая установка теперь использует последнюю стабильную версию, а не нестабильную сборку из ветки `main`.
- `hermes update` больше не отклоняет стабильный канал, если Git не сразу находит новый релиз.
- Команда `/loop` теперь показывает ход выполнения в реальном времени.

## sem-weave: ревью кода на уровне функций

16 октября witcheer сообщил о появлении sem-weave в каталоге плагинов: агент проверяет код не построчно, а на уровне функций. Можно спросить, где определена функция и кто её вызывает, — в ответе будут её определение и все места вызова с файлами и номерами строк.

Согласно описанию в каталоге, пакет от Ataraxy Labs (`Ataraxy-Labs/sem`) включает два скилла:

- `sem-code-review` — поиск функций и классов, проверка вызывающих участков и ревью Git-diff на уровне сущностей;
- `weave-merge-preview` — предварительный анализ слияния ветки без его применения.

Пакет добавляет инструкции, но не инструменты: он использует существующие терминал хоста и процесс подтверждения действий. Для работы необходим Sem (проверена версия 0.27.0); Weave (0.5.4) можно установить дополнительно. Обе зависимости устанавливаются отдельно.
