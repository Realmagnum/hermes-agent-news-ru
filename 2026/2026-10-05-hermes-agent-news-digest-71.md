## Wingtips #92: Nous Portal в одну команду

В 92-м выпуске заметок Wingtips разработчик @witcheer рассказал о команде `hermes setup --portal`. На чистой установке всего одна команда связывает Hermes Agent с Nous Portal, назначает Nous провайдером моделей и включает Tool Gateway: в браузере открывается окно авторизации, пользователь выбирает модель — и агент готов к диалогу.

В документации портала процесс описан подробнее:
- Команда запускает OAuth-авторизацию через portal.nousresearch.com и сохраняет refresh-токен в `~/.hermes/auth.json`.
- Предлагает выбрать модель Nous и прописывает `model.provider: nous` в `config.yaml`.
- Активирует **Tool Gateway** для веб-поиска, генерации изображений, синтеза речи (TTS) и автоматизации браузера.

Если подписки нет, сначала потребуется зарегистрироваться на portal.nousresearch.com/manage-subscription. Если агент уже настроен с другим провайдером, подключить портал параллельно можно через `hermes model` (выбрав Nous Portal) либо с помощью `hermes portal`. Статус подключения, текущую модель и состояние Tool Gateway можно проверить командой:

```bash
hermes portal info
```

## Каталог плагинов приближается к 500 записям

4 октября @Teknium сообщил о стремительном росте каталога плагинов Hermes Agent: база насчитывает уже почти 500 модификаций, расширяющих возможности агента, добавляющих новых провайдеров моделей, улучшения долгосрочной памяти, визуальные интерфейсы и многое другое. Любой плагин ставится по имени:

```bash
hermes plugins install <имя_плагина>
```

На момент публикации страница каталога насчитывает 448 позиций, разбитых по 9 категориям: 9 официальных решений и 439 плагинов от сообщества. Самые популярные разделы:
- **Инструменты (Tools):** 122
- **Desktop:** 112
- **Память (Memory):** 48
- **Модели:** 35
- **Автоматизация:** 33
- **Веб и браузер:** 33

Каждый плагин в каталоге жестко зафиксирован за конкретным коммитом и проходит ручной код-ревью командой проекта перед публикацией.

## Коллекция из 68 готовых профилей по вселенной Star Trek

4 октября обозреватель @HermesWatcher обратил внимание на репозиторий из 68 готовых профилей, опубликованный в аккаунте GitHub @teknium1. Автор подчеркивает: это не просто скины или косметические промпты. Каждый профиль реализует собственный стиль рассуждения, сильные стороны, рабочий метод и паттерны поведения. @BkashJosi приводит примеры специализации:
- **Spock** — для глубокого траблшутинга и расследования причин сбоев;
- **Data** — для скрупулезного анализа датасетов;
- **Picard** — для взвешивания сложных стратегических решений;
- **Worf** — для аудита безопасности и анализа уязвимостей.

Репозиторий `hermes-star-trek-profiles` охватывает сериалы The Original Series, The Next Generation, Deep Space Nine и Voyager. Каждый персонаж оформлен как изолированный бандл, включающий:
- Проработанный файл `SOUL.md` (идентичность, голос, картина мира, методология, слепые зоны, поведение под стрессом и специфика аргументации);
- Стилизованную тему для терминала;
- Провайдер-нейтральный `config.yaml`.

Профили не содержат секретов, дампов памяти, истории сессий или cron-задач, оставляя настройки LLM-провайдеров на усмотрение пользователя. Установка выполняется скриптом `manage.py` (можно поставить одного персонажа, франшизу целиком или весь набор с флагом `--alias`). Проект распространяется как неофициальная фанатская коллекция.

## Запуск нескольких агентов с помощью профилей

Отвечая на частые вопросы сообщества, @witcheer опубликовал краткое руководство по запуску нескольких независимых агентов. Для разграничения контекстов (например, работа, личные дела, домашняя автоматизация) используются профили. Каждый профиль представляет собой изолированный домашний каталог Hermes и автоматически превращается в отдельную CLI-команду.

Архитектура профиля включает собственный `config.yaml`, файл `.env`, инструкции `SOUL.md`, базу памяти, сессии, скиллы, cron-задачи и БД состояния.

Типичный воркфлоу выглядит следующим образом:

```bash
# Создание профиля и регистрация CLI-алиаса coder
hermes profile create coder

# Настройка ключей и моделей в изолированном профиле
coder setup

# Запуск чата
coder chat
```

**Важное правило:** два параллельных процесса никогда не должны работать с одним и тем же профилем одновременно во избежание конфликтов записи памяти. 

Для создания профилей на базе уже настроенных окружений предусмотрены флаги клонирования:
- `--clone` — переносит конфигурацию, скиллы и память идентичности;
- `--clone-all` — копирует вообще всё, кроме истории диалогов и cron-задач.

Быстрее всего инициализировать новый профиль с помощью команды `hermes setup --portal` — она мгновенно подключит нужные модели и шлюз инструментов.

## Покерный стол для агентов

Разработчик @tonysimons_ представил проект **Agent Hold'em** — виртуальный покерный стол для агентов Hermes. Несколько независимых LLM-агентов собираются за одной игрой в Texas Hold'em: блефуют, повышают ставки, сбрасывают карты и пытаются переиграть друг друга. По словам автора, наблюдать за тем, как агенты с невозмутимым видом совершают катастрофические покерные ошибки, — отдельное удовольствие.
