## Wingtips #84: mcp.discovery_concurrency

witcheer посвятил 84-й выпуск Wingtips параметру `mcp.discovery_concurrency` — новой опции в Hermes Agent, которая ограничивает количество одновременно подключаемых MCP-серверов. Серверы, объявленные в конфигурации, подключаются при старте Hermes Agent, при этом каждый локальный сервер запускается в отдельном процессе.

В документации по MCP приводятся подробности этой настройки. Hermes обнаруживает MCP-серверы при запуске и регистрирует их инструменты в стандартном реестре. Серверы подключаются пакетами максимум по четыре за один проход обнаружения — при запуске, по команде `/reload-mcp` и при срабатывании наблюдателя конфигурации. Каждый stdio-сервер порождает собственное дерево дочерних процессов, поэтому поиск без ограничений при большом количестве серверов приводил к их одновременному запуску, вызывая всплеск нагрузки на CPU и RAM, а на масштабных мультипрофильных инсталляциях — шквал параллельных обращений к провайдерам. Параметр задается в `config.yaml` под ключом `mcp.discovery_concurrency` (по умолчанию равен четырем; значение ноль снимает ограничение).

## Канбан-доска Hermes Agent переходит на двухколоночный вид

26 сентября Tony Simons представил масштабный редизайн интерфейса канбан-доски Hermes Agent, подчеркнув, что это далеко не просто косметическое обновление. Новый двухколоночный вид задачи объединяет комментарии, активность, запуски и логи воркера в единую ленту, в зависимостях отображаются действительно связанные задачи, обеспечен полноценный рендеринг Markdown, а свойства стали выглядеть аккуратнее. Доступно видео с демонстрацией.

witcheer дополнил в тот же день: при открытии активной задачи поле ввода комментария отправляет сообщения напрямую воркеру, что позволяет управлять процессом прямо из текущего окна.

> Источники: [@tonysimons_, Hermes Agent's Kanban just got a MASSIVE UI upgrade, 26 сентября 2026](https://x.com/tonysimons_/status/2103707278037631420) и [@witcheer, the comment box goes straight to the worker, 26 сентября 2026](https://x.com/witcheer/status/2103770155423600646)

## Hermes Agent пишет собственное руководство

26 сентября witcheer поделился промптом, с помощью которого Hermes Agent сам составляет руководство по своей настройке: используемая модель, провайдер, платформы, cron-задачи, скиллы (skills), пути к памяти и сессиям, а также инструкции по резервному копированию. Агент проверяет каждую строчку непосредственно на машине, а ключи помечаются как «set» или «not set». Готовый промпт для копирования опубликован в первом комментарии к посту.

> Источник: [@witcheer, your Hermes Agent can write its own manual, 26 сентября 2026](https://x.com/witcheer/status/2103764777621147741)

## Голосовое управление в Hermes OS

25 сентября iamlukethedev продемонстрировал работу недавно добавленного нативного голосового управления: после единственной команды «Создай сайт для парикмахерской» агент начал писать код, переключаться между окнами и собирать сайт прямо на глазах пользователя, при этом за всем процессом можно было наблюдать в реальном времени.

Этот твит развивает презентацию Hermes OS — разрабатываемой им системы на базе Linux с рабочим столом, лаунчером приложений и раздельными пространствами для личных дел, работы и идей.
