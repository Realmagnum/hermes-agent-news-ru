## 138 пулл-реквестов смерджено 28 сентября

Разработчик @iamlukethedev подвел итоги масштабного дня разработки: 28 сентября в репозиторий Hermes влили сразу 138 пулл-реквестов. Изменения затронули интерфейс (47), голосовые модули и real-time (1), инструменты и плагины для разработчиков (51), безопасность и работу с секретами (7), чат и интеграции (8), а также общую стабильность системы (24). 

Ключевые нововведения релиза:
- **Изоляция окружения:** Bot Screen, `computer_use` и встроенный браузер теперь запускаются внутри песочницы терминального бэкенда.
- **Новый образ песочницы:** для Desktop опубликован Docker-образ `nousresearch/hermes-sandbox:desktop`, оснащенный графическим стеком дисплея.
- **Полноценная i18n:** реализованы подключаемые и накладываемые языковые пакеты для Core, TUI и Desktop с паритетом локализации на 16 языках.
- **Контекст сессий:** Desktop и TUI теперь взаимодействуют с профилем-владельцем текущей сессии, а не с профилем, запустившим бэкенд.
- **Синхронизация настроек:** параметры в Desktop теперь корректно считывают и перезаписывают отображаемый профиль (аппрувы, бэкенд, хранилище секретов и токены).
- **Мультиплексирование cron:** планировщик задач учитывает профиль владельца задачи при доставке сообщений, маршрутизации и получении секретов.
- **Поддержка моделей:** Claude Sonnet 5.5 добавлен в каталоги OpenRouter и Nous Portal.
- **Прозрачная телеметрия:** опциональная (opt-in) отправка метрик отображает сбои, удержание, процент отказов, а также затраты на конфигурацию и модели — строго с согласия пользователя в Desktop.
- **Сжатие контекста:** компактизация вновь ориентируется на параметр `compression.threshold` вместо жестко заданного лимита в 256 000 токенов.
- **Расширение экосистемы плагинов:** каталог пополнился Nachos, unbrowse, антигравитационной авторизацией OAuth, графом памяти PIR8 brain graph, эмулятором Android и другими инструментами.
- **Индикация OAuth:** статус авторизации Qwen теперь выводит срок действия токена, его превью и путь к файлу учетных данных.
- **Стабильность cron:** задачи с безопасным перезапуском больше не падают из-за отсутствия модуля `ruamel` в режиме мультиплексирования.

## Новая вкладка Skills в Hermes Desktop

@witcheer опубликовал короткий видеообзор обновленной вкладки **Skills** в Hermes Desktop. 

Интерфейс раздела скиллов переработали: к привычному списку добавился карточный режим просмотра, позволяющий комфортно просматривать как уже установленные навыки, так и общий каталог. Как отмечает @tonbistudio, теперь пользователи могут включать и отключать скиллы индивидуально для каждого профиля, а также находить и инсталлировать новые расширения напрямую из каталога в пару кликов.

## Десять промптов Hermes Autopilot от witcheer

@witcheer собрал подборку из десяти готовых промптов для **Hermes Autopilot** на единой странице. Каждый сценарий предназначен для запуска в новой сессии диалога.

Серия охватывает широкий спектр задач автоматизации:
- обучение агента индивидуальному стилю работы;
- упаковка недавних действий в переиспользуемый скилл;
- аудит текущей конфигурации системы;
- автогенерация еженедельного отчета за понедельник;
- автоматическое составление файла `AGENTS.md` для репозитория проекта.

Все промпты задействуют механизмы долговременной памяти, скиллы, контекст сессии и доступ к терминалу. По умолчанию каждый из них спроектирован с упором на безопасность: агент сначала демонстрирует предлагаемый результат и не вносит изменений в файлы без подтверждения пользователя. Все сценарии предварительно протестированы на боевых инстансах Hermes Agent.

## Платформа для прогнозирования скачек на базе Hermes и Opus 5.5

Инженер @iamlukethedev поделился кейсом создания коммерческого решения под ключ: клиент заказал платформу для аналитики скачек с применением ИИ, помогающую принимать решения при размещении ставок.

Связка Hermes и Claude Opus 5.5 полностью спроектировала архитектуру сервиса и интегрировала API платформы FormFav (поставщик данных о форме участников, статистике и параметрах заездов). В дополнение к аналитическому дашборду система получила модуль 3D-симуляции скачек в реальном времени. Автор с иронией подчеркнул, что гарантирует качество написанного софта, но не стопроцентный выигрыш на ставках.
