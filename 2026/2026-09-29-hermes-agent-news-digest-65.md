# Новости Hermes Agent #65

В этом выпуске: разбор 138 pull request'ов, смерженных 28 сентября; новая карточная раскладка во вкладке Skills в Hermes Desktop; интеграция Claude Sonnet 5.5 в Hermes Agent; десять промптов для Hermes Autopilot от witcheer; а также платформа прогнозирования скачек, созданная с помощью Hermes и Opus 5.5.

## 138 pull request'ов, смерженных 28 сентября

iamlukethedev подвёл итоги 29 сентября: 28 сентября в Hermes было смержено 138 pull request'ов. Они распределились по следующим направлениям: интерфейс (47), голос и real-time (1), инструменты и плагины для разработчиков (51), безопасность и секреты (7), интеграции и чат (8), стабильность (24). Среди наиболее заметных изменений:

- Bot Screen, `computer_use` и браузер теперь работают внутри песочницы терминального бэкенда.
- В Desktop опубликован образ песочницы `nousresearch/hermes-sandbox:desktop` со стеком дисплея для этого бэкенда.
- Полноценная поддержка интернационализации (i18n): подключаемые и накладываемые языковые пакеты для Core, TUI и Desktop с паритетом для 16 локалей.
- Desktop и TUI теперь взаимодействуют с профилем-владельцем сессии, а не с профилем запуска бэкенда.
- Настройки Desktop теперь корректно считывают и перезаписывают отображаемый профиль: подтверждения, бэкенд, хранилище секретов и токены.
- В режиме мультиплексирования cron использует профиль-владелец задачи для доставки, маршрутов и секретов.
- Claude Sonnet 5.5 добавлен в каталоги OpenRouter и Nous Portal.
- Опциональная общая телеметрия (opt-in) отображает сбои, показатели удержания и оттока, а также затраты на конфигурацию и модели — строго с согласия пользователя в Desktop.
- Сжатие контекста снова ориентируется на порог `compression.threshold` вместо захардкоженного лимита в 256 000 токенов.
- В каталог плагинов добавлены Nachos, unbrowse, antigravity OAuth, PIR8 brain graph, эмулятор Android и другие.
- Статус Qwen OAuth теперь показывает срок действия токена, его превью и путь к файлу учетных данных.
- Cron-задачи с безопасным перезапуском больше не падают из-за отсутствия `ruamel` в режиме мультиплексирования.

> Источник: [@iamlukethedev, Hermes merged 138 PRs on September 28, 29 сентября 2026](https://x.com/iamlukethedev/status/2104754369455616484)

## Десять промптов для Hermes Autopilot от witcheer

29 сентября witcheer собрал свои первые десять промптов для Hermes Autopilot на одной странице — каждый из них можно просто вставить в новый диалог с Hermes Agent. Серия охватывает самые разные задачи: обучение агента вашему стилю работы, превращение недавних действий в готовый навык, аудит текущей конфигурации, автоматическое составление отчета по понедельникам и генерацию `AGENTS.md` для репозитория.

В описании отмечается, что каждый промпт задействует память, навыки, историю сессий и терминал. Все они безопасны по умолчанию: агент сначала показывает результат и ничего не меняет без явного подтверждения. Кроме того, все сценарии были протестированы на реальной рабочей установке Hermes Agent перед публикацией. Промпты пронумерованы в хронологическом порядке — от первого интервью по настройке памяти до десятого, формирующего список задач по документации на основе открытых pull request'ов.

> Источники: [@witcheer, 10 Hermes Agent prompts so far, all on one page, 29 сентября 2026](https://x.com/witcheer/status/2104849784456565146) и [Hermes Autopilot prompts, notwitcheer, hermes-recipes](https://notwitcheer.github.io/hermes-recipes/prompts/)

## Платформа для прогнозирования скачек на базе Hermes и Opus 5.5

iamlukethedev рассказал 29 сентября, что клиент заказал платформу для прогнозирования скачек с ИИ-аналитикой, помогающей принимать решения по ставкам. Hermes в связке с Opus 5.5 с нуля создал платформу и интегрировал сервис FormFav, предоставляющий данные о форме участников, статистику и информацию о заездах через API. В проект также вошла 3D-симуляция скачек. Автор отдельно подчеркивает: он поставляет качественный софт, а не гарантированную прибыль.

> Источник: [@iamlukethedev, Hermes + Opus 5.5 did it again, 29 сентября 2026](https://x.com/iamlukethedev/status/2104885630392234474)
