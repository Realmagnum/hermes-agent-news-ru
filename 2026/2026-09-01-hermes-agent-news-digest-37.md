# Новости Hermes Agent #37

В этом выпуске рассматривается крупный релиз Hermes Agent v0.21.0 «The Pantheon Release», преодоление порога в 100 000 pull requests и поток вклада, сопровождающий его, а также использование, которое превращает несколько Hermes Agent в маленькую команду, которая общается между собой.

## Hermes Agent v0.21.0, «The Pantheon Release»

Nous Research опубликовала 31 августа Hermes Agent v0.21.0 — крупный релиз, объединяющий всё с v0.20.0. С тех пор примерно 5 800 коммитов и 2 475 слитых pull requests, около 2 100 закрытых issue и более 760 contributeurs. Версия также включает окна исправлений v0.20.1–v0.20.6, заметки к которым были опубликованы здесь.

Bot Mode становится интегрированным компонентом десктопного приложения, включённым по умолчанию: каждый профиль агента получает имя, детерминированное лицо аватара (со случайной настройкой и блокировкой) и место в общем реестре, с групповыми чатами в стиле Discord, где упоминают ботов и дают имя и картинку комнатам. Команда `hermes peer` позволяет любому агенту писать другому по идентификатору, между профилями и шлюзами, из CLI или разговора, ответы приземляются в каноничный Bot Chat каждого агента. Задачи cron получают постоянную память, с опцией `continuity=true`, которая переносит вывод одного выполнения в следующее, долговременный блокнот на задачу, режим наблюдателя, который обходит модель, когда ничего не изменилось, и вывод, который может попасть в Bot Chat бота. `delegate_task` теперь управляется в реальном времени: список текущих субагентов, корректировка их траектории, остановка раньше срока с сохранением частичного результата, валидация их выводов по JSON-схеме и показ стоимости за делегирование, с повышенными потолками по умолчанию. Центр управления MCP объединяет серверы и каталог на одной странице, с импортом перетаскиванием, фоновыми проверками здоровья, видом стоимости и использования за тридцать дней и глубокими ссылками `hermes://` под подтверждением. CLI получает палитру команд с нечётким поиском через Ctrl+P, селектор `/model`, фильтрующий во время набора, расширенный `/status`, метрики в реальном времени в строке состояния (коэффициент кэша, задержка, токены в секунду), глобальный аварийный останов и закрепление сессии. Агент наконец управляет встроенным браузером десктопа: он перемещается, кликает и читает, и может переносить страницы в системный браузер. Приходят шесть поставщиков (Meta Model API Muse Spark встроенный, CommandCode, Tencent TokenPlan, Nebius Token Factory, Ramp Router, Actual Computer), каталог принимает GLM-5.3-Flash, qwen3.8-max/family, hermes-4-405b-tool-use, llama-4-maverick-instruct и claude-opus-4.5-multi-tool, голосовые профили привязываются к поставщику, чат-сессии помечаются меткой модели, закреплённой за ними, а имена профилей и каталог моделей становятся редактируемыми.

Две новинки были отменены до поставки: режим Model Council (`/council`) и движок контекста DCP, слитые затем удалённые, не входят в этот релиз.

## 100 000 pull requests и интеграция через извлечение

Teknium объявил, что Hermes Agent преодолел планку в 100 000 pull requests от contributeurs и команды. Параллельно он уточнил поток вклада, который делает этот темп устойчивым: contributeurs не должны перестраивать и держать свои pull requests без конфликтов, команда извлекает работу в main, когда готова, так как обновление pull request — это усилие, невозможное, пока main быстро эволюционирует. Это отражено в заметках к релизу, где часть изменений помечена как извлеченные из issue или pull requests сообщества.

> Источники: [@Teknium, We just crossed our 100,000th PR, 1 сентября 2026](https://x.com/Teknium/status/2094701489059197383) и [@Teknium, nous récupérerons votre PR vers main, 1 сентября 2026](https://x.com/Teknium/status/2094785645399171385)

## Несколько Hermes Agent в маленькой команде

witcheer описывает свою установку как маленькую команду: один агент размышляет и пишет с ним в Discord, второй выполняет запланированные задачи на Mac Mini, третий тестирует модели на GPU-машине, и они пишут друг другу, когда нужно. Он подчёркивает, что с v0.21.0 эта схема — прямой обмен между агентами и Bot Mode — встроена нативно в десктопное приложение.

> Источник: [@witcheer, my Hermes Agent setup is a small team, 1 сентября 2026](https://x.com/witcheer/status/2094733012751524191)
