## Hermes Agent — самый экономичный агент по бенчмарку Composio

31 июля Composio опубликовала результаты сравнительного тестирования агентских harness по метрике стоимости выполнения задачи (cost per task). **Hermes Agent** и **Pi Agent** возглавили рейтинг, показав минимальные расходы, тогда как выполнение задач через Claude Code обходится в 3,7 раза дороже:

- **$0,39** — Hermes Agent
- **$0,40** — Pi Agent
- **$0,47** — Codex
- **$0,51** — OpenCode
- **$0,54** — Kimi Code
- **$1,47** — Claude Code

Медианная стоимость демонстрирует ту же картину: **$0,29** для Pi Agent и Hermes Agent, **$0,35** для OpenCode, **$0,38** для Kimi Code, **$0,39** для Codex и **$0,72** для Claude Code. Такой отрыв обусловлен не разовыми выбросами на сложных задачах, а стабильной эффективностью на типовых сценариях.

Расчет проводился на базе официальных тарифов Kimi K3:
- $3 за 1 млн входных токенов;
- $0,30 за 1 млн кэшированных входных токенов;
- $15 за 1 млн выходных токенов.

## tinyMMLU: Hermes Agent быстрее и экономичнее OpenCode на Kimi K3 и GLM 5.2

Облачный провайдер GMI Cloud протестировал три модели — GLM 5.2, Kimi K3 и DeepSeek V4 Pro — на датасете **tinyMMLU** (Hugging Face), сравнив работу двух harness: Hermes Agent и OpenCode. Результаты бенчмарка заметно различаются в зависимости от выбранной связки модели и агента:

- **Kimi K3:** Hermes Agent справился за **40 секунд**, израсходовав 110K токенов (скор **96/100**). OpenCode завершил тест за **8 минут 13 секунд** с расходом 149K токенов (скор **93/100**). Hermes оказался в 12 раз быстрее при ощутимой экономии контекста.
- **GLM 5.2:** Hermes Agent уложился в **2 минуты 30 секунд** и 195K токенов (скор **94/100**), тогда как OpenCode потребовалось **6 минут 20 секунд** и 432K токенов (скор **94/100**). При одинаковой точности Hermes сжёг более чем в два раза меньше токенов.
- **DeepSeek V4 Pro:** На этой модели OpenCode показал себя эффективнее по ресурсам — **3 минуты 25 секунд** и 795K токенов (скор **95/100**, стоимость $0,06) против **3 минут 44 секунд** и 1,23M токенов у Hermes Agent (скор **97/100**, стоимость $0,15). Hermes обеспечил более высокий итоговый балл, но с большей стоимостью прогона.

Для тестирования всех моделей под управлением Hermes Agent, а также для связок GLM 5.2 и DeepSeek V4 Pro с OpenCode компания GMI Cloud задействовала собственный API. Работа Kimi K3 с OpenCode проверялась через стороннего провайдера.
