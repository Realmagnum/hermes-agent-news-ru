## Hermes v0.22.7 перешёл в статус stable

3 ноября разработчик `teknium1` опубликовал релизные заметки к **Hermes v0.22.7**, ознаменовав переход версии в стабильный статус. Это накопительный багфикс-релиз, который переносит в ветку stable около **174 пулл-реквестов**, влитых с момента выхода v0.22.6. Обновление охватывает CLI, инсталляторы, приложение для Microsoft Store, Docker-образы и облачный сервис Hermes Cloud.

На момент коммита `b200f5bc60e` окно разработки насчитывает **581 non-merge коммит**, затронувший **554 изменённых файла** (+24 012 / -3 144 строк), а также **29 закрытых issues**. Полные курированные release notes за весь цикл разработки войдут в состав грядущего мажорного релиза v0.23.0.

В релизных заметках кратко перечислены ключевые изменения окна разработки:
- **Маршрутизация лидером в Desktop (Lead routing):** опциональный выбор ведущего агента для групповых комнат с бейджем `Lead` в заголовке комнаты; лидер определяет адресата входящих сообщений без явного упоминания.
- **Интеграция cron и групповых комнат:** задачи cron теперь умеют отправлять сообщения в группы; для комнат появились общее описание цели (purpose) и заметки; обсуждение в группе отображается в единой колонке чата с живым статусом активности каждого бота.
- **Канбан-доски:** возможность закрепления Kanban-досок в качестве вкладок быстрого переключения.
- **Отображение формул и диаграмм:** поддержка математических формул `$$TeX$$` и рендеринг Mermaid-диаграмм через библиотеку Pele.
- **Диагностика ошибок обновления Desktop:** диалоговое окно сбоя обновления Desktop теперь выводит лог ошибки и прямую ссылку для отправки баг-репорта.
- **Индикация запуска Web Access:** веб-доступ теперь информирует о текущем этапе запуска с активным таймером выполнения.
- **Telegram через Team Gateway:** поддержка интеграции Telegram путём связывания аккаунта с общим ботом команды.
- **Режим молчания в Slack (`thread_followup_silence`):** опциональное отключение ответов в тредах без последующих реплик.
- **Переключатель Daybreak:** быстрый выбор моделей по подписке ChatGPT, доступных в каталоге.
- **Пополнение каталога:** очередная серия новых расширений в каталоге плагинов.

## 54 пулл-реквеста, влитых 3 ноября

4 ноября @iamlukethedev подвёл итоги продуктивности разработки: только за 3 ноября в репозиторий Hermes было влито **54 пулл-реквеста**. Среди ключевых системных улучшений автор выделил три направления:
- **Фокусные cron-задачи в группах:** задания cron могут отправлять уведомления в групповые комнаты, пробуждая исключительно тех ботов, которые в них упомянуты.
- **Нативный интерфейс групп:** групповые комнаты получили общие описания целей и заметки, а интерфейс приведён к единому чату с живым отображением статуса каждого участника в реальном времени.
- **Выбор лидера группы:** введение опциональной маршрутизации через назначенного ведущего агента.

Официальный чейнджлог за 3 ноября конкретизирует и расширяет список изменений:
- **Управление нецелевыми репликами (#148417):** назначенный лидер группы решает, какой именно агент обрабатывает сообщения, где не указано имя конкретного адресата.
- **Мультихостовые группы (#148418):** групповые комнаты вновь поддерживают добавление ботов, запущенных на разных физических хостах или удалённых машинах.
- **Чистка избыточных скиллов (#148639):** удалены опциональные скиллы, дублирующие возможности каталога MCP, встроенных плагинов, нативного веб-поиска или официальных репозиториев вендоров.
- **Фокус на архитектуре Apple Silicon (#148622):** из сборочных пайплайнов CI исключены установка и релизные сборки для macOS на базе Intel; фокус разработки полностью сосредоточен на Apple Silicon.
- **Прозрачность сбоев в Desktop (#148355):** окно ошибки обновления Desktop показывает детальный вывод терминала при падении и кнопку перехода к созданию issue.
- **Тайминг Web Access (#148408):** при инициализации Web Access в реальном времени отображается текущая стадия и затраченное время.
- **Патчи безопасности зависимостей (#148630):** устранены уязвимости и закрыты секьюрити-алерты в пакетах `undici`, `zod`, `fast-uri`, `qs`, `pypdf`, `pyasn1`, `tornado`, `filelock` и `setuptools`.

## Hermes Agent возглавил рейтинг GitHub Octoverse 2026

4 ноября разработчик BkashJosi обратил внимание на результаты ежегодного отчёта **GitHub Octoverse 2026**: репозиторий Hermes Agent занял **первое место** в рейтинге самых вовлекающих open source проектов («most-engaged») в категории репозиториев под управлением единого вендора (single vendor / product-led). При этом отмечается, что звёзды составляют лишь треть итоговой оценки.

Ежегодный отчёт GitHub подтверждает лидерство Nous Research. В исследовании этого года независимые комьюнити-проекты разделены с проектами, курируемыми компаниями-разработчиками:
- **Победа Nous Research:** в номинации *single vendor / product-led* проект `NousResearch/hermes-agent` опередил таких конкурентов, как `anomalyco/opencode` и `earendil-works/pi`.
- **Комплексная метрика вовлечённости:** итоговый показатель активности («most-engaged») формируется не только на основе количества звёзд на GitHub, но и учитывает число форков, а также количество уникальных авторов пулл-реквестов и открытых обсуждений (issues).

## Crouton Alpha — бесплатная stealth-модель в Nous Portal

3 ноября платформа OpenRouter анонсировала **Crouton Alpha** — новую скрытую (stealth) модель рассуждения, спроектированную для масштабирования рутинных агентных задач: **бесплатный доступ**, контекстное окно в **1 миллион токенов**, мультимодальный ввод (текст, изображения, аудио и видео) и строгий отказ от использования входящих данных для обучения сетей (zero data retention for training). @witcheer сообщил о появлении новой скрытой модели в каталоге, а @yeahfortommy подтвердил, что Crouton Alpha уже доступна абсолютно бесплатно в **Nous Portal** для работы в связке с Hermes Agent.

Карточка модели на платформе OpenRouter раскрывает подробности:
- **Назначение:** легковесная модель для кодинга, агентных сценариев и мультимодальной обработки, оптимизированная под рутинные подзадачи, вызов внешних инструментов и анализ объёмных документов.
- **Тандем с флагманскими моделями:** модель ориентирована на работу в паре с топовыми моделями глубокого рассуждения (frontier reasoning models) — пока ведущая модель формирует архитектурный план, Crouton Alpha оперативно исполняет конкретные шаги, переводя план в действия.
- **Поддержка инструментов:** полная совместимость с function calling, вызовами инструментов и структурированным выводом по схемам JSON Schema.
- **Приватность и география:** сторонний провайдер модели остаётся анонимным на этапе preview; данные пользователей могут временно кэшироваться для обработки запроса, но не сохраняются для дообучения. Модель генерирует только текстовый вывод и на текущий момент недоступна через европейский дата-роутинг OpenRouter.

## Список ожидания для мобильного приложения

3 ноября команда Nous Research подвела итоги конференции **NousCon 2026**, поблагодарив гостей со всего мира, и отметила, что места в закрытом бета-тестировании официального мобильного приложения, запущенного прямо на мероприятии, закончились намного быстрее прогнозов. @Teknium и @witcheer объявили об открытии **официального списка ожидания (waitlist)** для подключения новых пользователей по мере расширения серверных мощностей.

- **Подключение к персональному шлюзу:** мобильное приложение Hermes Agent подключается напрямую к шлюзу (gateway), запущенному на собственном оборудовании или сервере пользователя.
- **Поэтапное приглашение:** лист ожидания позволит присоединиться к экосистеме мобильного клиента тем, кто не успел получить прямой инвайт в дни проведения конференции.
