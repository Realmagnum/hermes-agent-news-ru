## Режим HUD: Hermes превращается в активный оверлей рабочего стола

8 августа разработчик Brooklyn! (@imbabybrooklyn) продемонстрировал **режим HUD** в Hermes Desktop. Вместо привычного отдельного окна, к которому нужно добираться через `Alt+Tab`, Hermes теперь работает как полупрозрачный слой, парящий поверх запущенных программ:

- Окно можно переместить в любую область экрана;
- Интерфейс автоматически уходит в прозрачность и сливается с фоном, когда пользователь отвлекается на другие задачи (по словам @witcheer, HUD сворачивается сам, стоит только перестать его читать);
- Хоткей `Cmd+Shift+H` моментально схлопывает интерфейс до компактной строки композера с выводом последнего ответа над ней.

9 августа @Teknium также сообщил о доработке CLI: имя текущей сессии теперь выводится прямо в правой части строки контекста.

## Жест «this»: наведите панель и укажите на приложение

9 августа Brooklyn! показал следующий шаг в эволюции HUD. Пользователю больше не нужно вручную описывать окружение или объяснять агенту, с каким приложением ведется работа: достаточно перетащить панель HUD поверх целевого окна и написать `this`. 

Hermes мгновенно считывает контекст приложения прямо под собой, анализирует интерфейс и разбирает экранные данные.

> "You don't tell Hermes which app you mean anymore. Put the bar over it and say 'this'."

Функция уже доступна в свежем апдейте десктопного клиента на macOS и Windows. При этом через удаленный шлюз (remote gateway) такой жест передать нельзя: как пошутил Brooklyn!, *«it would require a wormhole»*. Команда Nous Research встретила демонстрацию лаконичным удивленным эмодзи.

> **Источники:**
> - [@imbabybrooklyn — Контекстный жест "this" в HUD (9 августа 2026)](https://x.com/imbabybrooklyn/status/2086270328926240782)
> - [@NousResearch — Реакция команды на демонстрацию (9 августа 2026)](https://x.com/NousResearch/status/2086270481305424201)

## Hermes Wingtips #41: команда `hermes approvals suggest`

9 августа Witcheer представил полезную утилиту для интерфейса командной строки:

```bash
hermes approvals suggest
```

Команда сканирует историю выданных разрешений (approvals) и формирует рекомендованный белый список для типовых повторяющихся действий. Если агент запрашивает одно и то же разрешение уже третий раз за неделю, утилита предложит автоматизировать этот шаг.

Инструмент носит исключительно рекомендательный характер: изменения не вносятся в конфигурационные файлы без явного подтверждения пользователем.

> **Источники:**
> - [@witcheer — Hermes Wingtips #41: автогенерация белого списка подтверждений (9 августа 2026)](https://x.com/witcheer/status/2086460177046286778)

## Единая подписка: один логин для всех инструментов

9 августа Witcheer напомнил, что подписка Nous охватывает не только доступ к базовым моделям. Единая учетная запись предоставляет централизованный доступ к:

- Поиску в вебе;
- Генерации изображений;
- Синтезу речи (TTS);
- Браузерной автоматизации.

Маршрутизацией запросов занимается шлюз **Nous Tool Gateway**, благодаря чему отпадает необходимость генерировать и прописывать отдельные API-ключи под каждый сервис.

> "Your agent stops needing a separate account and key for every tool."

> **Источники:**
> - [@witcheer — Единая аутентификация для тулинга через Nous Tool Gateway (9 августа 2026)](https://x.com/witcheer/status/2086473034148266167)

## Плагин Shodan для Hermes Agent

Разработчик @adolandev выпустил плагин интеграции с сервисом Shodan. Расширение позволяет агенту проводить разведку сетевой инфраструктуры (сбор данных по IP-адресам, статистика в масштабах глобальной сети) без платного API-ключа, опираясь на базу InternetDB.

Благодаря архитектуре Plugin API установка выполняется одной командой и не затрагивает ядро системы. Исходный код доступен в репозитории `github.com/Adolanium/hermes-plugin-shodan`, релиз также отметил @Teknium.

> **Источники:**
> - [@adolandev — Анонс Shodan-плагина на базе InternetDB (7 августа 2026)](https://x.com/adolandev/status/2085655993371767172)

## Hermes Browser Extension: студия тем оформления

8 августа @jonkomet представил студию тем для браузерного расширения Hermes Browser Extension. Пользователи могут:
- Напрямую импортировать готовые темы оформления из VS Code;
- Генерировать индивидуальные цветовые палитры через промпт агенту.

Сообщество встретило решение позитивно, назвав прямой импорт существующих тем из экосистемы VS Code куда более логичным подходом, чем создание очередного громоздкого конструктора стилей.

> **Источники:**
> - [@jonkomet — Студия тем для Hermes Browser Extension (8 августа 2026)](https://x.com/jonkomet/status/2086165169605165488)

## В разработке: официальное мобильное приложение

8 августа Teknium подтвердил разработку нативного мобильного клиента для Hermes Agent. Быстрого релиза ждать не стоит: команда планирует довести продукт до максимальной стабильности перед выходом в публичный бета-тест.

> "I promise an official mobile app for Hermes Agent will come. Not too soon though, we want it to be truly as perfect as we can make it without public feedback."

На скептический вопрос о том, зачем агенту отдельное приложение, если с ним уже можно взаимодействовать через привычные мессенджеры, Teknium ответил прямо: *«Because 50,000 people asked for it»*.
