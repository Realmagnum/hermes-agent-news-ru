## Hermes Agent v0.22.3: стабильный релиз с 620 пулл-реквестами

21 октября Teknium опубликовал стабильный релиз **v0.22.3**. Это корректирующий выпуск, объединивший около 620 пулл-реквестов, вошедших после v0.22.2. Стабильное обновление доступно для CLI, установщика, приложения в Microsoft Store, Docker и платформы Hermes Cloud.

С момента выхода v0.22.2 (вплоть до коммита `5b147ab036d`) кодовая база пополнилась 2 911 коммитами без учета мержа: затронуто 4 206 файлов (+360 278 / −64 308 строк), смержено около 620 пулл-реквестов и закрыто 326 issue. Среди ключевых новшеств:

- Классический CLI получил обновлённый интерфейс: транскрипция с глифами, строка состояния под композером и двухстрочный заголовок.
- Плагины теперь могут объявлять OAuth-клиентов: Hermes берёт на себя авторизацию и регулярное обновление токенов.
- Команда `hermes plugins update` предлагает все доступные обновления; в Desktop появилась кнопка обновления для плагинов, установленных через git.
- В Desktop теперь можно управлять запросом в очереди и редактировать его, а субагенту доступен пошаговый выбор модели и провайдера.
- В CLI и TUI отображается живой таймер обратного отсчёта `/loop`.
- Автоматический перенос личных тем Telegram стал опциональным (opt-in), а для плагинов добавлен хук `post_compaction`.
- Добавлен каталог возможностей (Capabilities), а сборка для Microsoft Store теперь публикуется автоматически с каждым релизом.
- Автоочистка сессий снова стала опциональной (opt-in) — при нехватке места на диске выводится однократный запрос.
- В локальный runtime добавлены поддержка Nemotron 3.5 Bolt и спекулятивное декодирование DFlash с одним слотом черновика.

Полный структурированный ченджлог за этот период выйдет с релизом v0.23.0, где будут подробно описаны все изменения начиная с v0.22.0.

## 160 пулл-реквестов в мерже за 20 октября

21 октября iamlukethedev подвёл итоги: 20 октября в Hermes было смержено 160 пулл-реквестов. Среди заметных изменений:

- Krea 3 теперь работает через управляемый шлюз и стал моделью генерации изображений по умолчанию для подписчиков платных тарифов — поддерживаются редактирование по текстовой инструкции и несколько референсных изображений.
- Инструменты MCP транслируют прогресс в реальном времени: отдельной строкой в Desktop, спиннером в CLI и событиями плагинов во время работы.
- Каталог возможностей Desktop, объединяющий скиллы, плагины, коннекторы и инструменты, получил переработанный интерфейс.
- Инструмент Git Review в Desktop показывает изменения в коде и позволяет цитировать конкретные строки в черновике.
- Плагин hermes-board добавляет интерактивную доску (whiteboard): агент заполняет её данными, а пользователь может редактировать содержимое в боковой панели Desktop.
- Виджет строки состояния burnclock показывает баланс у провайдера и прогнозируемое время работы до исчерпания средств.

## Herald: приложение Hermes Bots отправлено на ревью в Apple

21 октября iamlukethedev объявил, что Herald — приложение Hermes Bots — наконец отправлено на ревью в Apple. Разработчик извинился за задержку и пояснил, что мог выпустить его раньше, но хотел довести продукт до уровня, за который не стыдно просить оплату. Он изучил более 200 отзывов бета-тестировщиков Herald и внедрил ключевые предложения перед отправкой сборки на проверку.

## Memory Pane: что агент запоминает

21 октября Adolan представил Memory Pane — плагин для Hermes Desktop, снимающий частую претензию пользователей к памяти агента: теперь точно видно, что именно он сохраняет, запоминает или отбрасывает.

Все операции Hermes с памятью (сохранение, обновление, удаление) отображаются в реальном времени рядом с перепиской. Любую запись можно отредактировать, удалить или отменить — всё работает локально, без сетевых запросов и телеметрии.

В журнале изменений за 20 октября также отмечено появление панели памяти в интерфейсе чата для отслеживания запоминаемой агентом информации и оперативного исправления неточностей.

## Draft Cards: проверка черновиков перед отправкой

21 октября witcheer обратил внимание на плагин Draft Cards, созданный для тех, кто поручает агенту составлять письма, но хочет лично контролировать каждое сообщение перед отправкой.

Плагин выводит каждый черновик в виде интерактивной карточки в интерфейсе Hermes Desktop: пользователь может попросить агента внести правки либо отредактировать текст вручную.

Журнал изменений за 20 октября подтверждает нововведение: вместо обычного неформатированного текста черновики представлены интерактивными карточками с поддержкой редактирования по месту (in-place) и отслеживания версий.
