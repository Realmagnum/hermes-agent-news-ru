## Релиз Hermes Agent v0.20.0: Herald Release

Состоялся масштабный релиз **Hermes Agent v0.20.0** с кодовым именем **Herald Release** (тег `v2026.8.3` на GitHub от 3 августа). С момента выхода v0.19.0 репозиторий претерпел колоссальные изменения: около 3 650 коммитов, 1 400 смердженных пулл-реквестов, 5 200 измененных файлов, 1 200 закрытых issues и свыше 650 контрибьюторов.

### Ключевые изменения:

- **Голосовой диалоговый режим:** потоковый TTS по предложениям, поддержка **barge-in** (агент немедленно прерывает свою речь, если пользователь начинает говорить), детекция пауз, локальные wake-words («hey Hermes» или настраиваемая фраза), роутинг по профилям и глобальная голосовая команда «stop».
- **Голос на всех поддерживаемых платформах:** автоматическая транскрипция голосовых заметок в WhatsApp, Feishu, DingTalk, LINE, QQ, Photon и Weixin. Адаптивные голосовые ответы (TTS) под каждую платформу и полностью конфигурируемый STT (категория инструментов `hermes tools`, тумблеры в GUI и интеграция с `gpt-transcribe` от OpenAI).
- **Протокол Agent-to-Agent (A2A v1.0):** встроенный плагин реализует протокол A2A. Теперь Hermes может самостоятельно обнаруживать сторонних A2A-совместимых агентов, общаться с ними и работать под их управлением. Это закрывает issue #514 — один из старейших запросов сообщества.
- **Исходящие вебхуки:** агент научился отправлять подписанные через HMAC события на внешние HTTP-эндпоинты, упрощая интеграцию с CI/CD, системами умного дома и дашбордами без необходимости постоянного поллинга.
- **Поиск с верификацией источников:** скилл `grounded-citations` связывает каждую цитату с исходным содержимым веб-страниц, генерируя прямые ссылки на подтверждающие фрагменты и поддерживая режим фактчекинга.
- **Десктоп как платформа расширений:** версионируемые артефакты с живым предпросмотром в песочнице, открытый SDK плагинов (первым официальным плагином стал Kanban), всплывающее окно быстрого ввода по глобальному хоткею и поддержка многооконного интерфейса.
- **Улучшения CLI:** быстрый режим шелла через префикс `!`, команды `/init` (генерирует файл `AGENTS.md`), `/diff`, `/context`, `/focus`, а также утилита `hermes import-agent` для плавной миграции конфигураций с Claude Code и Codex CLI.
- **Корректировка на лету (Mid-turn steering):** ввод уточнений во время генерации сразу же корректирует активный шаг агента без сброса контекста и перезапуска всей цепочки.
- **Самовосстанавливающиеся инструменты:** усеченный вывод терминала теперь автоматически выгружается в отдельный файл, инструмент `patch` определяет уже примененные диффы, `write_file` валидирует запись на диск, а алгоритмы поиска перешли на нечеткое сопоставление (fuzzy matching). Лимит итераций по умолчанию поднят с 90 до 500.
- **Оптимизация контекста:** пошаговая микрокомпактизация контекста (micro-compaction), гарантия сохранения последних *N* пользовательских сообщений и индивидуальные пороги отсечения в абсолютных токенах для разных моделей.
- **Производительность:** холодный запуск команды `hermes -w` ускорился с ~14 с до 1,8 с, prompt caching теперь покрывает схемы вызова инструментов на нативном провайдере Anthropic, а интерфейс десктопного приложения получил очередную волну оптимизаций до стабильных 60 fps.
- **Интеграция Buzz и облачные шлюзы:** клиент Buzz (Nostr-мессенджер от Block) подключен в качестве платформенного шлюза (нативный WebSocket-транспорт, авторизация по стандарту NIP-42). Также обновлены коннекторы к Vercel AI Gateway и Vercel Sandbox.
- **Безопасность секретов:** строгая изоляция секретов через Ironproxy, ротация токенов одной командой и опциональный зашифрованный break-glass кэш для интеграций с Bitwarden.

Основатель Nous Research @Teknium прокомментировал запуск кратко: *«so much in the Herald Release»*, отдельно отметив появление шлюза Buzz, новый пакет скиллов для офисной работы и скидку 20% на инференс всех моделей в Nous Portal.

## Liquid AI обучает новую модель внутри Hermes Agent

Компания Liquid AI сообщила, что финальный этап пост-тренировки (post-training) их новой архитектуры опирается на многошаговый агентный RL (multi-turn agentic RL), который запускается одновременно в трех тестовых обвязках: Pi, Hermes Agent и OpenClaw.

Каждая итерация (rollout) выполняется в изолированной песочнице и оптимизируется методом GRPO (Group Relative Policy Optimization) на основе функции вознаграждения за результат. Оценка складывается из LLM-судейства, программных тестов и проверок защитных барьеров (guardrails).

> «Модель приходит на прод, уже будучи знакомой с инструментами, системными промптами и реальными паттернами взаимодействия этих сред», — подчеркивают в Liquid AI.

@Teknium поделился этим анонсом, в очередной раз подтвердив статус Hermes Agent не просто как удобного рантайма для конечных пользователей, но и как индустриального стандарта тестовой среды для обучения агентных моделей.

> **Источники:**
> - [@liquidai via @Teknium — Агентный RL в среде Hermes Agent (4 августа 2026)](https://x.com/liquidai/status/2084640749862236227)

## Интеграция Hermes Agent с iMessage через Photon

Разработчица Джули Чен (@0xJuliechen) опубликовала минутный гайд по связке Hermes Agent с iMessage через сервис Photon.

По ее словам, официальной интеграцией с Nous Research уже пользуются свыше 12 000 человек, а вся настройка шлюза занимает не более 60 секунд. Туториал получил репост от @Teknium.

## Плагин достижений для Hermes Desktop

Тони Саймонс (@tonysimons_) представил плагин `hermes-desktop-achievements`, который добавляет систему геймификации в приложение Hermes Desktop.

Плагин выводит текущий счет очков в шапке окна, панель фильтрации ачивок по уровням сложности, прогресс-бары выполнения, бейдж в статус-баре и меню быстрого вызова через палитру команд `⌘K`. 

> «Никакого стороннего бэкенда: проект полностью опирается на штатный Plugin API, который уже поставляется в Hermes», — отметил Тони. Сам разработчик успел открыть 36 из 60 предусмотренных ачивок.

> **Источники:**
> - [@tonysimons_ via @Teknium — Плагин achievements для десктопа (3 августа 2026)](https://x.com/tonysimons_/status/2084124783893967221)
