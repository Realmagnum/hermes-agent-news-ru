# Новости Hermes Agent #9

Вышел Herald Release v0.20.0, Liquid AI обучает свою модель в Hermes Agent, уточняется интеграция iMessage через Photon, и на desktop приходит плагин достижений.

## Hermes Agent v0.20.0, Herald Release, опубликован

Версия v0.20.0 Hermes Agent, анонсированная вчера, вышла на GitHub (тег v2026.8.3, 3 августа). Кодовое имя — Herald Release. С момента v0.19.0 в репозитории примерно 3650 коммитов, 1400 смерженных PR, 5200 изменённых файлов и 1200 закрытых issues, при более чем 650 контрибьюторах.

Основные изменения вкратце:

- Разговорный голос: TTS-стриминг фраза за фразой, barge-in (агент останавливается, если вы говорите), детекция тишины и локальные wake-слова («hey Hermes» или выбранное слово), с маршрутизацией по профилям и голосовой командой «stop» на всех поверхностях.
- Голос на всех платформах: голосовые заметки транскрибируются на WhatsApp, Feishu, DingTalk, LINE, QQ, Photon и Weixin, автоматические TTS-ответы, адаптированные под каждую платформу, полностью настраиваемый STT (категория hermes tools, тумблеры в GUI, поддержка gpt-transcribe от OpenAI).
- Протокол A2A v1.0: встроенный плагин реализует протокол Agent-to-Agent, Hermes может обнаруживать другие совместимые с A2A агенты, вести с ними диалог и быть ими управляемым. Это закрывает issue #514 — один из самых старых запросов репозитория.
- Исходящие вебхуки: Hermes отправляет подписанные (HMAC) события на HTTP-эндпоинты — для подключения CI, умного дома или дашбордов без циклов поллинга.
- Поиск с источниками: скилл grounded-citations сопоставляет каждую цитату с реальным текстом страниц, со ссылками на точное доказательство и режимом fact-checking.
- Desktop становится платформой: версионируемые артефакты с live-превью в песочнице, SDK плагинов (Kanban — первый официальный плагин), окно быстрого ввода по глобальному хоткею, несколько GUI-окон.
- CLI: shell-режим с !, команды /init (генерирует AGENTS.md), /diff, /context, /focus и hermes import-agent для миграции конфига Claude Code или Codex CLI.
- Перенаправление посреди раунда: ввод исправления, пока агент работает, перенаправляет активный раунд без полного перезапуска.
- Самовосстанавливающиеся инструменты: усечённый вывод терминала сохраняется в файл, patch обнаруживает уже применённые правки, write_file проверяет содержимое на диске, поиск с нечётким совпадением; лимит итераций по умолчанию вырос с 90 до 500.
- Сжатие: микро-компакция за раунд, гарантия сохранения последних N сообщений пользователя, настраиваемые пороги по абсолютным токенам на модель.
- Производительность: холодный старт hermes -w ускорился примерно с 14 с до 1,8 с, кэш промптов покрывает схемы инструментов на нативном Anthropic, вторая волна 60 fps на desktop.
- Buzz интегрирован как gateway-платформа (Nostr-мессенджер Block, нативный WebSocket-транспорт, auth NIP-42), обновлённый возврат провайдеров Vercel AI Gateway и Vercel Sandbox.
- Секреты: блокировка секретов с Ironproxy, ротация токена одной командой, опциональный шифрованный break-glass кэш для Bitwarden.

Teknium резюмирует: «so much in the Herald Release», перечисляя также интеграцию Buzz, новые офисные/productivity скиллы и скидку 20 % на все модели Nous Portal.

## Liquid AI обучает свою модель в Hermes Agent

Liquid AI анонсировал 4 августа, что финальный этап пост-обучения его новой модели проходит через мультираундовый агентный RL в трёх реальных harness'ах: Pi, Hermes Agent и OpenClaw. Каждый rollout крутится в собственном песочнице, оптимизированный по GRPO с наградой за результат (рубрика судьи-LLM, программные проверки, защитные ограничения безопасности).

«Модель приходит, уже увидев их инструменты, system prompts и схемы взаимодействия», — объясняет Liquid AI. Teknium перепостил анонс без комментариев. Это очередное подтверждение Hermes Agent как среды обучения, а не только исполнения.

> Источник: [@liquidai, перепост @Teknium, 4 августа 2026](https://x.com/liquidai/status/2084640749862236227)

## Hermes Agent подключён к iMessage через Photon

Julie Chen (@0xJuliechen) опубликовала минутный туториал по подключению Hermes Agent к iMessage через Photon. «12k+ hermes users are already on it», — пишет она, упоминая официальную интеграцию с Nous Research и настройку за 60 секунд. Teknium перепостил туториал 4 августа.

> Источник: [@0xJuliechen, перепост @Teknium, 4 августа 2026](https://x.com/0xJuliechen/status/2084416774452412635)

## Плагин достижений для Hermes Desktop

Tony Simons (@tonysimons_) опубликовал hermes-desktop-achievements — плагин, добавляющий достижения в desktop-приложение: счёт в шапке, фильтры по уровням, полосы прогресса, чип в строке состояния и команду ⌘K. «Backed by the plugin API Hermes already ships, zero new backend», — уточняет он. Он говорит, что разблокировал 36 достижений из 60 на своей машине.

> Источник: [@tonysimons_, перепост @Teknium, 3 августа 2026](https://x.com/tonysimons_/status/2084124783893967221)
