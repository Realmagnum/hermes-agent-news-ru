## 59 пулл-реквестов, влитых 26 октября

27 октября iamlukethedev подвёл итоги дня: за 26 октября в репозиторий Hermes влили 59 пулл-реквестов. Среди ключевых изменений:

- **GLM-5.3 — новый тихий дефолт:** модель GLM-5.3 назначена моделью по умолчанию для фоновой работы без вывода лишних деталей.
- **Модульность GitHub Copilot:** интеграция с GitHub Copilot вынесена из ядра в отдельный плагин `github-copilot` (Hermes Labs), который уже доступен в каталоге.
- **Ускорение запуска:** Hermes теперь стартует примерно на секунду быстрее при запуске из git-чекаута.

В changelog за 26 октября также вошли важные оптимизации и исправления:
- **Единый ConfigBackend:** все операции чтения и записи `config.yaml` теперь проходят через абстракцию `ConfigBackend`.
- **Быстрый `optimize-storage`:** команда оптимизации хранилища теперь выводит прогресс каждого этапа и завершает работу чуть более чем за минуту вместо почти 25 минут.
- **Исправление окон Desktop на Linux:** окна приложения Desktop в Linux больше не зависают в полупрозрачном состоянии.
- **Оптимизация ввода:** задержка ввода больше не растёт по мере накопления истории в контексте.
- **Фоновая очистка scratch:** запуск агента больше не блокируется ожиданием завершения очистки директории `scratch`.

## Advanced Delegation: два режима для субагентов

26 октября Nous Research представила официальный плагин **Advanced Delegation**, расширяющий стандартный инструмент делегирования `delegate_task` двумя новыми режимами работы субагентов:

1. **Маршрутизация по моделям (Model routes):** агент под каждую задачу выбирает именованный маршрут из предварительно настроенного списка (например, «быстрый», «глубокий», «локальный»).
2. **Маршрутизация по профилям (Profile routes):** субагент запускается в изолированном контексте одного из существующих профилей Hermes — со своей моделью, кредами, скиллами и файлом `SOUL.md`.

### Архитектура и безопасность
В контекст LLM передаются только заданное имя и однострочное описание маршрута: провайдер, model ID, эндпоинт и API-ключ никогда не утекают в параметры вызова инструмента.

Как отмечает iamlukethedev, теперь нет необходимости гонять тяжелую флагманскую модель на каждом подзапросе: быстрый маршрут берет на себя поиск и саммари, глубокий — сложную аналитику и код, либо управление полностью передается специализированному профилю. witcheer протестировал новинку на выходных: основной агент самостоятельно направил генерацию саммари в модель Haiku 5.5, а решение логической головоломки — в Opus 5.5.

### Установка и настройка
Плагин доступен в каталоге для Hermes Agent версии **0.22.5 и выше**:

```bash
hermes plugins install advanced-delegation
```

- **Конфигурация:** настраивается командой `hermes delegation config`.
- **Управление на лету:** слеш-команда `/delegation` позволяет переключать режимы субагентов прямо в ходе активной сессии.
- Первым практическим видеообзором возможностей плагина уже поделился tonbistudio.

## kinocut: безопасный локальный видеомонтаж

27 октября witcheer представил **kinocut** — комьюнити-плагин от Kyanite Labs для локального монтажа видео. Плагин включает собственный MCP-сервер Kinocut и два специализированных скилла: для общего редактирования видео и для автоматического создания коротких клипов (например, конвертации горизонтального видео 16:9 в вертикальный Shorts/Reels 9:16 с наложением субтитров прямо на локальной машине).

### Безопасность и окружение
Согласно каталогу и пулл-реквесту `#142459`, архитектура плагина спроектирована с упором на локальное исполнение и приватность данных:
- **Локальный рендеринг:** вся обработка медиа выполняется через `FFmpeg` и `ffprobe`. Базовый монтаж не требует аккаунтов или внешних API-ключей.
- **Приватность:** опциональные вызовы моделей компьютерного зрения (vision API) по умолчанию отключены.
- **Требования к хосту:** наличие пакетного менеджера `uv`, утилит `ffmpeg` и `ffprobe` в переменной окружения `PATH`, а также Python 3.11+.
- **Поставка:** бандл версии 1.16.7 фиксирует рантайм 1.16.4. Плагин подписан разработчиком simongonzalezdc и распространяется Kyanite Labs под лицензией Apache-2.0.

## Hermes Agent на смарт-часах с Wear OS

27 октября witcheer показал клиент Hermes Agent для умных часов на платформе Wear OS. Приложение распознает голос прямо на носимом устройстве и отправляет распознанный текст напрямую на API-сервер Hermes Agent — без использования смартфона в качестве промежуточного моста. Пользователь зажимает на экране сферу (orbe), произносит запрос, а ответ агента озвучивается вслух.

### Особенности реализации
Исходный код опубликован в репозитории `jribnik/hermes-wear`:
- **Автономность:** полностью самостоятельное приложение для Pixel Watch под управлением Wear OS 3 и новее.
- **Прямой API:** связывается по стандартному HTTP с OpenAI-совместимым API шлюза Hermes Agent.
- **Минимальные привилегии:** приложению требуется исключительно разрешение на доступ в сеть (`INTERNET`). Для распознавания речи задействован системный движок распознавания голоса, поэтому даже прямое разрешение на микрофон не запрашивается.
