## 86 пулл-реквестов, влитых 24 октября

iamlukethedev подсчитал, что 24 октября в Hermes влили 86 пулл-реквестов. Среди заметных изменений:

- Плагины Desktop теперь могут показывать в приложении медиафайлы, созданные их собственными инструментами.
- Пользователи Desktop на Windows теперь могут подключаться к удалённым машинам через Windows SSH.
- При потоковой генерации изображения в Markdown теперь отображаются как изображения, а не как текст.

В changelog за 24 октября также отмечены:

- API-ключи Context7 больше не попадают в логи: их распознают по префиксу поставщика.
- Allowlist MCP-серверов для cron-задачи больше не расширяется автоматически на все включённые серверы.
- При подтверждении недоверенной MCP-записи теперь показываются аргументы вызова, а секреты маскируются.
- Результаты и списки инструментов MCP размером более 1 MiB теперь передаются через Streamable HTTP.
- Обычное аудио отправляется как вложение, а не как голосовая заметка.
- Команды `/refine` и `/review` работают с оставленными бездействовать сессиями.
- Плагин Blender из каталога теперь устанавливается самостоятельно и обнаруживает версию из Microsoft Store.

## crontab-ref: чтение cron-выражений простыми словами

25 октября witcheer напомнил о частой ошибке: `0 9 1 * 1` означает не «в первый понедельник месяца», а «первого числа и каждый понедельник».

`crontab-ref` — community-плагин, который объясняет любое cron-выражение обычными словами. Достаточно написать в сообщении `@crontab:"..."`, и Hermes покажет:

- значение каждого поля;
- примет ли выражение команда `/cron`;
- пять следующих запусков в часовом поясе Hermes;
- пояснения о типичных ошибках.

Для разбора используется `croniter` — библиотека планировщика Hermes, поэтому дополнительные зависимости не устанавливаются. Начиная с Hermes 0.21.5, плагин можно включить одной командой; API-ключ и настройка не нужны:

```bash
hermes plugins install crontab-ref --enable
```

## viajante: поиск авиабилетов и отелей с собственного компьютера

24 октября witcheer представил `viajante` — community-плагин для поиска авиабилетов и отелей с собственного компьютера, без API-ключа и учётной записи.

Плагин получает данные из публичных страниц Google Flights и Google Hotels через локальный IP-адрес, а затем возвращает цены, расписание и ссылки. Агенту доступны 22 инструмента и скилл с пояснениями к результатам. Плагин не бронирует поездки и не хранит учётные данные.

По данным каталога, плагин распространяется felipebasurto по лицензии MIT, использует закреплённый MCP-сервер `npx -y @viajante/mcp` и требует `uv`, Python 3.10 или новее и Node.js.

> - [@witcheer — viajante is a community plugin for Hermes Agent that searches flights and hotels (24 октября 2026)](https://x.com/witcheer/status/2114046764202500179)

## hookspool: вебхуки сохраняются на диске

25 октября witcheer рассказал о `hookspool` — community-проекте с открытым исходным кодом. Он ставит локальную очередь перед webhook-маршрутами Hermes: каждое событие хранится на диске, пока агент его не обработает.

Так агент может сам начать работу, когда приходит письмо, кто-то делится файлом или завершается сборка, — не дожидаясь следующего запроса.

## За неделю в каталог добавили 144 плагина

По подсчёту witcheer, за неделю к каталогу Hermes добавили 144 community-плагина. Среди шести рекомендаций для первой установки — `llmslim`: он локально сжимает старые результаты инструментов без обращения к модели, помогая сохранить работоспособность prompt cache. Другой пример — `hermes-memory-pane`, который показывает, что агент сохранил в памяти.
