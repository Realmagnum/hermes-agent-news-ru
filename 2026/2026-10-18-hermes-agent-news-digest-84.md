## 17 октября смержили 113 пулл-реквестов

18 октября @iamlukethedev подвёл итоги: за 17 октября в репозиторий Hermes влили **113 пулл-реквестов**. Среди ключевых изменений:

- **Hermes Desktop:** при падении шлюза посреди хода приложение теперь отображает потерянный ход с кнопкой **Discard**, а промпты в очереди теперь можно редактировать или отменять напрямую из интерфейса.
- **Быстрые инструменты:** вызовы `patch` и `write_file` теперь отрабатывают за считанные миллисекунды — диагностика LSP больше не блокирует запись файлов.
- **Управление фоновыми процессами:** агенты больше не уходят в холостое ожидание немых фоновых задач — Hermes уведомляет об их завершении. Команды с одиночным амперсандом `&` на конце теперь запускаются как отслеживаемые фоновые процессы вместо отказа в выполнении.
- **Стриминг tool calls:** исправлена поломка стриминга вызовов инструментов (streaming tool calls) для LM Studio, Kimi и MiniMax.
- **Плагин X Chat:** официально добавлен в каталог плагинов; агент работает от имени подключённого аккаунта.
- **Поддержка моделей:** DeepSeek v4.1 Flash добавлен в селекторы провайдеров OpenRouter и Nous Portal, а в llama.cpp появилась поддержка Nemotron 3.5 Bolt со speculative drafting через DFlash.
- **CLI:** нажатие `Ctrl+D` посреди выполнения хода отключает терминал от шлюза (detach), не убивая сам запущенный процесс.
- **Усиление безопасности секретов:** статически заданные секреты конфигурации теперь строго привязываются к своим разрешённым эндпоинтам, а встроенные ключи изолированы от одноимённых кастомных записей.
- **Фиксы платформ обмена сообщениями:** масштабная ревизия устранила баги в WhatsApp, Telegram, Feishu, голосовом режиме Discord и граничных сценариях Bot Chat.
- **Расширение каталога:** добавлены плагины Unraid, Nextcloud Talk, Grok Voice (через hermes-xai), Jina, pay, personae и другие.

## hermes-vcc-engine: сжатие контекста без вызова модели

18 октября @witcheer сообщил о появлении в официальном каталоге плагина **hermes-vcc-engine** от разработчика danbiocchi (лицензия Apache-2.0). Плагин позволяет сжимать контекст длинных диалогов без генерации текстового резюме языковой моделью. По замерам автора на локальных моделях, задержка при сжатии сокращается примерно в **9 раз**.

**Как устроен механизм детерминированного сжатия:**
- Движок заменяет классический этап саммаризации детерминированной проекцией истории сессии: фиксируются исходные запросы, выполненные команды с кодами возврата, ошибки, применённые патчи и затронутые файлы.
- Каждая строка сохраняет ссылку на исходное сообщение в базе данных Hermes для быстрого поиска через `session_search`.
- Никаких вызовов LLM в штатном сценарии: если стандартное резюме на локальной модели занимало в среднем 195 секунд (а в крайних случаях доходило до лимита в 15 минут), то этап VCC отрабатывает **быстрее одной секунды**.
- Одинаковый вход всегда даёт идентичный результат, что делает поведение сжатия полностью воспроизводимым и предсказуемым в тестах.

**Архитектура и интеграция:**
Плагин наследует класс `ContextCompressor` и переопределяет исключительно внутренний метод `_generate_summary`. Логика триггеров сжатия, сохранение точных фрагментов verbatim, сопоставление вызовов инструментов и архивация остаются под управлением штатного кода Hermes.

Поскольку решение использует приватные методы ядра, плагин снабжён проверкой совместимости при запуске и автоматическим фолбэком на стандартный компрессор в случае изменений во внутреннем API.

Включение настраивается в файле `config.yaml`:
```yaml
context:
  vcc:
    enabled: true
```

## by2kb: от видеороликов к структурированным конспектам

18 октября @witcheer представил плагин **by2kb** от Charlesmpc — инструмент для автоматической переработки видеоматериалов в конспекты. Достаточно отправить агенту ссылку на YouTube или Bilibili, и он локально транскрибирует контент, формируя структурированные заметки в отдельной папке.

**Что создаёт плагин:**
Для каждого видео формируются три Markdown-артефакта:
1. **Полная транскрипция** с сохранением таймкодов и фактуры.
2. **Краткий вердикт:** быстрое резюме, отвечающее на вопрос, стоит ли тратить время на глубокое изучение материала.
3. **Развёрнутый конспект:** подробные структурированные тезисы для изучения.

**Принцип работы:**
- Хук `pre_gateway_dispatch` перехватывает ссылку в сообщении, проверяет права отправителя и запускает фоновый процесс транскрибации.
- Транскрипция в первую очередь извлекает встроенные субтитры; если их нет — переходит к локальному распознаванию аудиопотока через Whisper (по умолчанию полностью оффлайн, без сторонних облачных сервисов).
- Генерация конспекта выполняется основной моделью агента в Hermes — без сторонних MCP-серверов или дополнительных API-ключей.

Установка:
```bash
hermes plugins install by2kb
```

## Пять полезных функций, о которых стоит знать

18 октября @witcheer опубликовал список из пяти удобных возможностей Hermes Agent, реализованных по запросам сообщества. Первые три уже доступны в версии **v0.22.2**, а две оставшиеся войдут в следующий релиз:

- **Автоматическая установка плагинов и скиллов по запросу:** прямо в чате Hermes Desktop можно описать желаемую задачу простыми словами, и агент сам подберёт и установит подходящий плагин или скилл (`#134052`).
- **Интерактивный тур по Hermes Desktop:** агент может провести краткую или полную ознакомительную экскурсию по интерфейсу приложения (`#134054`).
- **Интеллектуальный поиск установленных приложений:** плагины, взаимодействующие с десктопным софтом (например, Blender), теперь проверяют стандартные пути установки в Windows, macOS и Linux вместо поиска по единственному захардкоженному пути (`#134050`).
- **Обратный отсчёт до выполнения периодических задач (в следующем релизе):** запланированные cron-задачи отображают живой таймер до следующего запуска прямо на экране (`#139187`).
- **Защита незавершённого кода (в следующем релизе):** при закрытии побочной сессии кодинга с несохранёнными изменениями Hermes предложит сохранить правки, отложить их (stash) или удалить (`#140603`).

## Harness Pro: поддержка с первого дня

18 октября @Teknium объявил о поддержке Hermes Agent «из коробки» (Day 0) для **Harness Pro** — специализированного настольного дисплея для AI-агентов от компании Autonomous (сославшись на анонс @dee_hw).

**Характеристики и возможности устройства ($299):**
- **Форм-фактор:** квадратный сенсорный дисплей с разрешением 720×720 пикселей, подключаемый по USB-C к Mac и работающий в связке с приложением Harness.
- **Управление агентами:** дисплей подключается к агентам на любых ваших хостах. Каждый агент визуализируется интерактивным цифровым питомцем, мимика которого отражает текущую деятельность агента; переключение между агентами выполняется свайпом.
- **Голосовое взаимодействие:** достаточно коснуться экрана, чтобы начать голосовой диалог.
- **Автономность:** агенты продолжают выполнение задач на серверах даже при закрытии приложения на Mac или выключении компьютера.
- **Аппаратная база:** чип ESP32-P4, 16 МБ Flash-памяти, 32 МБ PSRAM, массив из трёх микрофонов, встроенный динамик и обновление прошивки по кабелю.
