## Ox Alpha временно доступен бесплатно на Nous Portal

Команда **Nous Research** объявила, что модель **Ox Alpha** стала временно бесплатной на платформе **Nous Portal**. Заявленная пропускная способность инфраструктуры составляет 1 квадриллион токенов в день (при этом @Teknium в шутку намекнул на масштаб порядка 10 квадриллионов).

**Nous Portal** выступает единым центром управления для Hermes Agent:
- Один аккаунт связывает агента с полным каталогом моделей, шлюзом инструментов и облачным хостингом.
- Пользователям доступны сотни моделей от ведущих AI-лабораторий, включая бесплатные тиры и специальные скидки внутри портала.
- Теперь Ox Alpha доступна напрямую через портал — в дополнение к ранее открытым шлюзам через `opencode` и OpenRouter.

## Hermes Wingtips #51: чекпоинты в one-shot запусках

В 51-м выпуске серии микро-гайдов **Hermes Wingtips** разработчик @witcheer подробно разобрал работу механизма контрольных точек (**checkpoints**).

По умолчанию Hermes Agent автоматически сохраняет снапшоты файлов перед внесением любых правок. Этот страховочный механизм актуален не только для интерактивных сессий, но и для полностью скриптовых **one-shot** прогонов:
- Перед модификацией кода создается снимок текущего состояния.
- Если автономный запуск завершается ошибкой или вносит нежелательные изменения, состояние проекта можно мгновенно откатить.
- В выпуске детально описана архитектура автоматического бэкапа, защищающая инфраструктуру при выполнении задач без прямого участия человека.

## Hermes Wingtips #50: маркер [SILENT] для тихих cron-задач

Юбилейный 50-й выпуск серии посвящен флагу `[SILENT]`, предназначенному для подавления лишнего шума в логах и каналах оповещений.

Когда фоновые задачи мониторинга отправляют отчет о каждом штатном цикле выполнения, пользователи быстро привыкают к постоянным уведомлениям и начинают их игнорировать (эффект *alert fatigue*). Hermes Agent предлагает лаконичное решение:
- Если результат выполнения cron-задачи содержит маркер `[SILENT]`, доставка сообщения во внешние каналы полностью блокируется.
- Агент отправляет уведомление только тогда, когда в выводе задачи нет этого маркера — то есть возникла ошибка или произошло событие, требующее внимания инженера.

> **Источники:**
> - [@witcheer — Hermes Wingtips #50: маркер [SILENT] (21 августа 2026)](https://x.com/witcheer/status/2090697512097112274)

## Управление Hermes Agent с Apple Watch через iMessage

@witcheer поделился интересным юзкейсом: один из участников комьюнити настроил полноценное взаимодействие со своим Hermes Agent прямо с экрана **Apple Watch**.

Интеграция развернута поверх нативного шлюза к **iMessage**:
- Агент способен принимать текстовые команды и голосовые заметки, а также отправлять изображения, видео и файлы.
- Поддерживаются нативные интерактивные опросы прямо внутри диалога.
- В связке с поддержкой тредов в Telegram-шлюзе Hermes этот кейс наглядно демонстрирует концепцию **multi-surface** доступа: агент одинаково эффективно работает на десктопе, сервере, смартфоне или носимых устройствах.
