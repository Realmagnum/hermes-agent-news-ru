## hermes record: запись действий в браузере вместо их описания

25 октября witcheer представил `hermes record` — плагин Hermes Labs от Nous Research. Вместо того чтобы описывать браузерный сценарий словами, достаточно выполнить его один раз:

- Плагин подключается к браузеру на базе Chromium (Chrome, Chromium, Brave, Edge) по протоколу Chrome DevTools Protocol (CDP).
- Отслеживает действия пользователя в активной вкладке и сохраняет демонстрацию в JSON-файл.
- Встроенный скилл обучает команду `/learn` превращать эту запись в полноценный скилл, который затем воспроизводит весь сценарий инструментами браузера Hermes.
- В демонстрационном ролике witcheer записал заказ пиццы и затем успешно поручил агенту повторить его автоматически.

Плагин устанавливается из официального каталога одной командой:

```bash
hermes plugins install workflow-record
```

Плагин добавляет CLI-команду `hermes record` и готовый скилл. Он не регистрирует инструментов для моделей, не использует хуки и ничего не выполняет во время обычных диалогов, а его единственная зависимость — `websockets` — уже входит в поставку Hermes. Функциональность вынесена из ядра в отдельный плагин в рамках пулл-реквеста `hermes-agent #72199`.

## Unbroker: удаление персональных данных у брокеров информации

26 октября Nous Research обратила внимание на скилл `Unbroker`, который устанавливается одной командой:

```bash
hermes skills install official/security/unbroker
```

Скилл находит, где персональные данные пользователя (ФИО, адреса, телефоны, email, контакты родственников) утекли к дата-брокерам и на сайты поиска людей, и автоматически запрашивает их удаление там, где это возможно. Ручные шаги с подсказками агента требуются только в случаях, когда сервис запрашивает ввод CAPTCHA, скан документа, звонок или отправку факса.

Ключевые особенности и ограничения безопасности:
- **Безопасность и этичность:** скилл не обходит защиту от ботов, не выполняет действий без явно зафиксированного согласия и не трогает публичные архивы или аккаунты, контролируемые самим пользователем.
- **Автономный движок:** утилита представляет собой Python CLI без сторонних зависимостей.
- **Удаление по закону:** для жителей Калифорнии единый запрос DROP удаляет данные сразу у всех зарегистрированных дата-брокеров (около 545 компаний). Для пользователей из других регионов отправляются адресные запросы в рамках требований CCPA и GDPR.

## agent-run-debugger: поиск сломавшегося шага в упавших сессиях

26 октября witcheer представил community-плагин `agent-run-debugger`. Если длинная задача падает на полпути, инструмент точно указывает на сбойный шаг и выводит сопутствующую ошибку. В тестовом сценарии плагин проанализировал сессию и сразу выявил скрипт отчётов, который падал на некорректной строке CSV-файла, отранжировав вероятные причины сбоя.

Возможности плагина по данным каталога:
- **Локальная офлайн-отладка:** анализирует упавшие, зависшие или аномально дорогие запуски без обращения к внешним API.
- **Поддержка форматов трейсов:** принимает дампы сессий в JSONL от Hermes, Claude Code или нейтральном формате v1.
- **Глубокий анализ сбоев:** строит детерминированную хронологию выполнения, подсвечивает точки отказа, ранжирует гипотезы с доказательствами, выявляет пробелы в данных и позволяет «вхолостую» воспроизвести записанный запуск.

Установка:
```bash
hermes plugins install agent-run-debugger
```
Автор проекта — Sahil-SS9.

## Herald: скорая поддержка упоминаний в X

26 октября iamlukethedev анонсировал скорую поддержку упоминаний в соцсети X для Herald.

Сценарий работы предельно прост:
1. Заметив твит, требующий действия или анализа, пользователь отвечает на него с упоминанием `@HeraldHermes` и кратким описанием задачи.
2. Herald отправляет push-уведомление на смартфон.
3. Смартфон передает задачу локальному экземпляру Hermes Agent.
4. Hermes приступает к выполнению задания.

Интеграция работает в режиме «только чтение»: Herald никогда не публикует твиты от имени учетной записи пользователя.

## Wingtips #111: сохранение задач в именованные скиллы

26 октября witcheer опубликовал совет Hermes Wingtips #111. Когда вы завершили сложную цепочку действий, которую планируете повторять в будущем, достаточно попросить агента:

```text
save what we did as a skill called weekly-update
```

Hermes проанализирует шаги из текущей беседы, структурирует инструкцию и сохранит её в качестве нового скилла с указанным именем.
