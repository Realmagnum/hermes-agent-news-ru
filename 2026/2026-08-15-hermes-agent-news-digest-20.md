# Новости Hermes Agent #20

/loop появляется в Hermes Agent, Bot Mode готовится к выходу в desktop, поверхность плагинов подробно документирована, а фишинговая кампания нацелена на контрибьюторов.

## /loop: цикл, живущий в сессии

14 августа в Hermes Agent появилась новая слэш-команда: `/loop`. Принцип: `/loop 5m <prompt>` заново выполняет промпт каждые 5 минут в той же сессии. Если оставить интервал пустым, Hermes саморегулируется: сначала проверяет часто, а затем увеличивает интервалы, пока ничего не меняется.

Дополнительная ценность по сравнению с обычным cron-заданием: цикл живёт в сессии вместе со всем контекстом текущего обмена. Агент может сам решить остановить цикл, когда задача выполнена, — через `--times N`, `--until <condition>` или предоставив решение агенту. witcheer привёл примеры использования: следить за деплоем или CI, запускать тесты и исправлять ошибки, пока они не пройдут, или держать heartbeat длительной задачи, продолжая заниматься чем-то другим в той же сессии.

Команда работает в CLI, desktop и во всех каналах обмена сообщениями. Teknium уточнил, что это аналог `/loop` из Claude Code для Hermes. Документация уже доступна: [hermes-agent.nousresearch.com/docs/user-guide/features/loops](https://hermes-agent.nousresearch.com/docs/user-guide/features/loops).

## Bot Mode: подготовка desktop-релиза

15 августа Teknium подтвердил, что работает над серией оптимизаций, исправлений багов и улучшений качества жизни в desktop-GUI-приложении, готовя релиз Bot Mode — вероятно, в понедельник (17 августа). Он также показал новинку в UX: при создании нового бота интерфейс позволяет просматривать skills hub в расширенном режиме и добавлять любую skill в бота напрямую.

Отзыв пользователя EddieVi подтверждает интерес: его поисковый бот Rick получил тему, отправился искать информацию, процитировал источники и вернул ответ в виде сообщения. Его слова: «Мои агенты теперь похожи на экипаж, а не на файл конфигурации».

## Расширение поверхности плагинов: детали

13 августа Teknium анонсировал масштабное расширение поверхности плагинов Hermes Agent через tracking issue [#64182](https://github.com/NousResearch/hermes-agent/issues/64182#issuecomment-5275487630). В тот же день witcheer подробно описал основные интеграции:

- Плагины могут перехватывать поток LLM в реальном времени и события gateway в момент их возникновения.
- Шина событий позволяет плагинам реагировать друг на друга.
- Система декларирования возможностей с согласием при установке: поверхности безопасности отключены по умолчанию.
- Плагин-паки и просматриваемый индекс плагинов.
- Scaffold и Plugin Doctor для разработчиков плагинов.

Все эти дополнения кумулятивны: старые плагины продолжают работать без изменений.
