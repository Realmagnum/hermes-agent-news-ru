# Новости Hermes Agent #19

Bot Mode официально запущен в публичной бете, управление под-агентами в реальном времени, Browser Use mode включён по умолчанию, загрузка файлов перетаскиванием и LongCat-2.0 бесплатно неделю на Nous Portal.

## Bot Mode выходит в публичную бету

Вечером 13 августа Teknium официально запустил Bot Mode для Hermes Agent — на этот раз в публичной бете с отдельным плагином. Bot Mode заменяет режим сессий: каждый профиль агента становится «ботом» со своей историей, аватаром, описанием и конфигурацией. Боты могут общаться между собой через отдельный inbox.

Бета доступна через плагин на [github.com/NousResearch/Hermes-Bot-Mode](https://github.com/NousResearch/Hermes-Bot-Mode). Tonbistudio опубликовал видео-демонстрацию: боковая панель ботов, создание нового бота и agent inbox, через который боты обмениваются сообщениями. Окно cron-задач тоже доступно у каждого бота. Teknium планирует встроить режим в основное desktop-приложение после фазы тестирования.

> Источники: [@Teknium, 13 августа 2026](https://x.com/Teknium/status/2088003994904113614) — [@tonbistudio, 14 августа 2026](https://x.com/tonbistudio/status/2088059838362501360) — [@witcheer, 13 августа 2026](https://x.com/witcheer/status/2088028193590087994)

## Управление под-агентами в реальном времени

13 августа Teknium представил новую возможность: агент Hermes теперь может направлять под-агентов, останавливать их и читать их транскрипты в реальном времени. Функция опирается на параметры `steer`, `stop` и `list` инструмента `delegate_task`, используя механизм live-оркестрации асинхронных дочерних задач. Пока под-агент работает в фоне, родительский агент может отправить ему корректировку траектории (`steer`), остановить его, чтобы получить частичный результат (`stop`), или посмотреть список активных под-агентов с их статусом (`list`).

> Источник: [@Teknium, 13 августа 2026](https://x.com/Teknium/status/2087986084592709814)

## Hermes Wingtips #46: Browser Use mode включён по умолчанию

14 августа witcheer опубликовал сорок шестой выпуск своей серии Hermes Wingtips. Тема — Browser Use mode, harness, разработанный командой Browser Use. В отличие от классического подхода, где агент управляет страницей по одному вызову инструмента за клик, агент пишет скрипт, который выполняет весь поток за один раз. Начиная с версии v2026.8.13 режим включён по умолчанию. Достаточно простого обновления, чтобы веб-задачи стали дешевле — без каких-либо изменений в настройках.

> Источник: [@witcheer, 14 августа 2026](https://x.com/witcheer/status/2088204444391399722)

## Перетаскивание файлов в Hermes Agent

14 августа witcheer показал удобную функцию: файл можно перетащить прямо в Hermes Agent. Файл становится частью разговора, после чего можно задавать вопросы и итерировать по нему. Видео демонстрирует жест: файл перетаскивается в интерфейс, и агент сразу загружает его как контекст для дальнейшего обмена.

> Источник: [@witcheer, 14 августа 2026](https://x.com/witcheer/status/2088167034982932693)

## LongCat-2.0 бесплатно неделю на Nous Portal

13 августа Nous Research объявил, что LongCat-2.0 от Meituan бесплатен на Nous Portal в течение недели. Модель — MoE с 1,6 триллиона параметров (около 48B активных на токен) и контекстом в 1 миллион токенов, разработанная для агентного кодинга. Её результаты: 70,8 на Terminal-Bench 2.1, 59,5 на SWE-bench Pro, 77,3 на SWE-bench Multilingual. Архитектура основана на трёх инновациях: разреженное внимание, адаптированное к длинному контексту (LSA), динамически активируемые эксперты без мёртвых вычислений (Zero-Compute Experts) и маршрутизация по группам задач (MOPD), которая направляет каждый токен к подходящему специализированному эксперту (агент, рассуждение, взаимодействие).

> Источники: [@NousResearch, 13 августа 2026](https://x.com/NousResearch/status/2087970618167706023) — [@Teknium, 13 августа 2026](https://x.com/Meituan_LongCat/status/2087943641956057322)
