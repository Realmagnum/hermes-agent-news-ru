## Bot Mode выходит в публичную бету

Вечером 13 августа @Teknium официально представил **Bot Mode** для Hermes Agent в формате публичной беты с отдельным плагином. 

Bot Mode кардинально меняет привычную сессионную модель: теперь каждый профиль агента становится полноценным «ботом» со своей историей переписки, аватаром, описанием и индивидуальной конфигурацией. Боты получили возможность общаться между собой через выделенный агентный инбокс (`inbox`).

Бета-версия доступна через плагин в репозитории [github.com/NousResearch/Hermes-Bot-Mode](https://github.com/NousResearch/Hermes-Bot-Mode). Разработчик @tonbistudio опубликовал демо-ролик, где показаны:
- сайдбар со списком ботов;
- процесс создания нового бота;
- меж-агентный инбокс для обмена сообщениями;
- окно настройки запланированных cron-задач для каждого конкретного бота.

После завершения этапа тестирования @Teknium планирует встроить этот режим напрямую в основное десктопное приложение.

> **Источники:**

> - [@tonbistudio — Демонстрация интерфейса Bot Mode (14 августа 2026)](https://x.com/tonbistudio/status/2088059838362501360)
> - [@witcheer — Первые впечатления от Bot Mode (13 августа 2026)](https://x.com/witcheer/status/2088028193590087994)

## Управление субагентами в реальном времени

13 августа @Teknium показал новую возможность оркестрации: родительский агент Hermes теперь может в реальном времени направлять, останавливать и читать транскрипты своих субагентов.

Функционал реализован через параметры `steer`, `stop` и `list` инструмента `delegate_task`, задействуя механизм live-оркестрации асинхронных дочерних процессов. На практике это работает следующим образом: пока субагент выполняет фоновую задачу, родительский агент может:
- **скорректировать курс** (`steer`) — отправить новые вводные или правки прямо по ходу выполнения;
- **прервать работу** (`stop`) — принудительно остановить процесс и мгновенно забрать частичный результат;
- **получить статус** (`list`) — запросить список всех активных дочерних агентов с их текущим состоянием.

> **Источники:**
> - [@Teknium — Демонстрация оркестрации субагентов (13 августа 2026)](https://x.com/Teknium/status/2087986084592709814)

## Hermes Wingtips #46: режим Browser Use включен по умолчанию

14 августа @witcheer опубликовал сорок шестой выпуск серии Hermes Wingtips, посвященный режиму **Browser Use** — специальному харнессу, созданному командой Browser Use.

В отличие от классического подхода, при котором агент пошагово дергает браузер через вызовы инструментов (один клик — один tool call), в новом режиме агент генерирует единый скрипт, отрабатывающий весь пользовательский сценарий за один проход. 

Начиная со сборки `v2026.8.13`, этот режим активирован по умолчанию. Достаточно просто обновиться — веб-автоматизация станет ощутимо быстрее и экономнее по токенам без необходимости править конфиги.

> **Источники:**
> - [@witcheer — Hermes Wingtips #46 (14 августа 2026)](https://x.com/witcheer/status/2088204444391399722)

## Drag-and-Drop файлов в Hermes Agent

14 августа @witcheer продемонстрировал удобное улучшение UX: поддержку перетаскивания файлов (drag-and-drop) прямо в окно Hermes Agent.

Файл мгновенно становится частью текущего диалога: агент сразу захватывает его в рабочий контекст, после чего к документу или коду можно адресовать вопросы и запускать итеративную доработку. В коротком видео показано, как гладко это работает на практике без вызова диалоговых окон выбора файлов.

> **Источники:**
> - [@witcheer — Демонстрация drag-and-drop файлов (14 августа 2026)](https://x.com/witcheer/status/2088167034982932693)

## LongCat-2.0 доступен бесплатно на неделю в Nous Portal

13 августа Nous Research объявили о бесплатном недельном доступе к модели **LongCat-2.0** от Meituan на платформе Nous Portal.

LongCat-2.0 — это MoE-архитектура на 1,6 трлн параметров (порядка 48B активных на один токен) с контекстным окном в **1 миллион токенов**, спроектированная специально под задачи агентного программирования. Модель показала впечатляющие результаты в бенчмарках:
- **Terminal-Bench 2.1:** 70,8
- **SWE-bench Pro:** 59,5
- **SWE-bench Multilingual:** 77,3

Архитектурно решение опирается на три ключевых новшества:
1. **LSA** (*Long-context Sparse Attention*) — разреженное внимание, оптимизированное под сверхдлинные контексты;
2. **Zero-Compute Experts** — динамическая активация экспертов без холостых вычислительных затрат;
3. **MOPD** — таск-ориентированный роутинг, распределяющий каждый токен к профильным экспертам (агентные действия, рассуждения, интерактивное взаимодействие).

## Релиз v2026.8.13: стабилизация апдейта из 656 PR

13 августа состоялся релиз тега `v2026.8.13` (соответствует версии `v0.20.1`). 

С момента релиза `v0.20.0` (3 августа) команда провела колоссальную работу: замерджили 1 444 коммита из **656 пулл-реквестов**, затронув 2 172 файла. Этот накопительный патч (rollup) стабилизирует работу десктопного приложения, платформ gateway, инсталляторов, системы тулов и каталогов провайдеров. В рамках апдейта было закрыто 481 issue. 

Полные release notes разработчики опубликуют вместе с крупным обновлением `v0.21.0`. Обновиться можно стандартной командой:

```bash
hermes update
```
